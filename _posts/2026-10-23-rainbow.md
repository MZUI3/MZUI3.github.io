> [DQN]({% post_url 2026-10-24-dqn %}) 이후 여러 개선이 따로따로 제안되었습니다. 이 블로그에서도 [Double DQN]({% post_url 2026-08-04-double-dqn %}), [Noisy Networks]({% post_url 2026-08-10-noisy-network %}), [C51]({% post_url 2026-08-12-c51-distributional-rl %})을 각각 다뤘습니다. 그런데 이것들이 **서로 보완적인지, 합치면 더 좋은지**는 분명하지 않았습니다. **Rainbow**(Hessel et al., DeepMind, AAAI 2018)는 여섯 가지 확장을 한 에이전트에 통합해 Atari 57 게임에서 데이터 효율과 최종 성능 모두 당시 최고를 기록하고, 하나씩 빼 보는 ablation으로 각 부품의 기여를 쟀습니다.

## 1. 여섯 가지 확장

각 확장은 DQN의 서로 다른 한계를 겨냥합니다. 같은 문제(예: 탐험)를 다루는 방법은 하나씩만 골랐습니다.

| 확장 | 문제 | 방법 |
|---|---|---|
| **Double Q-learning** | max 연산의 과대평가 | 부트스트랩 행동의 선택(online)과 평가(target)를 분리: $$R_{t+1} + \gamma_{t+1} q_{\bar\theta}(S_{t+1}, \arg\max_{a'} q_\theta(S_{t+1}, a'))$$ |
| **Prioritized replay** | 균등 샘플링의 비효율 | TD 오차의 절댓값에 비례한 확률 $$p_t \propto \lvert \delta_t \rvert^\omega$$로 샘플링. 새 전이는 최대 우선순위 |
| **Dueling** | 행동 간 일반화 | $$q_\theta(s, a) = v_\eta(f_\xi(s)) + a_\psi(f_\xi(s), a) - \frac{1}{N_{\text{actions}}} \sum_{a'} a_\psi(f_\xi(s), a')$$ |
| **Multi-step** | 보상 전파가 느림 | n-step 절단 return $$R^{(n)}_t = \sum_{k=0}^{n-1} \gamma^{(k)}_t R_{t+k+1}$$로 부트스트랩 |
| **Distributional** | 기댓값만 학습 | $$N_{\text{atoms}}$$개 받침점 $$z$$ 위의 return 분포를 KL로 학습: $$D_{KL}(\Phi_z d'_t \,\Vert\, d_t)$$ |
| **Noisy Nets** | ε-greedy의 한계 | 선형층에 노이즈 스트림 추가: $$y = (b + Wx) + (b_{\text{noisy}} \odot \epsilon^b + (W_{\text{noisy}} \odot \epsilon^w) x)$$ |

## 2. 통합 에이전트

조합이 단순한 나열은 아닙니다. 서로 얽힌 부분을 정리해야 합니다.

- **Multi-step + distributional**: 1-step 분포 손실을 n-step으로 바꿉니다. $$S_{t+n}$$의 분포를 누적 할인 $$\gamma^{(n)}_t$$로 수축하고 n-step return으로 이동시킨 목표 분포를 받침점에 투영합니다.

$$
d^{(n)}_t = \big(R^{(n)}_t + \gamma^{(n)}_t z,\ p_{\bar\theta}(S_{t+n}, a^*_{t+n})\big),\qquad \mathcal{L} = D_{KL}\big(\Phi_z d^{(n)}_t \,\|\, d_t\big)
$$

- **Double + distributional**: 부트스트랩 행동 $$a^*_{t+n}$$은 online 네트워크의 평균 행동가치로 고르고, 그 행동의 분포는 target 네트워크로 평가합니다.
- **Prioritized + distributional**: TD 오차 대신 **KL 손실**을 우선순위로 씁니다. 알고리즘이 최소화하는 양이 그것이고, 확률적 환경에서 return이 결정론적이지 않아도 손실은 계속 줄 수 있어 더 견고할 수 있습니다.
- **Dueling + distributional**: 공유 표현 $$f_\xi(s)$$ 위에 가치 스트림($$N_{\text{atoms}}$$ 출력)과 advantage 스트림($$N_{\text{atoms}} \times N_{\text{actions}}$$ 출력)을 두고, **atom마다** dueling 집계를 한 뒤 softmax로 정규화합니다.

$$
p^i_\theta(s, a) = \frac{\exp\big(v^i_\eta(\phi) + a^i_\psi(\phi, a) - \bar a^i_\psi(s)\big)}{\sum_j \exp\big(v^j_\eta(\phi) + a^j_\psi(\phi, a) - \bar a^j_\psi(s)\big)}
$$

- **Noisy Nets**: 모든 선형층을 noisy 버전으로 바꾸고, 독립 노이즈 변수를 줄이기 위해 factorised Gaussian 노이즈를 씁니다. 탐험은 완전히 greedy($$\epsilon = 0$$)입니다.

### 하이퍼파라미터

조합 공간이 너무 커서 각 부품을 도입한 논문의 값에서 시작해 민감한 것만 수동 좌표 하강으로 조정했습니다. **57개 게임에 같은 값**입니다.

| 파라미터 | 값 |
|---|---|
| 학습 시작 전 최소 history | 80K 프레임(DQN은 200K, prioritized replay 덕에 빨리 시작) |
| Optimizer | Adam, 학습률 $$0.00025/4 = 6.25 \times 10^{-5}$$, $$\epsilon = 1.5 \times 10^{-4}$$ |
| 탐험 | $$\epsilon = 0$$, Noisy Nets $$\sigma_0 = 0.5$$ |
| Target 네트워크 주기 | 32K 프레임 |
| Prioritization | proportional, $$\omega = 0.5$$, 중요도 샘플링 $$\beta$$ 0.4 → 1.0 |
| Multi-step | $$n = 3$$ (1, 3, 5 비교. 3과 5가 초반엔 비슷했으나 3이 최종 최고) |
| Distributional | 51 atoms, $$[-10, 10]$$ |

## 3. 코드로 보기: 투영, dueling 집계, noisy layer

통합 에이전트의 핵심 연산 세 가지를 작은 텐서로 확인합니다.

```python
import torch, torch.nn as nn, torch.nn.functional as F

torch.manual_seed(0)
N_ATOMS, V_MIN, V_MAX, GAMMA, N_STEP = 51, -10.0, 10.0, 0.99, 3
z = torch.linspace(V_MIN, V_MAX, N_ATOMS)                   # 분포의 받침점(atom)
dz = (V_MAX - V_MIN) / (N_ATOMS - 1)

# 1) Distributional + multi-step: n-step 보상으로 이동·수축한 목표 분포를 고정 받침점 z 위로 투영(Φ_z)
def project(p_next, rewards, gammas):
    """p_next: 다음 상태(S_{t+n})에서 고른 행동의 분포 (B, N_ATOMS). rewards: n-step 할인 보상 R^(n). gammas: γ^(n)(종료면 0)"""
    Tz = (rewards[:, None] + gammas[:, None] * z[None]).clamp(V_MIN, V_MAX)   # 목표 받침점 R^(n) + γ^(n) z
    b = (Tz - V_MIN) / dz; l, u = b.floor().long(), b.ceil().long()
    m = torch.zeros_like(p_next)
    m.scatter_add_(1, l, p_next * (u - b + (l == u).float()))                 # 아래 atom으로 보내는 질량
    m.scatter_add_(1, u, p_next * (b - l))                                     # 위 atom으로 보내는 질량
    return m

p_next = torch.softmax(torch.randn(4, N_ATOMS), -1)
R_n = torch.tensor([1.0, 0.5, -2.0, 3.0]); g_n = torch.tensor([GAMMA ** N_STEP] * 3 + [0.0])   # 마지막은 종료 전이
m = project(p_next, R_n, g_n)
print(f"투영된 분포의 합: {m.sum(1).tolist()}")
print(f"평균 보존: 목표 평균 {(R_n + g_n * (p_next @ z)).tolist()}")
print(f"           투영 평균 {(m @ z).tolist()}")

# 2) Dueling + distributional: atom마다 가치 스트림과 advantage 스트림을 합친 뒤 softmax
class DuelingDistHead(nn.Module):
    def __init__(self, d, n_actions):
        super().__init__(); self.v = nn.Linear(d, N_ATOMS); self.a = nn.Linear(d, n_actions * N_ATOMS); self.n = n_actions
    def forward(self, phi):
        v = self.v(phi)[:, None]; a = self.a(phi).view(-1, self.n, N_ATOMS)
        return torch.softmax(v + a - a.mean(1, keepdim=True), -1)               # p_θ^i(s, a), 행동마다 합이 1
head = DuelingDistHead(32, 6); p = head(torch.randn(2, 32))
print(f"dueling-distributional 출력: {tuple(p.shape)} (batch, 행동, atom), 행동별 합 {p.sum(-1)[0, :3].tolist()}")
print(f"행동의 기댓값 q(s, a) = zᵀp: {(p @ z)[0].tolist()}")

# 3) Noisy linear (factorised Gaussian): 가중치의 노이즈 스트림으로 탐험. 노이즈를 끄면 보통의 선형층
class NoisyLinear(nn.Module):
    def __init__(self, i, o, sigma0=0.5):
        super().__init__()
        self.W, self.b = nn.Parameter(torch.randn(o, i) / i ** 0.5), nn.Parameter(torch.zeros(o))
        self.W_noisy, self.b_noisy = nn.Parameter(torch.full((o, i), sigma0 / i ** 0.5)), nn.Parameter(torch.full((o,), sigma0 / i ** 0.5))
        self.i, self.o = i, o
    def forward(self, x, noisy=True):
        if not noisy: return x @ self.W.T + self.b
        f = lambda e: e.sign() * e.abs().sqrt()
        eps_i, eps_o = f(torch.randn(self.i)), f(torch.randn(self.o))                # factorised: i + o개의 난수로 i×o 노이즈
        return x @ (self.W + self.W_noisy * torch.outer(eps_o, eps_i)).T + self.b + self.b_noisy * eps_o
nl = NoisyLinear(8, 3); x = torch.randn(1, 8)
outs = torch.stack([nl(x)[0] for _ in range(1000)])
print(f"noisy layer: 같은 입력에 대한 출력 표준편차 {outs.std(0).tolist()} (노이즈 없는 출력 {nl(x, noisy=False)[0].tolist()})")
```

```text
투영된 분포의 합: [0.9999999403953552, 1.0, 0.9999999403953552, 1.0000001192092896]
평균 보존: 목표 평균 [2.1525745391845703, -1.3188809156417847, -1.9135100841522217, 3.0]
           투영 평균 [2.1190226078033447, -1.3191922903060913, -1.8431179523468018, 3.0]
dueling-distributional 출력: (2, 6, 51) (batch, 행동, atom), 행동별 합 [1.0, 1.0000001192092896, 1.0]
행동의 기댓값 q(s, a) = zᵀp: [-0.8273299336433411, -1.2285151481628418, 0.14026498794555664, -0.6701855659484863, -1.3524690866470337, -0.4067268967628479]
noisy layer: 같은 입력에 대한 출력 표준편차 [0.2827375531196594, 0.28944557905197144, 0.28577929735183716] (노이즈 없는 출력 [-1.294177770614624, -1.2157938480377197, 0.43578314781188965])
```

- 투영은 확률 질량을 보존하고, 평균은 받침점 경계에서 잘리는 만큼만 달라집니다. 종료 전이($$\gamma^{(n)} = 0$$)는 보상 3.0 한 점에 질량이 모여 평균이 정확히 3.0입니다. 받침점 범위 $$[-10, 10]$$ 밖의 return은 잘린다는 점이 뒤의 ablation 해석에 중요합니다.
- dueling 집계는 atom별로 이루어지고 행동마다 51개 atom의 확률 합이 1입니다. 평균 행동가치는 $$z^\top p$$로 얻어 부트스트랩 행동을 고르는 데 씁니다.
- noisy layer는 같은 입력에도 출력이 흔들리고, 그 폭($$W_{\text{noisy}}$$)은 학습으로 조절되어 상태별로 다른 속도로 탐험이 줄어듭니다.

## 4. 실험

57개 Atari 게임, 200M 프레임, 1M step마다 500K 프레임 평가, 사람 정규화 점수의 **중앙값**이 주 지표입니다(평균은 Atlantis처럼 수백 배 점수가 나오는 게임에 지배됨).

### 기준선과 비교

| 에이전트 | no-ops | human starts |
|---|---|---|
| DQN | 79% | 68% |
| DDQN | 117% | 110% |
| Prioritized DDQN | 140% | 128% |
| Dueling DDQN | 151% | 117% |
| A3C | - | 116% |
| Noisy DQN | 118% | 102% |
| Distributional DQN | 164% | 125% |
| **Rainbow** | **223%** | **153%** |

- **7M 프레임**에 DQN의 최종 성능에 도달하고(한 GPU로 10시간 미만), **44M 프레임**에 모든 기준선의 최종 성능을 넘습니다.
- 사람 대비 20%, 50%, 100%, 200%, 500%의 각 임계값을 넘는 게임 수에서 모두 격차가 있습니다. 이미 잘하던 게임도, 아직 못하던 게임도 함께 좋아졌습니다.
- human starts(사람 플레이의 초반 상태에서 시작)에서 점수가 낮아지는 정도가 자기 궤적에 대한 과적합의 척도인데, Rainbow도 223%에서 153%로 떨어집니다.

### Ablation: 하나씩 빼 보면

| 뺀 부품 | 영향 |
|---|---|
| **Prioritized replay** | 가장 큰 하락. 초반 성능도 최종 성능도 나빠짐. 57개 중 53개 게임에서 Rainbow가 더 좋음 |
| **Multi-step** | 가장 큰 하락. 초반은 당연하고, **최종 성능까지** 나빠진 것이 뜻밖. 53/57 |
| **Distributional** | 그다음. 처음 40M 프레임은 차이가 없다가 뒤처짐. 사람 수준 근처나 이상의 게임에서 주로 손해 |
| **Noisy Nets** | 중앙값 하락. 일부 게임은 크게 나빠지고 일부는 조금 좋아짐 |
| **Dueling** | 중앙값에 유의한 차이 없음. 게임별로는 다름(200% 이상 게임에서 이득, 20% 미만 게임에서 손해) |
| **Double** | 중앙값 차이 제한적. 게임에 따라 도움도 되고 해도 됨 |

Double Q-learning의 효과가 작은 이유를 따로 분석했습니다. 학습된 에이전트의 예측과 실제 할인 return을 비교하니, 실제 return이 **10을 넘어 받침점 범위 밖**인 경우가 많아 **과대평가가 아니라 과소평가**가 일어났습니다. 값을 $$[-10, 10]$$으로 자르는 것 자체가 과대평가 편향을 상쇄하는 것으로 보이며, 받침점 범위를 넓히면 Double의 중요성이 커질 수 있다고 봅니다.

## 5. 해석

**1. 이 논문의 기여는 "새 알고리즘"이 아니라 "통합과 측정"입니다.** 여섯 부품 중 Rainbow가 새로 만든 것은 없습니다. 기여는 그것들이 정말 보완적인지 확인하고(그렇습니다, 하나만 빼고), 각각이 얼마나 기여하는지 같은 조건에서 잰 것입니다. 이후 Atari 연구의 표준 기준선이 된 이유입니다. [EfficientZero]({% post_url 2026-08-21-efficientzero %}) 같은 후속 연구가 비교 대상으로 삼는 것도 이 에이전트입니다.

**2. 결합에는 설계가 필요합니다.** 2절에서 본 것처럼 분포 손실을 n-step으로, Double의 선택·평가 분리를 분포로, 우선순위를 KL로, dueling을 atom별로 옮기는 결정들이 있어야 부품이 맞물립니다. 위 코드의 투영 함수가 n-step 보상과 $$\gamma^{(n)}$$을 받는 것이 그 한 예입니다.

**3. 가장 중요한 두 부품은 데이터를 어떻게 쓰느냐에 관한 것입니다.** prioritized replay(어떤 전이를 더 자주 배우나)와 multi-step(보상을 얼마나 빨리 전파하나)이 없으면 가장 크게 무너집니다. 네트워크 구조(dueling)나 추정 편향(Double)보다 **학습 신호의 질과 속도**가 결정적이었다는 뜻입니다.

**4. Double Q-learning의 분석이 흥미롭습니다.** 과대평가를 고치는 방법이 효과가 없던 이유가 "이미 과소평가하고 있어서"라는 발견은, 분포의 받침점 범위라는 사소해 보이는 설정이 다른 부품의 역할을 바꾼다는 것을 보여 줍니다. 부품의 효과는 조합 안에서만 뜻이 있습니다.

**5. 평가를 읽을 때 주의할 점.** 중앙값은 분포의 절반만 말해 줍니다. 게임별 그래프(Figure 4)를 보면 Noisy Nets와 dueling은 게임에 따라 득실이 갈립니다. 기준선 중 일부(DDQN, Prioritized, Dueling, A3C)는 논문 수치를 가져왔고 나머지는 재구현입니다. 하이퍼파라미터 조정은 제한적이었고, 벽시계 시간이 아니라 프레임 수 기준의 비교라 병렬화 방법들과는 직접 비교하지 않았습니다.

## 6. 정리

| 항목 | 내용 |
|---|---|
| 목표 | DQN의 여섯 확장이 보완적인지 확인하고 통합 에이전트의 성능과 부품별 기여 측정 |
| 통합 | n-step 분포 손실, online으로 행동 선택·target으로 평가(Double), KL 손실 우선순위, atom별 dueling, 전 층 factorised noisy |
