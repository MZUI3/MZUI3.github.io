> 웨이퍼 맵은 다이별 불량 여부를 2차원으로 그린 그림이고, 특정 **공간 패턴**(중심, 도넛, 가장자리 링, 스크래치 등)은 어느 공정 단계에서 문제가 생겼는지 알려 줍니다. 숙련 엔지니어가 눈으로 보던 일을 자동화하려는 연구는 많았지만, 대부분 원본 맵 픽셀을 그대로 입력으로 써서 대규모 데이터에는 정확도와 속도가 모자랐습니다. 이 논문(Wu, Jang, Chen, NTHU·NTU·TSMC, IEEE Transactions on Semiconductor Manufacturing 2015)은 **회전·크기 불변인 압축 특징**을 제안하고, 이를 검증하기 위해 **실제 팹에서 수집한 811,457장의 WM-811K**를 공개했습니다. 이후 10년 동안 웨이퍼 맵 딥러닝 연구의 표준 벤치마크가 된 데이터셋입니다.

## 1. 문제: 대규모 팹에서는 정확도와 처리량이 함께 필요하다

TSMC는 2013년 한 해에 8인치 환산 약 1,500만 장의 웨이퍼를 생산했습니다. 기존 접근은 세 갈래였습니다.

- **웨이퍼 기반 군집화**(ART1 등): 새 패턴을 발견할 수 있지만 회전 불변이 아니어서 같은 패턴을 각도만 다르면 다른 군집으로 봅니다.
- **영역 기반 모델링**(이변량 정규, 주곡선 등): 다중 패턴을 모델링할 수 있지만 합성 데이터에 의존하고 원본 맵을 입력으로 씁니다.
- **공간 시그니처 분석**: 이미지 모멘트 특징과 fuzzy k-NN을 쓰지만 k-NN이 대규모에서 느립니다.

필요한 것은 (1) 웨이퍼 크기와 회전에 무관하고 (2) 계산과 저장이 작으면서 (3) 분류력이 있는 특징, 그리고 그 위에서 빠른 분류기와 검색입니다.

## 2. 방법

### Radon 기반 특징

Radon 변환은 CT에서 쓰는 선 적분입니다. 웨이퍼 맵 $$M$$(불량 다이 1, 정상 0)에 대해

$$
g(\rho, \theta) = \sum_{x=1}^{m} \sum_{y=1}^{n} M(x, y)\, \delta(x \cos\theta + y \sin\theta - \rho)
$$

로 각도 $$\theta$$마다 투영을 구해 $$\rho \times \theta$$ 행렬 $$G$$를 만들고 min-max 정규화합니다. 중심 패턴은 $$\rho$$ 중앙에 좁고 강한 응답, 도넛은 더 넓은 응답, 가장자리 링은 응답 띠의 경계에 강한 응답을 보입니다. 여기서 $$\theta$$ 방향으로 **행 평균 $$G_\mu$$와 행 표준편차 $$G_\sigma$$**를 취하면 회전에 무관해지고, 3차 보간으로 각각 20차원으로 리샘플링하면 크기에도 무관해집니다. 합쳐 40차원입니다.

### 기하 기반 특징

연결 성분 라벨링으로 영역을 찾고 **가장 두드러진 영역**(최대 면적 $$s_a$$ 또는 최대 둘레 $$s_p$$)의 속성을 웨이퍼 크기로 정규화해 씁니다. 면적 비율, 둘레/반지름, 중심까지의 최대·최소 거리, 외접 타원의 장축·단축 비율, solidity, eccentricity 등입니다. 통계 속성으로는 전역 불량 다이 비율(RDD)과 바깥 두 링의 지역 RDD(가장자리 패턴 검출용)를, 선형 속성으로는 **Hough 변환**으로 검출한 선분 수(스크래치, 지름의 10% 이상, 3% 이하 끊김 허용)를 씁니다. 총 18차원입니다.

### 잡음 제거는 양날의 검

메디안 필터는 도넛을 드러내지만 가장자리 링을 지워 버립니다. 그래서 **잡음 제거 전후 각각** 특징을 뽑아 이어 붙입니다. $$(18 + 40) \times 2 = 116$$차원이 최종 표현이고, DET 곡선에서 두 특징 집합이 서로 다른 오류 모드를 보완함을 확인했습니다.

### 2단계 SVM 분류(WMFPR)

1단계는 패턴 유무의 이진 SVM, 2단계는 8개 패턴 유형의 일대일 SVM 28개 투표입니다. RBF 커널, LIBSVM + OpenMP. 1단계에서 Nonpattern 비용 1에 대해 Pattern 비용 $$c_{pattern} = 20$$이 DET 곡선에서 원점에 가장 가까웠고, 2단계에서는 클래스 불균형을 보정하려고 **표본 수에 반비례하는 비용**을 줍니다. 서포트 벡터는 결정 경계 근처라 **오라벨 가능성이 높고 예측을 좌우**하므로, 웹 인터페이스로 전문가가 서포트 벡터만 재검토해 라벨을 고치고 재학습하는 운영 절차를 두었습니다.

### 유사도 검색(WMSR)

1단계로 116차원 특징의 유클리드 거리로 top-$$n$$ 후보를 고르고, 2단계로 크기를 맞춘 맵의 2차원 정규화 상관계수(템플릿 매칭)를 전체 맵과 가장 두드러진 영역 각각에 계산해 $$\beta = 0.5$$로 섞어 재정렬합니다. 같은 패턴은 같은 원인일 가능성이 높아, 유사 웨이퍼 검색이 근본 원인 분석을 돕습니다.

## 3. 코드로 보기: Radon 특징의 회전 불변성과 분류력

6가지 합성 패턴(중심, 도넛, 가장자리 링, 가장자리 국소, 스크래치, 국소)을 만들어 Radon 행 평균·표준편차 40차원 특징을 뽑고, 같은 패턴을 회전했을 때의 특징 거리와 다른 클래스까지의 거리를 비교한 뒤, 무작위 회전·잡음을 더한 맵을 최근접 중심으로 분류합니다.

```python
import numpy as np
rng = np.random.default_rng(0)
N = 48
yy, xx = np.mgrid[0:N, 0:N]; cx = cy = (N - 1) / 2
r = np.sqrt((xx - cx) ** 2 + (yy - cy) ** 2); wafer = r <= N / 2 - 1
def make(kind, rot=0.0, noise=0.03):
    ang = np.arctan2(yy - cy, xx - cx) - rot
    xr, yr = r * np.cos(ang), r * np.sin(ang)
    if kind == "center": m = r < 7
    elif kind == "donut": m = (r > 8) & (r < 13)
    elif kind == "edge-ring": m = r > N / 2 - 5
    elif kind == "edge-local": m = (r > N / 2 - 7) & (np.abs(np.arctan2(yr, xr)) < 0.5)
    elif kind == "scratch": m = np.abs(yr - 0.6 * xr + 3) < 1.2
    else: m = (xr - 8) ** 2 + (yr + 6) ** 2 < 25              # local
    m = m | (rng.random((N, N)) < noise)
    return m & wafer

def radon(m, n_theta=36):                     # projections along n_theta directions by binning rotated coordinates
    G = []
    for th in np.linspace(0, np.pi, n_theta, endpoint=False):
        rho = (xx - cx) * np.cos(th) + (yy - cy) * np.sin(th)
        bins = np.round(rho + N / 2).astype(int).clip(0, N - 1)
        G.append(np.bincount(bins[m], minlength=N))
    G = np.array(G, float).T                  # rho x theta
    return (G - G.min()) / (G.max() - G.min() + 1e-9)
def features(m):
    G = radon(m)
    mu, sd = G.mean(1), G.std(1)              # row mean / std over theta -> rotation invariant
    idx = np.linspace(0, N - 1, 20)
    return np.concatenate([np.interp(idx, np.arange(N), mu), np.interp(idx, np.arange(N), sd)])

kinds = ["center", "donut", "edge-ring", "edge-local", "scratch", "local"]
print("rotation invariance: ||f(map) - f(rotated map)|| vs. distance to the nearest other class")
for k in kinds:
    f0 = features(make(k)); f_rot = features(make(k, rot=1.1))
    other = min(np.linalg.norm(f0 - features(make(o))) for o in kinds if o != k)
    print(f"  {k:<10} rotated: {np.linalg.norm(f0 - f_rot):.3f}   nearest other class: {other:.3f}")
# nearest-centroid classification on 40-dim Radon features
train = {k: np.mean([features(make(k, rot=rng.uniform(0, 2 * np.pi))) for _ in range(20)], 0) for k in kinds}
correct = total = 0
for k in kinds:
    for _ in range(30):
        f = features(make(k, rot=rng.uniform(0, 2 * np.pi), noise=0.05))
        pred = min(kinds, key=lambda c: np.linalg.norm(f - train[c])); correct += pred == k; total += 1
print(f"\nnearest-centroid accuracy on {total} rotated, noisier maps: {100*correct/total:.1f}%  (features: 40 numbers per map instead of {N*N} pixels)")
```

```text
rotation invariance: ||f(map) - f(rotated map)|| vs. distance to the nearest other class
  center     rotated: 0.050   nearest other class: 0.683
  donut      rotated: 0.051   nearest other class: 0.696
  edge-ring  rotated: 0.040   nearest other class: 0.923
  edge-local rotated: 0.409   nearest other class: 0.363
  scratch    rotated: 0.177   nearest other class: 0.385
  local      rotated: 0.409   nearest other class: 0.602

nearest-centroid accuracy on 180 rotated, noisier maps: 100.0%  (features: 40 numbers per map instead of 2304 pixels)
```

- 원형 대칭인 중심·도넛·링 패턴은 회전해도 특징이 거의 변하지 않고(0.04~0.05), 다른 클래스와의 거리(0.7~0.9)보다 훨씬 작습니다. 비대칭 패턴(가장자리 국소, 국소)은 격자 이산화와 잡음 때문에 회전 시 0.4까지 움직여 이웃 클래스 거리와 비슷해집니다. 완전한 불변은 아니지만 클래스 중심으로 비교하면 180장 모두 맞혔습니다.
- 2,304픽셀 대신 40개 숫자로 분류가 되는 것이 이 논문의 핵심 주장입니다. 실제 WM-811K에서는 여기에 기하 특징과 잡음 제거 전후를 더해 116차원입니다.

## 4. 실험

**WM-811K.** 46,293개 로트에서 수집한 811,457장(고유 맵 696,599장). 다이 수가 웨이퍼마다 크게 다릅니다. 전문가가 약 20%를 9개 유형(Center, Donut, Edge-local, Edge-ring, Local, Near-full, Random, Scratch, Nonpattern)으로 라벨링했습니다. 학습 54,356장, 테스트 118,595장이며 유형별 분포는 심하게 불균형합니다.

**패턴 인식.** 테스트 118,595장에서 1·2단계 합산 정확도 **94.63%**. 혼동은 주로 Local과 다른 유형 사이에서 생기는데, 그런 맵은 두 유형의 경계에 걸쳐 있어 사용자가 예측을 수용하는 경우가 많다고 보고합니다. 비교 대상인 딥러닝(Hinton의 기본 구현, 원본 맵 입력)과 공간 시그니처 분석(이미지 모멘트)보다 정확하며, 특징이 의미를 담고 있기 때문이라고 해석합니다.

**유사도 검색.** Center 쿼리로 Center 부분집합(3,462장)과 전체 811,457장을 검색한 결과가 비슷해 안정적이고, 라벨이 없는 80%의 맵에서도 유사 패턴을 찾아냅니다. 전체에서 top-100 검색은 **2.5초**(10만 장 기준 1.0초).

**계산 시간.** 특징 추출이 웨이퍼당 0.0737초로 가장 길고 SVM 예측은 0.0005초라, PC 한 대로 **하루 100만 장 이상** 처리할 수 있습니다. 학습+테스트 644초로, 딥러닝(학습이 느림)과 공간 시그니처(테스트가 느림)보다 빠릅니다. TSMC가 실제 분석 도구로 채택했습니다.

## 5. 해석

**1. 데이터셋 공개가 방법론보다 오래 남았습니다.** 특징 설계와 SVM은 2015년의 실용적 선택이지만, WM-811K는 이후 CNN, 오토인코더, 반지도 학습, [이상 탐지]({% post_url 2026-07-30-patchcore %}) 연구의 공통 벤치마크가 됐습니다. 라벨 20%, 심한 불균형, 다양한 다이 수라는 성질이 현실적인 난이도를 제공합니다.

**2. 불변성을 특징에 설계해 넣는 접근입니다.** Radon 투영의 $$\theta$$ 방향 통계로 회전을, 리샘플링으로 크기를 지웁니다. CNN이라면 회전 증강이나 극좌표 변환으로 같은 효과를 내야 하고, 다이 수가 다른 맵을 고정 크기로 리사이즈하는 전처리가 필요합니다. 특징 공학과 표현 학습의 차이를 보여 주는 좋은 사례입니다.

**3. 운영 관점의 디테일이 많습니다.** 잡음 제거 전후 특징을 모두 쓰는 것, 1단계 비용으로 FP/FN 트레이드오프를 조절하는 것, 서포트 벡터만 재라벨링하는 것, 특징을 팹 워크플로에서 미리 추출해 두는 것은 모두 "하루 100만 장"이라는 제약에서 나온 결정입니다. [불균형 데이터]({% post_url 2026-06-27-imbalanced-data %})에 대한 역빈도 비용 가중도 같은 맥락입니다.

**4. 한계도 분명합니다.** 다중 패턴 맵은 하나의 유형으로만 분류되고(Scratch + Edge-ring → Scratch), 새 패턴은 신뢰도 임계값으로만 다룹니다. 이후 연구가 다중 라벨 분류와 열린 집합 인식으로 확장한 지점입니다.

**5. 평가를 읽을 때 주의할 점.** 딥러닝 비교는 2015년 기준 기본 설정의 네트워크라 현재의 CNN과는 비교가 되지 않습니다(이후 CNN은 같은 데이터에서 더 높은 정확도를 보고합니다). 학습 집합은 "다양한 패턴을 포함하도록 선별"했으므로 무작위 분할이 아닙니다. 위 toy의 합성 패턴은 실제 맵보다 훨씬 깨끗하고 유형당 변동이 작습니다.

## 6. 정리

| 항목 | 내용 |
|---|---|
| 데이터 | WM-811K: 실제 팹 811,457장, 20% 라벨(9유형), 공개 |
| 특징 | Radon 행 평균·표준편차(40) + 기하·통계·Hough 선(18), 잡음 제거 전후 ×2 = 116차원, 회전·크기 불변 |
| 분류 | 1단계 패턴 유무 SVM(비용 20) → 2단계 8유형 일대일 SVM, 역빈도 비용 |
| 검색 | 특징 거리 top-n → 전체·두드러진 영역 상관 $$\beta = 0.5$$ 재정렬 |
| 결과 | 정확도 94.63%(118,595장), 웨이퍼당 0.074초, 81만 장 top-100 검색 2.5초 |
| 운영 | 서포트 벡터 재라벨링, TSMC 도구로 채택 |
