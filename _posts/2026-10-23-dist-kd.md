> [Knowledge distillation]({% post_url 2026-06-25-pytorch-training-toolkit %})의 기본은 학생의 softmax 출력을 교사의 출력에 KL divergence로 맞추는 것입니다. 당연히 교사가 좋을수록 학생도 좋아져야 할 것 같지만, 실제로는 **더 큰 교사나 더 강한 학습 전략으로 학습한 교사를 쓰면 vanilla KD가 KD 없이 학습한 것보다도 나빠지는** 경우가 있습니다. **DIST**(Knowledge Distillation from A Stronger Teacher, Huang, You et al., SenseTime·University of Sydney, NeurIPS 2022)는 그 원인을 "정확한 일치를 요구하는 KL"에서 찾고, 예측의 **상대적 관계**만 맞추는 Pearson 상관 손실로 바꿉니다. 코드 몇 줄의 변경으로 ImageNet ResNet-18에서 72.07%, Swin-T에서 82.3%를 냈습니다.

## 1. 문제: 강한 교사는 따라 하기 어렵다

논문은 "강한 교사"를 두 가지로 만듭니다.

- **더 큰 모델**: ResNet-34 → 50 → 101 → 152
- **더 강한 학습 전략**: 기본 전략 B1(SGD 100 epoch, crop + flip)에서 B2(RMSProp 450 epoch, label smoothing, EMA, RandAugment, random erasing)로. ResNet-18은 69.8%에서 73.4%, ResNet-50은 76.1%에서 78.5%로 오릅니다.

그리고 ResNet-18 학생에 vanilla KD를 걸어 보면 둘 다 문제가 생깁니다. 교사가 ResNet-50보다 커지면 학생 성능이 오히려 내려가고, B2 전략에서는 KD를 쓴 학생(72.6%)이 KD 없이 학습한 학생(73.4%)보다 **나쁩니다**.

따로 학습한 네 모델(R18B1, R18B2, R50B1, R50B2)의 예측을 KL로 비교하면 원인이 보입니다.

- ResNet-18은 전략을 바꿔도 출력이 크게 달라지지 않습니다. **표현력이 성능을 제한**하고 있어서, 교사와의 차이가 클수록 정확히 맞추기가 어렵습니다.
- 교사와 학생을 **강한 전략으로 학습할수록 둘의 차이가 커집니다**. KD 손실과 분류 손실이 더 크게 어긋나 학습을 방해합니다.

KL은 두 분포가 **정확히 같을 때만** 최소가 됩니다. 학생이 도저히 재현할 수 없는 출력을 정확히 재현하라고 요구하는 것은 과욕이라는 것이 이 논문의 진단입니다.

## 2. DIST: 관계만 맞추는 느슨한 일치

### Isotone 변환에 불변인 거리

추론 때 우리가 정말 쓰는 것은 교사의 확률값 자체가 아니라 **순위**, 즉 어떤 클래스를 더 선호하는지입니다. 그래서 거리 $$d$$에 순서를 보존하는(isotone) 변환 $$\varphi$$, $$\psi$$를 허용합니다.

$$
d(\varphi(a), \psi(b)) = d(a, b) \quad \forall a, b
$$

가장 단순한 선택이 양의 선형 변환입니다. $$d(m_1 a + n_1, m_2 b + n_2) = d(a, b)$$ ($$m_1 m_2 > 0$$). 스케일과 이동에 불변인 거리이고, 바로 **Pearson 거리**가 이 성질을 가집니다.

$$
d_p(u, v) = 1 - \rho_p(u, v),\qquad \rho_p(u, v) = \frac{\text{Cov}(u, v)}{\text{Std}(u)\,\text{Std}(v)} = \frac{\sum_i (u_i - \bar u)(v_i - \bar v)}{\sqrt{\sum_i (u_i - \bar u)^2 \sum_i (v_i - \bar v)^2}}
$$

### Inter-class 관계

인스턴스마다 교사와 학생의 예측 벡터(클래스 $$C$$개에 대한 확률)가 선형으로 상관되도록 합니다. 각 인스턴스에서 **클래스 사이의 관계**를 옮기는 것입니다.

$$
\mathcal{L}_{\text{inter}} = \frac{1}{B} \sum_{i=1}^B d_p\big(Y^{(s)}_{i,:},\ Y^{(t)}_{i,:}\big)
$$

### Intra-class 관계

예측 행렬 $$Y \in \mathbb{R}^{B \times C}$$를 **열 방향**으로도 봅니다. 한 클래스에 대한 여러 인스턴스의 점수는 그 클래스와의 유사도를 뜻합니다. 고양이, 개, 비행기 사진의 "고양이" 점수는 $$e > f > g$$여야 하고, 같은 고양이 사진끼리도 어느 것이 더 전형적인지라는 정보가 있습니다. 이 관계도 옮깁니다.

$$
\mathcal{L}_{\text{intra}} = \frac{1}{C} \sum_{j=1}^C d_p\big(Y^{(s)}_{:,j},\ Y^{(t)}_{:,j}\big)
$$

전체 손실은 분류 손실과 두 관계 손실의 합입니다.

$$
\mathcal{L}_{\text{tr}} = \alpha \mathcal{L}_{\text{cls}} + \beta \mathcal{L}_{\text{inter}} + \gamma \mathcal{L}_{\text{intra}}
$$

분류에서는 $$\alpha = 1$$, $$\beta = \gamma = 2$$, 검출과 분할에서는 모두 1입니다. 온도는 ImageNet에서 1, 과적합되기 쉬워 분포가 날카로운 CIFAR-100에서는 4를 씁니다. 출력에만 작용하므로 학습 비용은 vanilla KD와 거의 같고, 128차원 feature의 메모리 뱅크가 필요한 CRD(+260M FLOPs)나 feature 정렬용 합성곱이 필요한 SRRL, Review보다 훨씬 단순합니다.

## 3. 코드로 보기: 강한 교사는 KL로는 멀고 상관으로는 가깝다

16차원 입력, 10개 클래스의 합성 분류 문제에서 같은 구조의 교사를 기본 전략과 강한 전략(label smoothing 0.5)으로 학습하고, 작은 학생과의 불일치를 KL과 Pearson 상관으로 각각 잽니다.

```python
import torch, torch.nn as nn, torch.nn.functional as F

torch.manual_seed(0)
C, D = 10, 16                                              # 클래스 10개, 16차원 입력
W1, W2 = torch.randn(D, 64) / D ** 0.5, torch.randn(64, C) / 8   # 정답을 만드는 숨은 비선형 함수
def data(n):
    x = torch.randn(n, D)
    return x, (torch.tanh(x @ W1) @ W2 * 12 + torch.randn(n, C)).argmax(1)   # 경계 근처에는 라벨 노이즈
Xtr, ytr = data(3000); Xte, yte = data(20000)

def mlp(w, depth):
    layers, d = [], D
    for _ in range(depth): layers += [nn.Linear(d, w), nn.ReLU()]; d = w
    return nn.Sequential(*layers, nn.Linear(d, C))

def fit(net, loss_fn, epochs=150, lr=3e-3):
    opt = torch.optim.Adam(net.parameters(), lr, weight_decay=1e-4)
    for _ in range(epochs):
        for i in torch.randperm(len(Xtr)).split(128):
            loss = loss_fn(net(Xtr[i]), i); opt.zero_grad(); loss.backward(); opt.step()
    return (net(Xte).argmax(1) == yte).float().mean().item() * 100

def pearson(a, b):                                         # 행별 Pearson 상관
    a = a - a.mean(-1, keepdim=True); b = b - b.mean(-1, keepdim=True)
    return F.cosine_similarity(a, b, dim=-1).mean()

# 1) 같은 구조의 교사를 기본 전략(B1)과 강한 전략(B2: label smoothing)으로 학습하고, 작은 학생(CE만)과의 차이를 잰다
t_b1, t_b2, student = mlp(256, 3), mlp(256, 3), mlp(16, 1)
fit(t_b1, lambda z, i: F.cross_entropy(z, ytr[i]))
fit(t_b2, lambda z, i: F.cross_entropy(z, ytr[i], label_smoothing=0.5))
s_acc = fit(student, lambda z, i: F.cross_entropy(z, ytr[i]))
with torch.no_grad():
    ps = F.softmax(student(Xte), -1)
    for name, t in [("기본 전략 교사", t_b1), ("강한 전략 교사", t_b2)]:
        pt = F.softmax(t(Xte), -1)
        print(f"{name}: 정확도 {(pt.argmax(1) == yte).float().mean() * 100:.1f}% | 학생과의 KL {F.kl_div(ps.log(), pt, reduction='batchmean'):.3f} | Pearson 상관 {pearson(ps, pt):.3f} | top-1 일치율 {(pt.argmax(1) == ps.argmax(1)).float().mean():.2f}")
print(f"학생(16-wide, CE만): 정확도 {s_acc:.1f}%")

# 2) Pearson 거리는 예측을 선형 변환해도 변하지 않지만 KL은 변한다 (relaxed match)
a, b = torch.randn(5, C), torch.randn(5, C)
print(f"Pearson 거리: d(a, b) = {1 - pearson(a, b):.4f}, d(3a + 2, b) = {1 - pearson(3 * a + 2, b):.4f} | KL: {F.kl_div(F.log_softmax(a, -1), F.softmax(b, -1), reduction='batchmean'):.3f} → {F.kl_div(F.log_softmax(3 * a + 2, -1), F.softmax(b, -1), reduction='batchmean'):.3f}")

# 3) 강한 교사에게서 KD(KL)와 DIST로 학생을 학습해 비교한다 (5회 평균)
with torch.no_grad(): T_logits = t_b2(Xtr)
def kd(z, i, tau=4):
    return 0.1 * F.cross_entropy(z, ytr[i]) + 0.9 * tau ** 2 * F.kl_div(F.log_softmax(z / tau, -1), F.softmax(T_logits[i] / tau, -1), reduction="batchmean")
def dist(z, i, tau=4):                                     # inter-class(행별) + intra-class(열별) Pearson
    ys, yt = F.softmax(z / tau, -1), F.softmax(T_logits[i] / tau, -1)
    return F.cross_entropy(z, ytr[i]) + 2 * (1 - pearson(ys, yt)) + 2 * (1 - pearson(ys.T, yt.T))
for name, loss_fn in [("CE만", lambda z, i: F.cross_entropy(z, ytr[i])), ("KD(KL)", kd), ("DIST", dist)]:
    accs = [fit(mlp(16, 1), loss_fn) for _ in range(5)]
    print(f"학생 {name:7s}: 정확도 {sum(accs) / 5:.2f}%")
```

```text
기본 전략 교사: 정확도 76.3% | 학생과의 KL 0.344 | Pearson 상관 0.863 | top-1 일치율 0.83
강한 전략 교사: 정확도 75.9% | 학생과의 KL 3.672 | Pearson 상관 0.875 | top-1 일치율 0.81
학생(16-wide, CE만): 정확도 77.5%
Pearson 거리: d(a, b) = 0.8124, d(3a + 2, b) = 0.8124 | KL: 0.635 → 3.050
학생 CE만    : 정확도 77.66%
학생 KD(KL) : 정확도 77.55%
학생 DIST   : 정확도 78.26%
```

- 두 교사는 정확도와 학생과의 top-1 일치율이 거의 같은데, **KL로 잰 거리는 10배 넘게 차이** 납니다(0.344 대 3.672). label smoothing으로 출력이 평평해졌기 때문이고, 학생이 그 평평함까지 재현할 이유는 없습니다. 반면 **Pearson 상관은 둘 다 0.86~0.88**로, 순위 관계는 두 교사 모두 학생과 잘 맞습니다. 논문 Figure 2의 관찰 그대로입니다.
- Pearson 거리는 예측을 3배 하고 2를 더해도 변하지 않지만 KL은 다섯 배로 뜁니다. 이것이 "느슨한 일치"의 뜻입니다.
- 강한 교사에게서 배울 때 KL 기반 KD는 CE만 쓴 학생보다 낫지 않았고, DIST는 조금 나았습니다. 작은 합성 문제라 차이는 크지 않지만 방향은 논문과 같습니다.

## 4. 실험

### ImageNet 기본 설정

Torchvision의 ResNet-34, ResNet-50을 교사로, 전략 B1으로 학습했습니다.

| 학생 (교사) | 교사 | 학생 | KD | OFD | CRD | SRRL | Review | **DIST** |
|---|---|---|---|---|---|---|---|---|
| ResNet-18 (ResNet-34) Top-1 | 73.31 | 69.76 | 70.66 | 71.08 | 71.17 | 71.73 | 71.61 | **72.07** |
| MobileNet (ResNet-50) Top-1 | 76.16 | 70.13 | 70.68 | 71.25 | 71.37 | 72.49 | 72.56 | **73.24** |

출력만 쓰는 DIST가 중간 feature를 쓰는 정교한 방법들을 넘었습니다.

### 더 큰 교사

| 학생 | 교사 | 교사 정확도 | KD | DIST |
|---|---|---|---|---|
| ResNet-18 | ResNet-34 | 73.31 | 71.21 | 72.07 (+0.86) |
| ResNet-18 | ResNet-50 | 76.13 | 71.35 | 72.12 (+0.77) |
| ResNet-18 | ResNet-101 | 77.37 | 71.09 | 72.08 (+0.99) |
| ResNet-18 | ResNet-152 | 78.31 | 71.12 | 72.24 (+1.12) |

KD는 ResNet-50 교사에서 정점을 찍고 더 큰 교사에서 내려가지만, DIST는 ResNet-101에서 잠시 주춤할 뿐 대체로 오르고 KD와의 차이도 벌어집니다.

### 더 강한 전략

B2 전략(Swin-T는 B3)으로 학생을 학습하고, 80.1%짜리 ResNet-50(TIMM)과 ImageNet-22K 사전학습 Swin-L(86.3%)을 교사로 썼습니다.

| 교사 | 학생 | 학생 단독 | KD | RKD | SRRL | **DIST** |
|---|---|---|---|---|---|---|
| ResNet-50 (80.1) | ResNet-18 | 73.4 | 72.6 | 72.9 | 71.2 | **74.5** |
| ResNet-50 | ResNet-34 | 76.8 | 77.2 | 76.6 | 76.7 | **77.8** |
| ResNet-50 | MobileNetV2 | 73.6 | 71.7 | 73.1 | 69.2 | **74.4** |
| ResNet-50 | EfficientNet-B0 | 78.0 | 77.4 | 77.5 | 77.3 | **78.6** |
| Swin-L (86.3) | ResNet-50 | 78.5 | 80.0 | 78.9 | 78.6 | **80.2** |
| Swin-L | Swin-T | 81.3 | 81.5 | 81.2 | 81.5 | **82.3** |

KD, RKD, SRRL은 학생이 작거나(ResNet-18, MobileNetV2) 구조가 다를 때(ResNet-50과 Swin-L) 단독 학습보다 못한 경우가 많습니다. 중간 feature를 재현하는 것이 예측을 재현하는 것보다 더 어렵기 때문으로 봅니다. DIST는 모든 조합에서 가장 좋았고, Swin-L 교사로 ResNet-50을 1.7%, Swin-T를 1.0% 올렸습니다.

### 다른 작업

- **CIFAR-100**: 같은 구조(WRN, ResNet)와 다른 구조(ResNet-50→MobileNetV2, ResNet-32x4→ShuffleNet) 모두에서 feature 기반 방법(CRD 등)을 넘었습니다.
- **COCO 검출**: 분류 head의 최종 예측에 DIST를 더하면 Faster R-CNN R50이 38.4 → 40.4 AP(KD는 39.7). FPN feature의 MSE(mimic)를 더하면 41.8로 검출 전용 KD(FKD 41.5, CWD 41.7)를 넘습니다. RetinaNet도 같은 경향입니다.
- **Cityscapes 분할**: 분류 head 예측만으로 DeepLabV3-R18 74.21 → 77.10 mIoU, PSPNet-R18 72.55 → 76.31. 최신 CIRKD보다 각각 0.7, 1.6 높습니다.

### Ablation

| 방법 | Inter | Intra | ResNet-18 정확도 |
|---|---|---|---|
| KD | - | - | 71.21 |
| DIST (KL로 관계) | - | ✓ | 70.61 |
| DIST (KL로 관계) | ✓ | ✓ | 71.62 |
| DIST | ✓ | - | 71.63 |
| DIST | - | ✓ | 71.55 |
| **DIST** | ✓ | ✓ | **72.07** |

- inter와 intra 각각이 KD보다 낫고, 합치면 더 좋습니다.
- intra-class 관계를 KL로 맞추는 것은 Pearson보다 훨씬 못합니다(70.61 대 71.55). 열 방향 분포는 평균과 분산이 제각각이라 스케일·이동 불변이 중요합니다.
- 분류 손실 없이 KD 손실만으로 학습하면 KD는 68.12%로 단독 학습(69.76%)보다 못하지만 DIST는 70.65%로 **라벨 없이도 단독 학습을 넘습니다**. 전달하는 신호가 그만큼 알차다는 뜻입니다.

## 5. 해석

**1. 진단이 처방보다 중요합니다.** "교사가 좋을수록 학생도 좋다"는 통념을 두 축(크기, 전략)으로 체계적으로 깨뜨린 Figure 1과, 그 원인을 예측 불일치로 좁힌 Figure 2가 이 논문의 핵심입니다. 위 예제에서 label smoothing 하나로 KL이 10배 뛰면서 순위는 그대로인 것을 보면, 정확한 일치 요구가 왜 해로운지 분명해집니다.

**2. 처방은 "무엇을 전달할 것인가"의 재정의입니다.** KL은 확률값을, Pearson은 순위와 상대 간격을 전달합니다. 학생은 교사의 확신 정도를 흉내 낼 필요가 없고, 어떤 클래스가 더 그럴듯한지와 어떤 인스턴스가 더 전형적인지만 배우면 됩니다. 이것이 cosine 유사도나 다른 isotone 거리로도 확장될 수 있다고 논문은 열어 둡니다.

**3. intra-class 관계는 작지만 새로운 관점입니다.** 기존 관계 기반 KD(RKD 등)는 feature 공간에서 인스턴스 간 관계를 옮겼습니다. DIST는 예측 행렬의 열, 즉 "한 클래스에 대한 배치 안 인스턴스들의 점수 순위"를 옮깁니다. 구현은 행렬을 전치하는 한 줄입니다.

**4. 단순함이 곧 범용성입니다.** feature 정렬 층도, 메모리 뱅크도 없이 출력에만 작용하므로 CNN, Transformer, 검출, 분할 어디에나 그대로 붙습니다. [Auto-KD]({% post_url 2026-10-23-auto-kd %})는 이 Pearson 거리를 logit 증류의 탐색 후보로 포함했고, [Online Speculative Decoding]({% post_url 2026-10-23-online-speculative-decoding %})처럼 "어떤 증류 거리가 좋은가"가 작업마다 다르다는 관찰과도 이어집니다.

**5. 평가를 읽을 때 주의할 점.** 강한 전략 실험의 baseline KD, RKD, SRRL은 저자들이 재현한 값이고, 각 방법의 하이퍼파라미터가 B2 전략에 맞게 재조정되었는지는 불분명합니다. 검출에서 DIST 단독은 FKD, CWD에 못 미치고 mimic을 더해야 넘습니다. 위 toy의 정확도 차이는 작아서 방향만 참고해야 합니다.

## 6. 정리

| 항목 | 내용 |
|---|---|
| 문제 | 더 큰 교사, 더 강한 학습 전략의 교사에서 vanilla KD가 단독 학습보다 나빠짐 |
| 원인 | 강한 교사와 학생의 예측 불일치가 커서 KL의 정확한 일치 요구가 학습을 방해 |
| 방법 | KL 대신 Pearson 거리(스케일·이동 불변)로 inter-class(행별) + intra-class(열별) 관계만 일치 |
| 손실 | $$\alpha \mathcal{L}_{\text{cls}} + \beta \mathcal{L}_{\text{inter}} + \gamma \mathcal{L}_{\text{intra}}$$, 분류는 $$(1, 2, 2)$$ |
| 결과 | ImageNet ResNet-18 72.07%, Swin-T 82.3%(단독 학습 +1.0%, KD +0.8%), COCO·Cityscapes에서도 최고 수준 |
| 비용 | 출력에만 작용해 vanilla KD와 거의 같음 |
