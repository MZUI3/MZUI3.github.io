> [이진 신경망]({% post_url 2026-06-17-binary-neural-networks %})과 [양자화]({% post_url 2026-06-15-pruning-and-quantization %})에서 활성 함수를 계단 함수로 바꾸면 손실은 **거의 모든 곳에서 기울기가 0인 조각별 상수 함수**가 되어 역전파가 작동하지 않습니다. 실무의 해법은 Bengio 등이 이름 붙인 **straight-through estimator(STE)**입니다. 순전파는 계단 함수로 하고, 역전파에서만 그 도함수를 항등·ReLU·clipped ReLU 같은 매끄러운 함수의 도함수로 바꿔치기합니다. 그렇게 얻은 "기울기"는 손실의 기울기가 아니고, 일반적으로 어떤 함수의 기울기도 아닙니다. 그런데 왜 그 음의 방향으로 가면 손실이 줄어드는가. **Understanding Straight-Through Estimator**(Yin, Lyu, Zhang, Osher, Qi, Xin, UCLA·UCI·Qualcomm, ICLR 2019)는 이 질문에 처음으로 이론적 답을 줍니다. 답은 "STE를 **제대로 고르면**"이라는 조건부이고, 잘못 고른 STE(항등)는 좋은 극솟값 근처에서 학습을 불안정하게 만든다는 것까지 증명하고 실험으로 확인합니다.

## 1. 설정: 이진 활성 2층 네트워크

입력 $$Z \in \mathbb{R}^{m \times n}$$(원소가 i.i.d. $$\mathcal{N}(0,1)$$), 첫 층 가중치 $$w \in \mathbb{R}^n$$(모든 행에 공유되므로 합성곱 필터에 해당), 둘째 층 $$v \in \mathbb{R}^m$$에 대해

$$
y(Z, v, w) = v^\top \sigma(Zw), \qquad \sigma(x) = \mathbb{1}_{\{x > 0\}}
$$

라벨은 참 파라미터 $$(v^*, w^*)$$, $$\lVert w^* \rVert = 1$$로 생성되고, 모집단 손실 $$f(v, w) = \mathbb{E}_Z[\tfrac{1}{2}(y - y^*)^2]$$을 최소화합니다. 가우시안 가정 덕에 $$f$$와 $$\nabla f$$가 닫힌 형태로 나오고, $$w$$와 $$w^*$$의 각도 $$\theta(w, w^*)$$만으로 표현됩니다. 지형을 분석하면(Proposition 1) 전역 최솟값 $$\{v = v^*, \theta = 0\}$$ 외에, $$(\mathbb{1}^\top v^*)^2 < \frac{m+1}{2}\lVert v^* \rVert^2$$일 때 **안장점**과 $$\theta = \pi$$에 **가짜 극솟값** $$v = (I + \mathbb{1}\mathbb{1}^\top)^{-1}(\mathbb{1}\mathbb{1}^\top - I)v^*$$가 존재합니다.

### 거친 기울기

표준 연쇄 법칙의 $$\partial \ell / \partial w = Z^\top \big(\sigma'(Zw) \odot v\big)\,\big(v^\top \sigma(Zw) - y^*\big)$$에서 $$\sigma'$$은 거의 모든 곳에서 0입니다. STE는 $$\sigma'$$를 어떤 (부)미분 가능 함수 $$\mu$$의 도함수 $$\mu'$$로 바꿉니다.

$$
g_\mu(v, w; Z) = Z^\top\big[\mu'(Zw) \odot v\big]\big(v^\top \sigma(Zw) - y^*(Z)\big)
$$

이것이 **거친 기울기**(coarse gradient)이고, 학습은 $$v$$는 진짜 기대 기울기로, $$w$$는 기대 거친 기울기 $$\mathbb{E}_Z[g_\mu]$$로 내려가는 Algorithm 1입니다. 세 STE를 봅니다. 항등 $$\mu(x) = x$$(퍼셉트론과 Hinton의 제안), ReLU $$\mu'(x) = \mathbb{1}_{\{x>0\}}$$, clipped ReLU $$\mu'(x) = \mathbb{1}_{\{0 < x < 1\}}$$(Hubara 등의 saturated STE, HWGQ).

## 2. 주요 결과

**Theorem 1 (수렴).** ReLU 또는 clipped ReLU STE를 쓰고 $$\lVert w_t \rVert \ge c_w$$이면, 충분히 작은 학습률에서 임의의 초기값으로부터 $$f(v_t, w_t)$$는 **단조 감소**하고 $$(v_t, w_t)$$는 안장점이나 (국소) 최솟값으로 수렴합니다. 반면 $$\mathbb{1}^\top v^* \ne 0$$, $$m > 1$$이면 항등 STE는 $$\theta = \pi$$의 극솟값 근처에서 하강·수렴 성질이 성립하지 않습니다.

증명의 뼈대는 두 가지입니다. 첫째, 기대 거친 기울기와 진짜 편기울기의 **내적이 음이 아닙니다**(Lemma 5, 7, 10).

$$
\Big\langle \mathbb{E}_Z[g_{\text{relu}}], \frac{\partial f}{\partial w} \Big\rangle = \frac{\sin\theta}{2(\sqrt{2\pi})^3 \lVert w \rVert}(v^\top v^*)^2 \ge 0
$$

둘째, 거친 기울기의 크기가 진짜 기울기 항들로 **상계**됩니다(식 12). 이 두 가지와 $$\nabla f$$의 립시츠 연속성(Lemma 3)을 합치면 표준 하강 보조정리가 작동해 에너지가 단조 감소합니다(식 13). ReLU와 clipped ReLU의 거친 기울기는 **임계점에서만 0이 되므로**(Lemma 6, 8) 수렴점은 반드시 임계점입니다.

**Lemma 9 (항등 STE의 문제).** 항등 STE의 기대 거친 기울기는 닫힌 형태로

$$
\mathbb{E}_Z[g_{\text{id}}] = \frac{1}{\sqrt{2\pi}}\Big(\lVert v \rVert^2 \frac{w}{\lVert w \rVert} - (v^\top v^*) w^*\Big)
$$

이고, 가짜 극솟값($$\theta = \pi$$)에서 그 크기는 $$\frac{2(m-1)}{\sqrt{2\pi}(m+1)^2}(\mathbb{1}^\top v^*)^2 > 0$$으로 **사라지지 않습니다**. 진짜 기울기와의 내적은 양수라(Lemma 10) 처음에는 극솟값 쪽으로 가지만, 가까워질수록 상계(식 16)가 무한대로 발산해 하강 성질이 깨지고 손실이 다시 오릅니다. 이것이 **불안정성**입니다. 저자들은 좋은 STE의 조건을 "단조성"에 더해 **양자화된 활성과 극값에서 일치하는 것**으로 요약합니다. clipped ReLU가 그렇습니다.

## 3. 코드로 보기: 세 STE의 거친 기울기

$$m = 5$$, $$n = 8$$의 같은 네트워크에서 (1) 여러 각도에서 기대 거친 기울기와 진짜 모집단 기울기(유한차분)의 코사인을 재고, (2) 가짜 극솟값에 세 STE를 놓고 거친 기울기의 크기와 150스텝 후 손실을 봅니다.

```python
import numpy as np
rng = np.random.default_rng(0)
m, n = 5, 8                                  # two-linear-layer net: y = v^T sigma(Z w), sigma = 1{x>0}, Z ~ N(0,1)^{m x n}
v_star = np.array([1.0, 0.8, 0.6, 0.4, 0.2]); w_star = rng.standard_normal(n); w_star /= np.linalg.norm(w_star)
def sample(B): return rng.standard_normal((B, m, n))
def coarse_grad(v, w, Z, ste):               # coarse gradient w.r.t. (w, v) with a chosen STE for sigma'
    pre = Z @ w; act = (pre > 0).astype(float)
    err = act @ v - ((Z @ w_star) > 0).astype(float) @ v_star
    if ste == "identity": mu = np.ones_like(pre)
    elif ste == "relu": mu = (pre > 0).astype(float)
    else: mu = ((pre > 0) & (pre < 1)).astype(float)                   # clipped ReLU
    return np.einsum("b,bm,bmn->n", err, mu * v, Z) / len(Z), np.einsum("b,bm->m", err, act) / len(Z)
def pop_grad_w(v, w):                        # true population gradient of f w.r.t. w (Lemma 2 of the paper)
    wn = w / np.linalg.norm(w); proj = w_star - (wn @ w_star) * wn
    return -(v @ v_star) / (2 * np.pi * np.linalg.norm(w)) * proj / (np.linalg.norm(proj) + 1e-12)
def pop_loss(v, w, Z): return 0.5 * np.mean((((Z @ w) > 0) @ v - ((Z @ w_star) > 0) @ v_star) ** 2)

print("(1) cosine between the expected coarse gradient and the true population gradient w.r.t. w (positive = descent-compatible)")
print("angle(w,w*)   identity   relu   clipped")
for theta in (0.3, 1.0, 2.0, 2.9):
    u = rng.standard_normal(n); u -= (u @ w_star) * w_star; u /= np.linalg.norm(u)
    w = np.cos(theta) * w_star + np.sin(theta) * u; v = v_star + 0.3 * rng.standard_normal(m)
    Z = sample(200000); g = pop_grad_w(v, w)
    cos = []
    for s in ("identity", "relu", "clipped"):
        cg = coarse_grad(v, w, Z, s)[0]; cos.append(float(cg @ g / (np.linalg.norm(cg) * np.linalg.norm(g) + 1e-12)))
    print(f"   {theta:4.1f}       {cos[0]:6.3f}   {cos[1]:6.3f}   {cos[2]:6.3f}")

# (2) the spurious local minimiser of the paper: theta = pi and v = (I + 11^T)^-1 (11^T - I) v*
ones = np.ones((m, m)); v_sp = np.linalg.solve(np.eye(m) + ones, (ones - np.eye(m)) @ v_star); w_sp = -w_star
Z = sample(400000)
print(f"\n(2) at the spurious local minimiser (loss {pop_loss(v_sp, w_sp, Z):.3f}; the global minimum has loss 0):")
print("STE        ||E[coarse grad w]||   loss after 150 coarse-GD steps from there (lr 0.02)")
for ste in ("identity", "relu", "clipped"):
    gw, gv = coarse_grad(v_sp, w_sp, Z, ste); norm = np.linalg.norm(gw)
    v, w = v_sp.copy(), w_sp.copy()
    for t in range(150):
        gw, gv = coarse_grad(v, w, sample(20000), ste); w -= 0.02 * gw; v -= 0.02 * gv
    print(f"{ste:<9}  {norm:20.4f}   {pop_loss(v, w, Z):.3f}   (angle to w* now {np.degrees(np.arccos(np.clip(w @ w_star / np.linalg.norm(w), -1, 1))):.0f} deg)")
print("-> ReLU/clipped-ReLU STEs vanish at the critical point and stay; the identity STE's coarse gradient does not vanish there,")
print("   so the iterates are pushed away: the instability the paper proves (Lemma 9) and observes on ResNet-20")
```

- (1) 세 STE 모두 모든 각도에서 코사인이 양수입니다. Lemma 5, 7, 10의 "양의 상관"이 그대로 보이고, 항등 STE도 일반 위치에서는 하강 방향을 줍니다. 각도가 $$\pi$$에 가까워질수록 코사인이 작아지는 것은 내적의 $$\sin\theta$$ 인자 때문입니다.
- (2) 가짜 극솟값(손실 0.753)에서 ReLU와 clipped ReLU의 거친 기울기는 0.005, 0.003으로 사실상 0이고 150스텝 뒤에도 그 자리에 머뭅니다(임계점에 수렴). 항등 STE의 거친 기울기는 0.80으로 **사라지지 않고**, 150스텝 뒤 손실이 0.137로 바뀌며 각도가 8°까지 돌아갑니다. Lemma 9의 현상입니다. 이 toy에서는 밀려난 곳이 우연히 전역 최솟값 쪽이지만, 논문이 말하는 요점은 방향이 아니라 **항등 STE는 극솟값에 머물 수 없다**는 것이고, 깊은 네트워크에서는 그것이 좋은 극솟값에서 튕겨 나가는 결과로 나타납니다.

## 4. 실험

MNIST의 LeNet-5, CIFAR-10의 VGG-11과 ResNet-20에서 2비트·4비트 양자화 ReLU(HWGQ 방식, 해상도 $$\alpha$$는 Lloyd 알고리즘으로 사전 계산)로 세 STE를 비교합니다. 가중치는 float이고 전정밀 모델로 초기화합니다.

| 네트워크 | 비트 | 항등 | ReLU | clipped ReLU |
|---|---|---|---|---|
| LeNet-5 | 2 | 2.6e-2 / 98.49 | 5.1e-3 / 99.24 | 5.4e-3 / 99.23 |
| LeNet-5 | 4 | 6.0e-3 / 98.98 | 9.0e-4 / 99.32 | 8.8e-4 / 99.24 |
| VGG-11 | 2 | 0.19 / 86.58 | 0.10 / 88.69 | 0.02 / 90.92 |
| VGG-11 | 4 | 3.1e-2 / 90.19 | 1.5e-3 / 92.01 | 1.3e-3 / 92.08 |
| ResNet-20 | 2 | 1.56 / 46.52 | 1.50 / 48.05 | 0.24 / 88.39 |
| ResNet-20 | 4 | 1.38 / 54.16 | 0.25 / 86.59 | 0.04 / 91.24 |

(학습 손실 / 검증 정확도 %) clipped ReLU가 전체적으로 최고이고 ReLU, 항등 순입니다. 얕은 LeNet-5에서는 ReLU가 clipped ReLU와 대등한데, 이론이 다룬 얕은 2층 네트워크에서 ReLU가 좋은 STE라는 결과와 맞습니다. 깊은 ResNet-20에서 항등 STE는 54%, 2비트 ReLU STE는 48%로 무너집니다.

**불안정성 재현(4.2절).** ResNet-20 4비트에서 ReLU·clipped ReLU STE가 찾은 좋은 극솟값(86.59%, 91.24%)에서 **항등 STE로** 학습을 시작합니다. 손실 지형은 STE와 무관하므로 안정적이라면 머물러야 합니다. 학습률 $$10^{-5}$$라는 아주 작은 값으로도 20에폭 안에 학습 손실과 검증 오차가 크게 오르고, 이후 정상 스케줄로 200에폭을 더 돌려도 훨씬 나쁜 극솟값에 끝납니다. 항등 STE의 거친 기울기가 좋은 극솟값에서 0이 아니기 때문이고(Lemma 9), 2비트 ResNet-20에서 ReLU STE의 부진도 같은 이유로 더 느리게 발산합니다.

## 5. 해석

**1. "왜 되는가"에 대한 첫 증명입니다.** STE는 2013년 이후 모든 양자화 학습의 기본 도구였지만 정당화는 경험뿐이었습니다. 이 논문은 거친 기울기가 기울기가 아님을 인정한 채로, **하강 방향**이라는 더 약하지만 충분한 성질을 증명합니다. 퍼셉트론 수렴 정리와 Convertron의 결과를 2개 학습 층으로 확장한 것이기도 합니다.

**2. "어떤 STE인가"에 실용적 답을 줍니다.** 좋은 STE의 조건은 단조성과 **양자화 함수와 극값에서의 일치**입니다. 순전파의 계단 함수가 포화하는 구간에서 역전파도 0이어야 한다는 뜻이고, clipped ReLU(saturated STE)가 이후 PACT, LSQ 등 학습 가능 클리핑 방법의 표준이 된 것과 일치합니다. [BNN]({% post_url 2026-06-17-binary-neural-networks %})의 $$\mathbb{1}_{|x| \le 1}$$이 경험적으로 선택된 이유를 설명합니다.

**3. 불안정성 실험의 설계가 설득력 있습니다.** 좋은 극솟값에 **다른 STE로** 학습을 시작해 떠나는지 보는 것은, 손실 지형이 STE와 무관하다는 점을 이용한 깔끔한 반증 실험입니다. "수렴하지 않는다"를 보이는 가장 직접적인 방법이고, 위 toy의 (2)도 같은 설계입니다.

**4. 한계는 모델의 단순함입니다.** 2층, 가우시안 입력, 이진 활성, 모집단 손실(무한 표본)입니다. Remark 1은 유한 표본에서는 거친 스케일에서만 하강하고 표본이 늘수록 단조성이 생긴다고 설명하며, 이것이 "STE가 대규모 데이터에서 잘 되는" 이유라고 봅니다. 다비트 양자화, 가중치 양자화, 배치 정규화가 있는 깊은 네트워크로의 일반화는 열려 있습니다.

**5. 평가를 읽을 때 주의할 점.** 실험은 가중치를 float로 두고 활성만 양자화했으며, 양자화 방식은 균일 HWGQ 하나입니다. 이론의 결론(ReLU가 좋은 STE)과 실험(깊은 망에서는 clipped ReLU)이 다른 지점은 저자들도 인정하는 이론의 범위 밖입니다. 위 toy는 $$m = 5$$의 작은 설정이고, 유한차분으로 구한 진짜 기울기와 2만 표본의 기대 거친 기울기를 쓰므로 수치가 정확한 닫힌 형태는 아닙니다.

| 모델 | $$v^\top \mathbb{1}_{\{Zw > 0\}}$$, 가우시안 $$Z$$, 모집단 손실, 지형에 안장점과 $$\theta = \pi$$ 가짜 극솟값 |
| 결과 1 | ReLU·clipped ReLU STE: 기대 거친 기울기가 진짜 기울기와 양의 상관, 단조 감소, 임계점에 수렴 |
| 결과 2 | 항등 STE: 가짜 극솟값에서 거친 기울기가 0이 아니어서 불안정 |
| 실험 | CIFAR-10 ResNet-20 4비트: clipped 91.24%, ReLU 86.59%, 항등 54.16%, 좋은 극솟값에서 항등 STE로 시작하면 튕겨 나감 |
| 교훈 | 좋은 STE = 단조 + 양자화 함수와 극값에서 일치(포화 구간에서 0) |
