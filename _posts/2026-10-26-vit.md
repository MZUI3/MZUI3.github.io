> [Transformer]({% post_url 2026-06-10-attention-is-all-you-need %})는 NLP에서 "대규모 사전학습 후 미세조정"의 표준이 됐고 1,000억 파라미터까지 성능이 포화하지 않았습니다. 비전에서는 attention을 CNN에 섞거나 CNN의 일부를 대체하는 시도가 있었지만, 특수한 attention 패턴 때문에 가속기에서 효율적으로 확장되지 못했고 대규모 인식에서는 여전히 ResNet 계열이 최고였습니다. **ViT**(Google Brain, ICLR 2021)는 가장 적은 수정으로 표준 Transformer를 이미지에 적용합니다. 이미지를 16×16 패치로 자르고 각 패치를 선형 임베딩해 **단어처럼** 넣는 것이 전부입니다. 결과는 조건부입니다. ImageNet 130만 장으로 학습하면 같은 크기 ResNet보다 몇 %p 낮지만, 1,400만~3억 장으로 사전학습하면 최고 CNN을 넘고 학습 계산은 훨씬 적습니다. **대규모 학습이 귀납 편향을 이긴다**는 것이 이 논문의 한 문장 요약입니다.

## 1. 방법

### 패치 열

이미지 $$x \in \mathbb{R}^{H \times W \times C}$$를 $$P \times P$$ 패치 $$N = HW/P^2$$개로 펼쳐 $$x_p \in \mathbb{R}^{N \times (P^2 C)}$$를 만들고, 학습 가능한 선형 투영 $$E \in \mathbb{R}^{(P^2 C) \times D}$$로 $$D$$차원에 매핑합니다. BERT의 [class] 토큰처럼 학습 가능한 임베딩 $$x_{\text{class}}$$를 앞에 붙이고, 그 출력 $$z_L^0$$이 이미지 표현이 됩니다. 위치 임베딩은 **학습 가능한 1D** $$E_{pos} \in \mathbb{R}^{(N+1) \times D}$$입니다(2D 인식 변형은 이득이 없었음).

$$
z_0 = [x_{\text{class}};\, x_p^1 E;\, \dots;\, x_p^N E] + E_{pos}, \qquad
z'_\ell = \text{MSA}(\text{LN}(z_{\ell-1})) + z_{\ell-1}, \qquad
z_\ell = \text{MLP}(\text{LN}(z'_\ell)) + z'_\ell
$$

인코더는 pre-LN의 표준 Transformer이고, MLP는 GELU 2층입니다. 분류 헤드는 사전학습 때 은닉층 하나의 MLP, 미세조정 때 선형층 하나입니다. 변형은 BERT를 따라 Base(12층, D=768, 86M), Large(24층, 1024, 307M), Huge(32층, 1280, 632M)이고 ViT-L/16은 Large에 패치 16을 뜻합니다. 열 길이가 패치 크기의 제곱에 반비례하므로 패치가 작을수록 비쌉니다.

### 귀납 편향

CNN은 지역성, 2D 이웃 구조, 이동 등변성이 모든 층에 내장되어 있습니다. ViT에서는 MLP만 지역적·이동 등변이고 self-attention은 전역입니다. 2D 구조는 **패치를 자를 때**와 **해상도를 바꿔 위치 임베딩을 보간할 때** 두 곳에서만 쓰이고, 위치 임베딩은 초기화 시 2D 위치 정보를 전혀 담지 않아 패치 간 공간 관계를 처음부터 배워야 합니다. 하이브리드 변형은 ResNet 특징 맵의 1×1 "패치"를 입력으로 씁니다.

### 고해상도 미세조정

사전학습보다 높은 해상도로 미세조정하면 대체로 좋습니다. 패치 크기를 유지하면 열이 길어지고, 사전학습된 위치 임베딩을 원래 이미지에서의 위치에 따라 **2D 보간**합니다. 이것이 2D 구조를 수동으로 넣는 유일한 지점입니다. 학습은 Adam(β₂=0.999), 배치 4096, 가중치 감쇠 0.1, 선형 워밍업·감쇠이고, 미세조정은 SGD 모멘텀, 배치 512, ImageNet은 512(L/16)·518(H/14) 해상도에 Polyak 평균을 씁니다.

## 2. 코드로 보기: 비용 구조와 위치 임베딩 보간

해상도와 패치 크기에 따른 토큰 수와 attention 층 비용을 세고, 14×14 격자의 2D 구조를 가진 위치 임베딩을 24×24로 bicubic 보간했을 때 같은 행끼리의 유사도가 유지되는지, 그리고 펼친 패치의 선형 투영이 stride-16 합성곱과 같은지 확인합니다.

```python
import torch, torch.nn.functional as F
torch.manual_seed(0)
print("sequence length N = HW/P^2 and the cost of one self-attention layer (D = 768)")
print("resolution  patch   N     N^2*D (attention)   4*N*D^2 (projections)")
for res, P in [(224, 16), (224, 32), (384, 16), (224, 14), (512, 16)]:
    N = (res // P) ** 2; D = 768
    print(f"{res:>8}    {P:>3}   {N:>5}   {N*N*D/1e9:9.2f} GFLOP        {4*N*D*D/1e9:7.2f} GFLOP")

# fine-tuning at a higher resolution: 2-D interpolation of the learned position embeddings
grid = 14; D = 64
yy, xx = torch.meshgrid(torch.arange(grid).float(), torch.arange(grid).float(), indexing="ij")
freqs = torch.arange(1, D // 4 + 1).float()
pos = torch.cat([torch.sin(yy[..., None] / grid * freqs), torch.cos(yy[..., None] / grid * freqs),
                 torch.sin(xx[..., None] / grid * freqs), torch.cos(xx[..., None] / grid * freqs)], -1)   # a "learned" 14x14 table with 2-D structure
sim = lambda p: F.normalize(p.reshape(-1, D), dim=1) @ F.normalize(p.reshape(-1, D), dim=1).T
new = F.interpolate(pos.permute(2, 0, 1)[None], size=(24, 24), mode="bicubic", align_corners=False)[0].permute(1, 2, 0)
s14, s24 = sim(pos), sim(new)
def row_col_structure(s, g):
    idx = torch.arange(g * g); r, c = idx // g, idx % g
    same_row = s[(r[:, None] == r[None]) & (c[:, None] != c[None])].mean()
    other = s[(r[:, None] != r[None]) & (c[:, None] != c[None])].mean()
    return same_row.item(), other.item()
print()
print(f"position-embedding similarity, 14x14 table: same row {row_col_structure(s14,14)[0]:.3f} vs different row and column {row_col_structure(s14,14)[1]:.3f}")
print(f"after bicubic interpolation to 24x24:       same row {row_col_structure(s24,24)[0]:.3f} vs different row and column {row_col_structure(s24,24)[1]:.3f}")
print("-> the 2-D neighbourhood structure survives the resize, the only place where ViT injects a 2-D inductive bias")

# patch embedding = one big-stride convolution
img = torch.randn(1, 3, 224, 224); E = torch.randn(768, 3, 16, 16)
patches = F.unfold(img, 16, stride=16).transpose(1, 2) @ E.reshape(768, -1).T
conv = F.conv2d(img, E, stride=16).flatten(2).transpose(1, 2)
print(f"\nlinear projection of flattened 16x16 patches == stride-16 conv: {torch.allclose(patches, conv, atol=1e-3)}, tokens {patches.shape[1]} x {patches.shape[2]}")
```

```text
sequence length N = HW/P^2 and the cost of one self-attention layer (D = 768)
resolution  patch   N     N^2*D (attention)   4*N*D^2 (projections)
     224     16     196        0.03 GFLOP           0.46 GFLOP
     224     32      49        0.00 GFLOP           0.12 GFLOP
     384     16     576        0.25 GFLOP           1.36 GFLOP
     224     14     256        0.05 GFLOP           0.60 GFLOP
     512     16    1024        0.81 GFLOP           2.42 GFLOP

position-embedding similarity, 14x14 table: same row 0.547 vs different row and column 0.094
after bicubic interpolation to 24x24:       same row 0.560 vs different row and column 0.120
-> the 2-D neighbourhood structure survives the resize, the only place where ViT injects a 2-D inductive bias

linear projection of flattened 16x16 patches == stride-16 conv: True, tokens 196 x 768
```

- 224×224, 패치 16에서는 토큰 196개뿐이라 attention 자체(N²D)보다 투영(4ND²)이 15배 비쌉니다. ViT가 "표준 Transformer를 그대로" 쓸 수 있었던 이유 중 하나이고, 토큰 수가 $$4D$$(여기서는 3,072)를 넘으면 attention이 지배적이 됩니다. 512에 패치 16(토큰 1,024개)은 아직 투영이 3배 크지만, 512에 패치 8([StyTr²]({% post_url 2026-09-13-stytr2 %}), 토큰 4,096개)이면 attention이 더 커집니다.
- 위치 임베딩을 24×24로 보간해도 같은 행의 유사도(0.56)와 다른 행·열의 유사도(0.12)의 차이가 유지됩니다. 학습된 임베딩이 Figure 7처럼 행·열 구조를 담고 있다면, 보간은 그 구조를 새 격자로 옮깁니다.
- 패치를 펼쳐 선형 투영하는 것은 커널 16, stride 16의 합성곱과 정확히 같습니다. ViT의 "유일한 합성곱"이 첫 층에 숨어 있는 셈이고, 구현도 보통 그렇게 합니다.

## 3. 실험

**최고 성능 비교(표 2).** JFT-300M으로 사전학습한 ViT-H/14는 ImageNet 88.55%, ReaL 90.72%, CIFAR-100 94.55%, VTAB(19과제) 77.63%로 BiT-L(ResNet152x4, 87.54/90.54/93.51/76.29)과 Noisy Student(EfficientNet-L2, 88.4)를 넘습니다. 사전학습 비용은 TPUv3 코어-일로 ViT-H/14 2.5k, ViT-L/16 0.68k 대 BiT-L 9.9k, Noisy Student 12.3k입니다. 공개 데이터인 ImageNet-21k로 학습한 ViT-L/16도 85.30%로 준수하며 8코어 TPUv3로 약 30일이면 학습됩니다. VTAB을 나눠 보면 Natural과 Structured에서 BiT를 앞서고 Specialized는 비슷합니다.

**데이터 규모(Figure 3, 4).** ImageNet만으로 사전학습하면 ViT-Large가 ViT-Base보다 **못하고** BiT ResNet에 뒤집니다. ImageNet-21k에서는 비슷해지고, JFT-300M에서야 큰 모델의 이점이 나타납니다. JFT의 9M/30M/90M/300M 부분집합으로 정규화 없이 학습한 few-shot 선형 평가에서는 ViT-B/32가 ResNet50보다 9M에서 훨씬 나쁘지만 90M 이상에서 더 좋습니다. 작은 데이터에서는 합성곱 귀납 편향이 유용하지만, 큰 데이터에서는 패턴을 데이터에서 직접 배우는 것으로 충분하고 오히려 유리하다는 결론입니다.

**스케일링(Figure 5).** JFT-300M에서 ResNet 7개, ViT 6개, 하이브리드 5개를 계산 대비 성능으로 비교하면 ViT가 성능/계산 트레이드오프에서 ResNet을 지배하고, 같은 성능에 약 **2~4배 적은 계산**을 씁니다. 하이브리드는 작은 예산에서 ViT를 조금 앞서지만 큰 모델에서 차이가 사라지며, ViT는 시도한 범위에서 포화하지 않습니다.

**내부 분석(Figure 7).** 첫 층 임베딩 필터의 주성분은 패치 내 미세 구조의 기저 함수처럼 보이고, 위치 임베딩은 **가까운 패치끼리 유사하고 같은 행·열끼리 유사한** 2D 위상을 스스로 배웁니다(2D 인식 임베딩이 도움이 안 된 이유). attention 가중치로 잰 평균 "attention 거리"(CNN의 수용 영역에 해당)는 **가장 낮은 층에서도 일부 헤드가 이미지 대부분**에 걸치고, 다른 헤드는 국소적이며, 깊어질수록 커집니다. 국소 헤드는 하이브리드에서 덜 나타나, 초기 합성곱 층과 비슷한 역할을 하는 것으로 보입니다.

**자기지도.** BERT의 마스크 언어 모델을 흉내 낸 마스크 패치 예측으로 ViT-B/16을 사전학습하면 ImageNet 79.9%로 처음부터 학습한 것보다 2%p 높지만 지도 사전학습보다 4%p 낮습니다. 대조 학습은 후속 과제로 남깁니다.

## 4. 해석

**1. "귀납 편향 대 데이터"의 교환 관계를 가장 깨끗하게 보여 준 실험입니다.** 같은 구조를 데이터 규모만 바꿔 가며 학습한 Figure 3·4는, CNN의 우위가 구조의 본질이 아니라 **데이터가 부족할 때의 사전 지식**이었음을 보여 줍니다. 이후 DeiT가 강한 증강과 증류로 ImageNet만으로도 ViT를 학습시키며 "데이터 대신 정규화"로 같은 간극을 메웠습니다.

**2. 최소 수정이 전략이었습니다.** NLP의 확장 가능한 Transformer 구현과 인프라를 그대로 쓰려고 이미지 특화 설계를 일부러 피했습니다. 이 선택 덕에 BERT의 크기 체계(Base/Large/Huge)와 스케일링 법칙이 비전으로 바로 옮겨졌고, 이후 ViT-G, ViT-22B로 확장됩니다. 반대로 Swin, [EdgeViTs]({% post_url 2026-08-25-edgevits %}), [경량 ViT]({% post_url 2026-06-13-lightweight-vision-transformer %})는 지역성과 계층 구조를 다시 넣어 작은 데이터·작은 예산에서의 약점을 보완하는 방향입니다.

**3. 토큰 표현이 새로운 인터페이스가 됐습니다.** 패치 토큰과 [CLS] 토큰은 분류를 넘어 DETR류 검출, 분할, 그리고 [Splice]({% post_url 2026-10-13-splice-vit %})가 보여 준 DINO 특징의 의미적 활용, 멀티모달 모델(CLIP, [VLA]({% post_url 2026-10-19-vision-language-action-models %}))의 공용 표현으로 쓰입니다. "이미지도 토큰 열"이라는 관점 전환의 영향이 성능 수치보다 큽니다.

**4. 위치 임베딩 보간은 작지만 중요한 설계입니다.** 해상도를 바꿀 때 열 길이가 달라지는 문제를 2D 보간으로 해결한 이 선택은 이후 거의 모든 ViT 계열이 따르고, StyTr²의 CAPE처럼 스케일 불변 인코딩을 처음부터 설계하는 연구의 출발점이기도 합니다.

**5. 평가를 읽을 때 주의할 점.** 최고 결과는 비공개 JFT-300M에 의존하고, 사전학습 효율 비교는 구조뿐 아니라 옵티마이저·가중치 감쇠·스케줄의 영향을 받는다고 저자들도 적습니다(그래서 4.4절의 통제 실험이 있음). ImageNet 단독 학습에서는 ResNet에 뒤진다는 점이 본문에 명시되어 있고, 검출·분할은 다루지 않습니다. 위 toy의 위치 임베딩은 손으로 만든 사인 격자라 "학습된" 2D 구조를 보여 주지는 않고 보간이 구조를 보존한다는 점만 확인합니다.

## 5. 정리

| 항목 | 내용 |
|---|---|
| 설계 | 16×16 패치 → 선형 투영 + 학습 가능 1D 위치 임베딩 + [class] 토큰 → 표준 pre-LN Transformer 인코더 |
| 귀납 편향 | 패치 자르기와 위치 임베딩 보간에서만 2D 구조 사용, 나머지는 데이터에서 학습 |
| 변형 | B(86M)/L(307M)/H(632M), 패치 32/16/14 |
| 결과 | JFT-300M 사전학습 ViT-H/14: ImageNet 88.55%, VTAB 77.63%, BiT-L 대비 1/4 계산 |
| 데이터 규모 | ImageNet만으로는 ResNet 이하, 21k에서 대등, JFT에서 우세, 90M 이상에서 역전 |
| 분석 | 위치 임베딩이 2D 위상을 학습, 낮은 층부터 전역 attention 헤드 존재 |
