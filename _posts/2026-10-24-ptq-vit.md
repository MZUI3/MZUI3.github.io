> [FQ-ViT]({% post_url 2026-07-21-fq-vit %})가 LayerNorm과 Softmax까지 양자화하는 데 집중했다면, 이 논문(**Post-Training Quantization for Vision Transformer**, Liu, Wang, Han, Ma, Gao, Peking University·Noah's Ark Lab, NeurIPS 2021)은 **재학습 없이** 선형 층과 attention의 양자화 구간을 어떻게 정할 것인가를 다룹니다. 세 가지 장치를 씁니다. 양자화 전후 **출력 특징의 Pearson 유사도**를 최대화하는 구간 탐색, attention 맵의 **상대적 순위**를 보존하는 손실, 그리고 **핵 노름(nuclear norm)**으로 층별 민감도를 추정해 비트를 배정하는 혼합 정밀도입니다. DeiT-B를 약 8비트 혼합 정밀도로 81.29%(FP 81.8%)까지 복원했습니다.

## 1. 문제: ViT의 PTQ는 CNN과 다르다

ViT-L은 307M 파라미터, 64 GFLOPs로 모바일에는 무겁고, 학습 데이터 전체로 재학습하는 양자화 인식 학습(QAT)은 비용이 큽니다. 소량의 보정 데이터만으로 하는 **post-training quantization(PTQ)**이 필요한데, CNN용 PTQ(percentile, EasyQuant, Bit-Split 등)를 ViT에 그대로 쓰면 정확도가 크게 떨어집니다. 이유는 둘입니다.

- 선형 층의 양자화 오차가 **출력 특징의 분포**를 바꾸고, 이것이 다음 층의 attention을 흔듭니다. 가중치의 MSE만 줄이는 기준으로는 부족합니다.
- attention 맵을 양자화하면 **점수의 상대적 순서**가 바뀔 수 있습니다. Softmax 후 어떤 토큰이 더 중요한지가 바뀌면 출력이 크게 달라집니다.

## 2. 방법

### 유사도 인식 구간 탐색

대칭 균일 양자화 $$\Psi_\Delta(X) = \text{clip}(\text{round}(X / \Delta), -2^{b-1}, 2^{b-1} - 1)$$에서 구간 $$\Delta$$를 정해야 합니다. 이 논문은 가중치 자체가 아니라 **양자화 전후 출력 특징 사이의 Pearson 상관**을 기준으로 삼습니다.

$$
\max_{\Delta_W, \Delta_X} \; \frac{1}{N} \sum_{i} \Gamma\!\left(O_i, \hat O_i\right), \qquad \Gamma(a, b) = \frac{\sum (a - \bar a)(b - \bar b)}{\sqrt{\sum (a - \bar a)^2}\sqrt{\sum (b - \bar b)^2}}
$$

여기서 $$O = X W$$, $$\hat O = \Psi(X)\Psi(W)$$입니다. 후보 $$\Delta$$는 최대 절댓값의 $$[\alpha, \beta]$$ 배 구간을 선형 분할해 만들고, 가중치 구간과 입력 구간을 **번갈아 탐색**합니다. 평균과 스케일에 불변인 Pearson을 쓰는 이유는, 뒤따르는 LayerNorm과 Softmax가 절대 크기보다 상대 구조에 민감하기 때문이라고 저자들은 설명합니다.

### 순위 인식 손실

attention 맵 $$A = \text{softmax}(QK^\top / \sqrt{d})$$의 양자화에는 순서 보존 항을 더합니다. 같은 행 안의 두 점수 $$(A_i, A_j)$$에 대해

$$
\mathcal{L}_{\text{rank}} = \sum_{i, j} \Phi\!\left(\, (\hat A_i - \hat A_j) \cdot \text{sign}(A_i - A_j)\, \right), \qquad \Phi(p) = (\theta - p)_+
$$

로, 양자화 후에도 원래 큰 쪽이 여전히 크도록(마진 $$\theta$$만큼) 요구하는 hinge 손실입니다. 최종 목적은 $$\Gamma$$ 최대화와 $$\mathcal{L}_{\text{rank}}$$ 최소화를 $$\gamma$$로 섞은 것이고, 구간 탐색은 같은 방식으로 합니다.

### 편향 보정

양자화 오차의 기댓값 $$\mathbb{E}[\hat O - O]$$를 보정 데이터로 추정해 출력 편향에서 빼 줍니다. 단순하지만 분포의 평균 이동을 제거해 효과가 있습니다.

### 핵 노름 기반 혼합 정밀도

층마다 민감도가 다르므로 비트를 다르게 배정합니다. 민감도 지표로 각 층의 **attention 맵(MSA)과 출력 특징(MLP)의 핵 노름**, 즉 특이값의 합을 씁니다. 핵 노름이 크면 특징이 다양하고 정보가 많아 양자화에 민감하다고 봅니다. 후보 비트 $$\{4, 5, 6, 7, 8\}$$에서 핵 노름이 큰 층에 높은 비트를 주는 단조 배정만 고려해 탐색 공간을 줄이고, 모델 크기 제약 아래 $$\Omega = \sum_l \text{nuc}_l \cdot f(b_l)$$가 최소인 설정을 고릅니다. Hessian 기반 민감도(HAWQ)와 비교하면 계산 시간이 754.6초에서 53.1초로 줄면서 정확도는 비슷합니다.

## 3. 코드로 보기: 구간 탐색 기준과 순위 손실

4비트 활성값에 대해 세 가지 기준(입력 MSE, 출력 MSE, 출력 Pearson)으로 구간을 고르고, attention 맵에서 순위 손실이 상위 키의 순서를 얼마나 지켜 주는지 봅니다.

```python
import numpy as np
rng = np.random.default_rng(0)

def quant(x, alpha, bits, signed=True):
    if signed:
        qmax = 2 ** (bits - 1) - 1; delta = alpha * np.abs(x).max() / qmax
        return np.clip(np.round(x / delta), -qmax - 1, qmax) * delta
    qmax = 2 ** bits - 1; delta = alpha * x.max() / qmax
    return np.clip(np.round(x / delta), 0, qmax) * delta

def pearson(a, b):
    a, b = a.ravel() - a.mean(), b.ravel() - b.mean()
    return float(a @ b / (np.linalg.norm(a) * np.linalg.norm(b) + 1e-12))

# --- (1) interval search for 4-bit activations (post-GELU, skewed) feeding a linear layer
W = rng.standard_normal((256, 256)) * 0.05
Z = rng.standard_normal((128, 256)) @ (rng.standard_normal((256, 256)) * 0.1 + np.eye(256))   # correlated features
X = Z * (1 / (1 + np.exp(-1.702 * Z)))                                                        # GELU
O = X @ W
alphas = np.linspace(0.05, 1.0, 96)
rows = []
for a in alphas:
    Xq = quant(X, a, 4); Oq = Xq @ W
    rows.append((a, np.mean((X - Xq) ** 2), np.mean((O - Oq) ** 2), pearson(O, Oq), np.linalg.norm(O - Oq) / np.linalg.norm(O)))
rows = np.array(rows)
print("4-bit activation quantization, clipping interval = alpha * max|X|")
print("criterion                 alpha   output rel.err   output Pearson")
for name, i in [("input MSE (naive)", np.argmin(rows[:, 1])), ("output MSE", np.argmin(rows[:, 2])), ("output Pearson (paper)", np.argmax(rows[:, 3]))]:
    print(f"{name:<24}  {rows[i,0]:>5.2f}   {rows[i,4]:>13.4f}   {rows[i,3]:>13.5f}")
print(f"alpha = 1.0 (no clipping, min-max): rel.err {rows[-1,4]:.4f}, Pearson {rows[-1,3]:.5f}")

# --- (2) ranking loss on attention: keep the ORDER of attention scores, not just their values
def rank_loss(a, aq, margin=0.002):
    order = np.sign(a[:, None] - a[None, :])
    return np.mean(np.maximum(0, -order * (aq[:, None] - aq[None, :]) + margin * np.abs(order)))
scores = rng.standard_normal((16, 64)) * 2.0
attn = np.exp(scores) / np.exp(scores).sum(-1, keepdims=True)
def top3_kept(a, aq): return np.mean([len(set(np.argsort(-r)[:3]) & set(np.argsort(-q)[:3])) / 3 for r, q in zip(a, aq)])
res = []
for a in np.linspace(0.1, 1.0, 37):
    aq = quant(attn, a, 4, signed=False)
    res.append((a, np.mean((attn - aq) ** 2), np.mean([rank_loss(r, q) for r, q in zip(attn, aq)]), top3_kept(attn, aq)))
res = np.array(res)
print()
print("attention map, unsigned 4-bit: objective = MSE + lambda * ranking loss")
print("lambda   chosen alpha   MSE        top-3 keys kept")
for lam in (0.0, 0.5, 2.0):
    i = np.argmin(res[:, 1] + lam * res[:, 2])
    print(f"{lam:>6}   {res[i,0]:>12.3f}   {res[i,1]:.2e}   {res[i,3]:>15.3f}")

# --- (3) nuclear norm of a layer's attention map / output as a sensitivity proxy for mixed precision
print()
print("layer  nuclear norm   assigned bits")
norms = []
for l in range(6):
    rank = [2, 64, 8, 32, 4, 16][l]
    A = rng.standard_normal((64, rank)) @ rng.standard_normal((rank, 64))
    norms.append(np.linalg.norm(A, "nuc"))
order = np.argsort(norms)
bits = {int(order[i]): [4, 4, 6, 6, 8, 8][i] for i in range(6)}
for l in range(6): print(f"{l:>5}  {norms[l]:>12.1f}   {bits[l]:>13}")
```

- 구간 탐색 자체는 효과가 큽니다. 최대값에 맞추는 min-max($$\alpha = 1$$)보다 $$\alpha \approx 0.6$$으로 **잘라 내는 쪽이 출력 오차를 19%에서 13.5%로** 줄입니다. 다만 이 toy의 대칭적인 분포에서는 입력 MSE, 출력 MSE, Pearson이 거의 같은 구간을 고릅니다. 논문이 보고한 기준 간 차이(DeiT-B 75.42 → 76.98 같은 ablation)는 실제 ViT의 치우친 특징 분포와 뒤따르는 LayerNorm·Softmax에서 나오는 것이라, 장난감 분포로는 재현되지 않았습니다.
- 순위 손실은 뚜렷합니다. MSE만 쓰면 큰 값을 살리느라 $$\alpha = 0.9$$를 고르고 상위 3개 키의 보존율이 87.5%인데, 순위 손실을 $$\lambda = 0.5$$로 더하면 $$\alpha = 0.675$$에서 **93.8%**로 오릅니다. $$\lambda$$가 너무 크면(2.0) 작은 값들의 순서를 지키느라 구간을 지나치게 좁혀 보존율이 떨어집니다. 논문의 $$\gamma$$ 균형이 필요한 이유입니다.
- 핵 노름은 행렬의 유효 랭크를 반영하므로, 랭크가 높은 층에 높은 비트가 배정됩니다.

## 5. 해석

**1. "무엇을 보존할 것인가"를 바꾼 논문입니다.** 가중치의 MSE가 아니라 출력 특징의 상관을, 절대값이 아니라 순위를 보존 대상으로 삼았습니다. [DIST]({% post_url 2026-10-23-dist-kd %})가 지식 증류에서 KL 대신 Pearson 상관으로 "관계"를 옮긴 것과 같은 발상이 양자화에 적용된 셈입니다.

**2. 순위 손실은 attention의 성질에 맞춘 장치입니다.** Softmax 뒤의 attention 맵은 값의 범위가 좁고 대부분이 0 근처라, 균일 양자화는 작은 값들을 뭉개 순서를 뒤섞기 쉽습니다. 위 실험에서 보듯 순위를 지키려면 구간을 좁혀야 하고, 그 대가로 큰 값의 정밀도가 떨어지므로 균형 계수가 필요합니다. [FQ-ViT]({% post_url 2026-07-21-fq-vit %})의 log2 양자화는 같은 문제를 비균일 격자로 푼 것입니다.

**3. 핵 노름은 싸고 그럴듯한 민감도 대리 지표입니다.** Hessian 계산보다 14배 빠르면서 비슷한 정확도를 냈다는 점이 실용적입니다. 다만 "핵 노름이 크면 민감하다"는 가정은 경험적이고, 랭크가 높지만 양자화에 둔감한 층이 있을 수 있습니다.

**4. PTQ 연구의 중간 지점에 있습니다.** 이 논문은 선형 층과 attention 맵만 다루고 LayerNorm, Softmax, GELU는 부동소수점으로 둡니다. 완전 정수 추론을 위해서는 FQ-ViT의 Power-of-Two Factor와 log2 양자화, 혹은 이후의 RepQ-ViT 같은 후속 연구가 필요합니다. [양자화 기초]({% post_url 2026-06-15-pruning-and-quantization %})와 함께 읽으면 PTQ의 설계 공간이 보입니다.

**5. 평가를 읽을 때 주의할 점.** 혼합 정밀도의 "8 MP"는 평균 비트가 8에 가깝다는 뜻이고 모델 크기 열에서 확인해야 합니다. 비교 대상 중 percentile 등은 저자들이 ViT에 맞춰 구현한 것입니다. 위 toy에서 구간 탐색 기준 간 차이가 나지 않은 것은 toy의 한계일 수도, 논문의 ablation이 특정 분포에 의존한다는 신호일 수도 있어 실제 모델로 확인해야 합니다.
