> 얼굴 교체 연구의 출발점은 딥페이크가 아니라 **프라이버시**였습니다. Google Street View 같은 서비스가 동의 없이 찍힌 사람들의 얼굴을 담자, 블러나 픽셀화 대신 **다른 사람의 얼굴로 바꿔서** 신원을 지우되 사진의 자연스러움은 유지하자는 제안이 나왔습니다. **Face Swapping: Automatically Replacing Faces in Photographs**(Bitouk, Kumar, Dhillon, Belhumeur, Nayar, Columbia, SIGGRAPH 2008)는 그 첫 완전 자동 시스템입니다. 핵심 발상은 단순합니다. 3D 복원처럼 어렵고 자동화하기 힘든 일을 피하고, **입력과 충분히 비슷한 얼굴을 큰 라이브러리에서 찾아** 2D 합성만으로 붙이는 것입니다. 이후 [Korshunova 등의 신경망 교체]({% post_url 2026-10-24-fast-face-swap %})와 [FSGAN]({% post_url 2026-10-24-fsgan %})이 이 논문을 "출력 신원을 제어할 수 없고 표정이 바뀐다"는 한계로 인용하지만, 선별·조정·순위라는 파이프라인의 뼈대는 그대로 남았습니다.

## 1. 라이브러리

Flickr와 Yahoo 이미지에서 키워드로 수집한 사진에 상용 검출기(OKAO)를 돌려 얼굴을 자르고, 중복·작은 얼굴·노출 불량을 거르면 약 **33,000장**입니다. 검출기가 주는 yaw·pitch로 15개 **포즈 빈**(yaw ±25°, pitch ±15°를 10° 간격)에 넣고, 좌우 반전도 추가합니다. 각 빈에는 6개 기준점(눈 안쪽·바깥쪽 모서리, 입꼬리)을 가진 일반 얼굴이 정의되어 있어, 얼굴마다 **아핀 변환**으로 공통 좌표계에 정렬합니다. 교체 영역도 빈마다 2D로 정의되므로 3D 기하는 전혀 필요 없습니다.

## 2. 선별: 비슷한 얼굴만 고른다

정렬된 입력 얼굴에 대해 같은 포즈 빈 안에서 순차적으로 거릅니다.

- **포즈**: yaw·pitch 차이 3° 이내. 평면 내 회전은 정렬로 보정되지만 평면 밖 회전은 2D로 못 고치기 때문입니다.
- **해상도**: 눈 사이 거리가 입력의 80% 이상(다운샘플은 언제든 가능).
- **블러**: 눈 영역을 정규화한 뒤 기울기 크기 히스토그램을 빈 인덱스의 제곱으로 가중해(큰 기울기 = 선명한 가장자리) 히스토그램 교차 거리로 비교, 상위 50%.
- **색과 조명**: 얼굴을 원통형 평균 형상(램버시안)으로 보고 9개 **구면 조화 함수**로 조명을 근사합니다. $$\tilde I_c(x,y) = \rho_c \sum_{k=1}^{9} a_{c,k} H_k(n(x,y))$$. 조화 기저는 교체 영역에서 직교하지 않으므로 Gram-Schmidt로 직교화한 뒤 알베도 3개와 조명 계수 27개를 최소제곱으로 추정합니다. 알베도를 HSV로 바꿔 색상·채도 5%, 명도 10% 이내만 남기고, 조명 계수의 L2 거리 상위 50%를 남깁니다.
- **경계 서명(seam signature)**: 교체 경계 안쪽 6픽셀 띠를 펼쳐 정규화한 질감입니다. 눈썹, 수염, 이마의 머리카락처럼 경계를 가로지르는 차이는 블렌딩으로도 안 가려지므로, 띠 방향 기울기의 절댓값을 L2로 비교하되 8% 이내 차이는 0으로 칩니다. 상위 50장을 후보로 남깁니다.

싼 기준(SQL 질의로 포즈·해상도·평균색)부터 비싼 기준 순으로 적용해 33,000장을 수천 장으로, 다시 50장으로 줄이며 C++ 구현에서 1초 미만입니다.

## 3. 조정과 순위

선별된 후보라도 색과 조명을 입력에 맞춰야 합니다. 후보의 조명 계수를 입력의 것으로 바꾸어 **재조명**하고(Liu 등 2001과 비슷한 비율 이미지 방식), 색은 알베도를 맞춥니다. 블렌딩은 경계에서 몇 픽셀의 **페더링**으로 충분합니다. 마지막으로 경계 영역에서 입력과의 차이로 **순위 메트릭**을 계산해 후보를 정렬합니다. Figure 4는 정렬만 한 결과, 기본 선별, 경계 서명 추가, 조정, 순위의 각 단계에서 결과가 좋아지는 것을 보여 줍니다.

## 4. 코드로 보기: 순차 선별과 구면 조화 재조명

합성 라이브러리 3만 3천 개에 논문의 기준을 순서대로 적용해 후보 수가 줄어드는 과정을 보고, 구면 위의 램버시안 얼굴에 9개 조화 기저를 최소제곱으로 맞춰 다른 조명의 후보를 입력 조명으로 바꾸며, 하드 붙여넣기와 페더링의 경계 점프를 비교합니다.

```python
import numpy as np
rng = np.random.default_rng(0)
# (1) a synthetic face library: pose (yaw, pitch), eye distance, HSV albedo, 27 lighting coefficients, seam signature
N = 33000
yaw, pitch = rng.uniform(-25, 25, N), rng.uniform(-15, 15, N)
eyes = rng.uniform(20, 120, N)
hsv = np.stack([rng.uniform(0.02, 0.12, N), rng.uniform(0.3, 0.7, N), rng.uniform(0.4, 0.9, N)], 1)   # skin-like hues
light = rng.standard_normal((N, 27))
seam = rng.standard_normal((N, 64))
q = dict(yaw=4.0, pitch=-2.0, eyes=60, hsv=np.array([0.07, 0.5, 0.65]), light=rng.standard_normal(27), seam=rng.standard_normal(64))
keep = np.ones(N, bool); print("sequential appearance-based selection (cheap criteria first)")
print(f"  library                                   {keep.sum():>6}")
keep &= (np.abs(yaw - q['yaw']) <= 3) & (np.abs(pitch - q['pitch']) <= 3);        print(f"  pose within 3 deg                         {keep.sum():>6}")
keep &= eyes >= 0.8 * q['eyes'];                                                  print(f"  resolution >= 80% of the input            {keep.sum():>6}")
keep &= (np.abs(hsv[:, 0] - q['hsv'][0]) <= 0.05) & (np.abs(hsv[:, 1] - q['hsv'][1]) <= 0.05) & (np.abs(hsv[:, 2] - q['hsv'][2]) <= 0.10)
print(f"  hue/sat within 5%, value within 10%       {keep.sum():>6}")
dl = np.linalg.norm(light - q['light'], axis=1); keep &= dl <= np.median(dl[keep]) if keep.any() else keep
print(f"  lighting distance in the top 50%          {keep.sum():>6}")
ds = np.linalg.norm(seam - q['seam'], axis=1); cand = np.argsort(np.where(keep, ds, np.inf))[:50]; cand = cand[keep[cand]]
print(f"  best seam signatures (<= 50 kept)         {len(cand):>6}")
# (2) relighting with 9 spherical harmonics on a Lambertian 'average face' (a sphere), then recolouring the candidate
n = 48; yy, xx = np.mgrid[-1:1:n*1j, -1:1:n*1j]; r2 = xx**2 + yy**2; m = r2 < 1
nx, ny, nz = xx[m], yy[m], np.sqrt(1 - r2[m])
H = np.stack([np.ones_like(nx), nx, ny, nz, nx*ny, nx*nz, ny*nz, nx**2 - ny**2, 3*nz**2 - 1], 1)   # 9 harmonic images
def render(coef, albedo): return albedo * (H @ coef)
cin = np.array([1.0, 0.6, 0.1, 0.3, 0, 0, 0, 0, 0]); ccand = np.array([1.0, -0.5, 0.0, 0.4, 0, 0, 0, 0, 0])
skin_in, skin_cd = 0.03 * np.sin(9 * nx) * np.cos(7 * ny), 0.03 * np.cos(11 * nx + 1) * np.sin(6 * ny)   # fine skin texture, not in the model
I_in, I_cand = render(cin, 0.55) + skin_in, render(ccand, 0.75) + skin_cd    # input lit from the right, candidate from the left, darker skin
coef_in, *_ = np.linalg.lstsq(H, I_in, rcond=None); coef_cd, *_ = np.linalg.lstsq(H, I_cand, rcond=None)
relit = I_cand * (H @ coef_in) / (H @ coef_cd)                             # swap the fitted albedo x illumination, keep the candidate's texture
print("\nrecolour + relight with the fitted albedo and 9 harmonic coefficients: mean |candidate - input| inside the face")
print(f"  raw candidate       {np.abs(I_cand - I_in).mean():.3f}")
print(f"  adjusted candidate  {np.abs(relit - I_in).mean():.3f}   (what remains is the two faces' own skin texture, which should differ)")
# (3) seam: hard paste vs feathering over a 6-px strip, on a 1-D cross-section with a brightness offset
x = np.linspace(0, 1, 100); target = 0.5 + 0.1 * np.sin(6 * x); source = target + 0.08
inside = (x > 0.3) & (x < 0.7); paste = np.where(inside, source, target)
w = np.clip((np.minimum(x - 0.3, 0.7 - x)) / 0.06, 0, 1); feather = w * source + (1 - w) * target
print(f"\nmax jump between neighbouring pixels: hard paste {np.abs(np.diff(paste)).max():.3f}, feathered {np.abs(np.diff(feather)).max():.3f}")
```

```text
sequential appearance-based selection (cheap criteria first)
  library                                    33000
  pose within 3 deg                            761
  resolution >= 80% of the input               545
  hue/sat within 5%, value within 10%           46
  lighting distance in the top 50%              23
  best seam signatures (<= 50 kept)             23

recolour + relight with the fitted albedo and 9 harmonic coefficients: mean |candidate - input| inside the face
  raw candidate       0.382
  adjusted candidate  0.016   (what remains is the two faces' own skin texture, which should differ)

max jump between neighbouring pixels: hard paste 0.083, feathered 0.018
```

- 포즈 3°가 33,000장을 761장으로, 색이 46장으로, 조명이 23장으로 줄입니다. 라이브러리가 클수록 마지막까지 살아남는 후보가 "이미 비슷한" 얼굴이라는 것이 이 시스템의 전제이고, 3만 장은 그 전제가 성립하는 최소 규모에 가깝습니다.
- 반대쪽에서 빛을 받은 더 어두운 피부의 후보가 입력과 0.38 차이였는데, 조화 계수를 바꿔 끼우면 0.016으로 줄고 남는 것은 두 얼굴 고유의 피부 질감뿐입니다. 9개 계수면 부드러운 조명은 충분히 설명된다는 Basri & Jacobs의 결과를 그대로 쓴 것입니다.
- 6픽셀 페더링만으로 경계 점프가 0.083에서 0.018로 줍니다. 후보가 이미 비슷하므로 복잡한 블렌딩이 필요 없다는 주장의 근거입니다.

## 5. 결과와 응용

**비식별화.** 거리 사진의 얼굴을 자동으로 바꿔 신원을 지웁니다. 기존 방법(PCA 평균, AAM)은 블러·고스팅이 남고 정면만 다뤘지만, 이 방법은 다양한 포즈·조명·피부색에서 자연스럽습니다.

**개인화 교체와 그룹 사진.** 라이브러리를 개인 사진첩으로 바꾸면 같은 사람의 더 나은 표정으로 바꿀 수 있고, 연속 촬영에서 모두가 웃고 눈을 뜬 합성 사진을 만들 수 있습니다.

**사용자 연구.** 실제 사진과 교체된 사진을 보여 주면 사람들은 거의 같은 비율로 "진짜"라고 판단했습니다.

**한계.** 라이브러리에 비슷한 얼굴이 없으면 실패하고, 나이·성별 일관성은 강제하지 않아(Figure 6의 c, d) 어긋난 결과가 나올 수 있습니다. 극단적 포즈와 그림자·동적 범위 차이는 재조명으로 못 고치고, 표정은 후보의 것으로 바뀝니다. 출력 신원을 지정할 수 없다는 점이 이후 연구가 가장 먼저 바꾼 부분입니다.

## 6. 해석

**1. "생성 대신 검색"의 전형입니다.** 어려운 추론(3D 형상, 조명)을 피하고 데이터의 양으로 대체하는 Hays & Efros의 장면 완성과 같은 시대의 발상입니다. 이후 딥러닝이 생성으로 돌아왔지만, "입력과 비슷한 소스를 고르면 쉬워진다"는 통찰은 [FSGAN]({% post_url 2026-10-24-fsgan %})의 외형 맵(포즈별 소스 프레임 선택)에 그대로 살아 있습니다.

**2. 파이프라인의 분해가 오래 남았습니다.** 정렬 → 선별 → 조정(색·조명) → 블렌딩 → 평가라는 단계는 [DeepFaceLab]({% post_url 2026-10-24-deepfacelab %})의 추출·학습·변환이나 [Nirkin 등]({% post_url 2026-10-24-face-segmentation-swapping %})의 3D 프록시 파이프라인에서도 그대로입니다. 색 전이와 포아송/페더링 블렌딩은 2020년대 방법에도 후처리로 남아 있습니다.

**3. 조명을 명시적으로 다룬 첫 교체 논문입니다.** 구면 조화 재조명은 [AOT]({% post_url 2026-10-24-aot %})가 외형 격차를 최적 수송으로 푸는 것, [Disney의 저주파 보존 블렌딩]({% post_url 2026-10-24-hires-face-swapping %})의 선조입니다.

**4. 윤리적 틀이 달랐습니다.** 2008년의 동기는 사진 속 타인의 **보호**였고, 결과를 사람이 구분 못 한다는 사용자 연구는 성공의 증거였습니다. 같은 수치가 2020년대에는 위조 탐지의 위협으로 읽힙니다([DeeperForensics]({% post_url 2026-10-24-deeperforensics %})).

**5. 평가를 읽을 때 주의할 점.** 정량 지표가 없고 사용자 연구도 12명·50장 규모에 통계 검정이 없어 비교가 어렵습니다. 상용 검출기(OKAO)에 의존하며 포즈 범위가 ±25°로 좁습니다. 위 toy의 라이브러리와 얼굴은 합성이라 선별 기준의 **순서와 축소율**만 보여 줄 뿐 실제 이미지 품질은 보여 주지 못합니다.

## 7. 정리

| 항목 | 내용 |
|---|---|
| 목표 | 3D 없이, 사용자 개입 없이 사진의 얼굴을 다른 얼굴로 자연스럽게 교체(비식별화) |
| 라이브러리 | 인터넷 수집 33,000장, 15개 포즈 빈, 6점 아핀 정렬 |
| 선별 | 포즈 3°, 해상도 80%, 블러 히스토그램, HSV 알베도, 9개 구면 조화 조명 계수, 경계 서명 → 상위 50 |
| 조정 | 조명 계수 교체 재조명, 색 보정, 페더링, 경계 메트릭으로 순위 |
| 결과 | 사용자 연구에서 실제와 비슷한 판단률, 1초 미만 선별 |
| 한계 | 출력 신원 지정 불가, 표정 변경, 극단 포즈·그림자, 나이·성별 비일관 |
