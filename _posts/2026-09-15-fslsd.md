> [MegaFS]({% post_url 2026-09-06-megafs %})는 StyleGAN 사전으로 1024² 교체를 열었지만, 신원과 속성이 얽힌 잠재 공간에서 두 코드를 **명시적 안내 없이** 조립하기 때문에 소스 신원 전이와 목표 속성 보존을 동시에 보장하지 못했고, 조립 과정에서 세부가 희석되어 결과가 흐렸습니다(Figure 1의 피부색·조명 손실, Figure 3의 경계). **High-resolution Face Swapping via Latent Semantics Disentanglement**(Xu, Deng, Wang, Jing, Pan, He, 화남이공대·Cardiff·Tencent·홍콩대, CVPR 2022; 저자들이 FSLSD라 부름)는 속성을 **종류별로** 옮기자고 주장합니다. 얼굴 형태·포즈·표정 같은 **구조** 속성은 소스와 목표에서 함께 정해야 하고, 조명·피부톤 같은 **외형** 속성은 목표 것을 그대로 쓰면 됩니다. StyleGAN의 거칠게-세밀하게 생성 순서가 이 분리를 거의 공짜로 줍니다. 여기에 영상용 시공간 제약 둘을 더해 **고해상도 영상 교체**의 첫 실용 해법이라고 자리매김합니다.

## 1. 종류별 속성 전이

$$\mathcal{W}+$$ 코드는 1024² 생성기에서 512차원 벡터 18개이고, 층마다 다른 세부 수준에 대응합니다. pSp의 관찰을 따라 **앞 7개를 구조**, 나머지를 **외형**으로 둡니다. pSp 인코더로 소스·목표를 역변환해 $$w_s = (g_s, h_s)$$, $$w_t = (g_t, h_t)$$를 얻습니다.

**구조.** 결과는 소스의 신원을 갖되 목표의 포즈·표정을 가져야 하므로, 소스 구조 코드에서 출발해 둘의 차이를 반영합니다. 얼굴 구조는 랜드마크가 나타내므로, 소스·목표 랜드마크의 히트맵에서 **구조 전이 방향** $$\vec n = E_{le}(l_s, l_t)$$을 만드는 랜드마크 인코더를 학습합니다.

$$
\hat g_s = g_s + \vec n, \qquad \hat w_s = \text{Cat}(\hat g_s, h_t)
$$

**외형.** 목표의 외형 코드 $$h_t$$를 그대로 씁니다. 생성기에 $$\hat w_s$$를 넣으면 **측면 출력** $$y_s$$가 나옵니다.

## 2. 배경 전이

$$y_s$$는 목표 배경을 보장하지 못하고, 포아송 블렌딩 후처리는 얼굴 경계를 부자연스럽게 만듭니다. 그래서 $$y_s$$ 자체는 버리고, 생성기의 각 업샘플 블록이 만든 **특징** $$F_s = \{f^i_s\}$$를 씁니다. 목표 이미지를 인코더 $$E_t$$에 넣어 같은 해상도의 $$F_t = \{f^i_t\}$$를 만들고, 각 해상도에서 **얼굴 안쪽 마스크** $$m_t$$ 영역의 $$f^i_t$$를 $$f^i_s$$로 바꾼 뒤 디코더로 최종 $$y_f = \text{Dec}(F_t, F_s, m_t)$$를 냅니다. 다중 수준 특징에서 배경을 옮기므로 명시적 블렌딩이 필요 없고, 코드 $$\hat w_s$$는 얼굴 영역에만 집중할 수 있습니다.

**손실.** 최종 얼굴에 적대(목표 대 결과), ArcFace 신원(소스), 랜드마크 정렬(측면·최종 출력 대 목표), 소스=목표일 때 픽셀+지각 재구성($$\alpha = 0.8$$), 그리고 **스타일 전이 손실** $$\lVert y_f - HM(y_f, x_t) \rVert_2$$입니다. 마지막은 BeautyGAN처럼 히스토그램 매칭으로 만든 안내 이미지에 맞추는 것으로, 소스·목표의 스타일 차가 클 때 코드 교체만으로 부족한 외형 전이를 보강합니다. 가중치 1, 2, 0.1, 2, 0.2.

## 3. 영상: 두 시공간 제약

프레임마다 독립 교체하면 고해상도에서 깜빡임이 두드러집니다. 구조와 외형 각각에 제약을 둡니다.

**코드 궤적 제약.** 이웃 프레임의 구조 코드 **오프셋**이 구조 변화를 나타내므로, 교체 결과의 오프셋이 목표의 오프셋과 같도록 $$\mathcal{L}_{ct} = \sum_k \lVert (\hat g^k_s - \hat g^{k-1}_s) - (g^k_t - g^{k-1}_t) \rVert_2$$.

**플로 궤적 제약.** 외형은 이웃 프레임 사이 변화가 국소 선형이라 가정하고, PWC-Net 옵티컬 플로에 대해 $$\mathcal{L}_{ft} = \sum_k \lVert (f_{k \Rightarrow k+2} + f_{k+2 \Rightarrow k})/2 - f_{k \Rightarrow k+1} \rVert_2$$. 플로의 시간 라플라시안의 $$\ell_1/\ell_2$$ 노름이라 대부분 프레임에서 작고 일부에서 클 수 있는 **구간별 매끄러운** 움직임을 허용합니다.

## 4. 코드로 보기: 두 제약이 떨림을 없애는 과정

40프레임의 매끄러운 목표 구조 코드에 프레임별 역변환 잡음을 더해 교체 코드를 만들고, 코드 궤적 손실로 50번 경사 하강했을 때 이웃 오프셋 불일치와 코드 이동량을 보며, 무작위 속도 변화가 있는 플로에 국소 선형 제약을 걸어 시간 라플라시안을 봅니다.

```python
import numpy as np
rng = np.random.default_rng(0)
# video face swapping: per-frame inversion gives noisy latent codes; the swapped sequence should move like the target sequence
T, K, D = 40, 7, 16                                            # frames, structure layers (first 7 of 18), code dim
t = np.arange(T) / T
target_struct = np.stack([np.sin(2 * np.pi * t + k) * 0.5 for k in range(K)], 1)[..., None] * np.ones(D)   # smooth target motion
inv_noise = 0.15 * rng.standard_normal((T, K, D))               # frame-wise inversion jitter
source_struct = rng.standard_normal((K, D)) * 0.5
direction = (target_struct - source_struct[None]) + inv_noise   # landmark-driven structure transfer direction, per frame (noisy)
swapped = source_struct[None] + direction
# code trajectory constraint: make neighbouring-frame offsets of the swapped codes follow the target's offsets
def jitter(c): return np.linalg.norm(np.diff(c, axis=0) - np.diff(target_struct, axis=0), axis=(1, 2)).mean()
smoothed = swapped.copy()
for _ in range(50):                                            # a few gradient steps on L_ct = sum ||(g_s^k - g_s^{k-1}) - (g_t^k - g_t^{k-1})||
    d = np.diff(smoothed, axis=0) - np.diff(target_struct, axis=0)
    grad = np.zeros_like(smoothed); grad[1:] += d; grad[:-1] -= d
    smoothed -= 0.2 * grad
print("structure-code trajectory: mean |offset(swapped) - offset(target)| between neighbouring frames")
print(f"  per-frame inversion            {jitter(swapped):.3f}")
print(f"  with the code trajectory loss  {jitter(smoothed):.3f}")
print(f"  identity drift (mean code change from the per-frame solution) {np.abs(smoothed - swapped).mean():.3f}  -> jitter removed, codes barely moved")
# flow trajectory constraint: optical flow between frames should be locally linear (small temporal Laplacian)
flow = np.cumsum(0.4 + 0.3 * rng.standard_normal(T), 0)       # frame positions with random speed changes (flicker-like)
lap = lambda f: np.abs(f[2:] - 2 * f[1:-1] + f[:-2]).mean()
sm = flow.copy()
for _ in range(100): sm[1:-1] -= 0.3 * (2 * sm[1:-1] - sm[2:] - sm[:-2]) * 0.5
print(f"\nflow trajectory (temporal Laplacian of the motion): raw {lap(flow):.3f} -> after the local-linear constraint {lap(sm):.3f}")
# structure vs appearance layers: which W+ layers carry what (the paper takes the first 7 of 18 as structure)
print("\nW+ layer split used: layers 1-7 structure (pose, expression, shape), 8-18 appearance (colour, lighting, skin)")
print("swap recipe: g_hat_s = g_s + n(landmarks_s, landmarks_t);  w_hat = [g_hat_s ; h_t]  -> source identity, target pose and appearance")
```

```text
  per-frame inversion            2.264
  with the code trajectory loss  0.061
  identity drift (mean code change from the per-frame solution) 0.113  -> jitter removed, codes barely moved

flow trajectory (temporal Laplacian of the motion): raw 0.340 -> after the local-linear constraint 0.007

```

- 프레임별 역변환의 오프셋 불일치 2.26이 코드 궤적 손실로 0.06이 되고, 그러는 동안 코드 자체는 평균 0.11만 움직입니다. 잡음은 지우고 신원은 거의 건드리지 않는 제약입니다. 오프셋을 맞추는 것이지 코드를 맞추는 것이 아니기 때문입니다.
- 플로의 시간 라플라시안은 0.34에서 0.007로 떨어집니다. 외형의 깜빡임을 "속도의 급변"으로 보고 벌하는 것이고, 큰 변화를 완전히 금지하지는 않습니다.

## 5. 실험

FFHQ 사전학습 StyleGAN2(1024²)와 pSp, 랜드마크 인코더는 pSp 변형, V100 4장 2일, 배치 8, 50만 반복.

**CelebA-HQ 1024²(MegaFS 비교).** MegaFS는 저차원 코드만으로 교체해 세부가 희석되어 흐리고 얼굴과 배경 사이에 경계가 보이며, 소스·목표의 의미 차가 크면 목표 조명·스타일을 못 옮기고(Figure 3 둘째 줄), 신원도 잘못 바꿉니다(눈 확대). FSLSD는 생성기의 다중 해상도 특징 덕에 세부를 지키고 종류별 전이 덕에 목표 속성을 유지합니다. 정량으로 ID 유사도, 포즈, 표정, FID에서 MegaFS를 앞섭니다(ID 0.5688 대 0.5214, 포즈 2.997 대 3.498, 표정 2.74 대 2.95, FID 9.987 대 11.645).

**FaceForensics++.** FaceSwap, DeepFakes, FaceShifter, MegaFS와 비교해 정성·정량 모두 최신 수준이며, 저자들은 결과가 고해상도 위조 탐지의 새 테스트 사례가 될 수 있다고 봅니다. 영상 교체는 두 제약의 ablation으로 깜빡임 감소를 보입니다.

## 6. 해석

**1. "층 = 의미 수준"이라는 StyleGAN 지식을 교체에 직접 썼습니다.** [MegaFS]({% post_url 2026-09-06-megafs %})가 14개 고수준 코드를 통째로 다루고 FTM에 분리를 맡겼다면, FSLSD는 pSp·StyleSpace 연구의 결론(얕은 층 = 구조)을 설계에 박아 **무엇을 어디서 가져올지**를 정했습니다. 위 [MegaFS 글의 toy]({% post_url 2026-09-06-megafs %})가 보여 준 "고층까지 소스에서 가져오면 피부톤이 샌다"는 문제를 정의로 피한 것입니다.

**2. 구조 전이 방향은 재연기의 잠재 공간판입니다.** 소스 코드에 랜드마크 차이에서 나온 방향을 더하는 것은 [FSGAN]({% post_url 2026-08-16-fsgan %})의 랜드마크 조건 재연기를 $$\mathcal{W}+$$에서 한 것이고, 신원은 소스 코드에 남고 포즈·표정만 방향으로 옮겨진다는 가정 위에 있습니다. [StyleIPSB]({% post_url 2026-10-18-styleipsb %})는 이 "방향"이 신원을 건드리지 않도록 기저를 따로 만듭니다.

**3. 생성기 특징과 인코더 특징의 다중 스케일 융합이 경계 문제를 풉니다.** [HifiFace]({% post_url 2026-09-03-hififace %})의 SFF와 같은 발상이고, StyleGAN 기반 방법에서 배경·가림을 다루는 표준 해법이 됩니다([RAFSwap]({% post_url 2026-10-06-rafswap %})의 FMP, [StyleSwap]({% post_url 2026-10-08-styleswap %})의 특징 연결). [E4S]({% post_url 2026-10-09-e4s %})는 그래도 FSLSD의 경계가 보인다고 평하며 마스크 기반 생성으로 갑니다.

**4. 영상 제약은 일반적입니다.** 구조 코드 오프셋 매칭과 플로 라플라시안은 교체에 국한되지 않고 StyleGAN 역변환 기반 영상 편집 전반에 쓰일 수 있는 형태이고, [FSGANv2]({% post_url 2026-09-11-fsganv2 %})가 입력(랜드마크) 쪽에서 떨림을 잡는 것과 상보적입니다.

**5. 평가를 읽을 때 주의할 점.** 고해상도 비교 대상은 MegaFS 하나이고, FF++ 표에서는 포즈(2.46)·표정(2.79) 오차가 가장 낮지만 ID 검색률(90.05%)은 MegaFS(90.83%)·FaceShifter(90.68%)보다 조금 낮습니다. 7개 층 분할은 pSp의 관찰을 따른 것이지 학습된 것이 아니며, 1024² 생성기에만 맞는 상수입니다. 위 toy는 구조 코드와 플로를 손으로 만든 신호라 실제 역변환 잡음의 성질(프레임 간 상관)을 반영하지 않습니다.

## 7. 정리

| 항목 | 내용 |
|---|---|
| 문제 | MegaFS식 잠재 조립은 신원·속성이 얽혀 흐리고 목표 외형을 놓침 |
| 분리 | $$\mathcal{W}+$$ 앞 7 = 구조(포즈·표정·형태), 뒤 11 = 외형(조명·피부) |
| 전이 | $$\hat g_s = g_s + E_{le}(l_s, l_t)$$, $$\hat w_s = [\hat g_s; h_t]$$ → 고정 StyleGAN2 |
| 배경 | 생성기 특징 $$F_s$$와 목표 인코더 특징 $$F_t$$를 얼굴 마스크로 다중 스케일 교체 후 디코더 |
| 손실 | 적대 + ID 2 + 랜드마크 0.1 + 재구성 2 + 히스토그램 매칭 스타일 0.2 |
| 영상 | 코드 궤적(구조 오프셋 일치) + 플로 궤적(시간 라플라시안) 제약 |
| 한계 | 고정 층 분할, 비교 대상 제한, 경계 잔존(E4S 지적) |
