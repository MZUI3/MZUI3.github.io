> Agent 시리즈의 첫 글로, 여러 에이전트가 협력해야 하는 **멀티에이전트 강화학습(MARL)**의 대표 알고리즘 QMIX(Rashid et al., ICML 2018)를 정리합니다. Actor-Critic 기반인 [COMA]({% post_url 2026-09-07-coma %})와 달리 QMIX는 **Q-Learning** 기반입니다.

## 1. 문제 상황: 협력하는 여러 에이전트

스타크래프트에서 마린 5기가 적과 싸운다고 생각해 봅시다.

- 각 마린은 **자기 주변만 볼 수 있고**(partial observation)
- 다른 마린과 **관측을 공유하지 않으며**
- 보상은 팀 전체가 **하나의 팀 보상**으로 받습니다.

실제로 행동할 때(execution)는 각자 자기 관측만으로 움직여야 하지만, 학습할 때(training)는 시뮬레이터에서 전체 상태를 볼 수 있습니다. 이렇게 **학습은 중앙에서, 실행은 분산해서** 하는 틀을 **CTDE**(Centralised Training with Decentralised Execution)라고 합니다.

핵심 질문은 이것입니다.

> 팀 전체의 가치 $$Q_{tot}$$를 학습하면서도, 각 에이전트가 **자기 $$Q_a$$만 보고 행동해도** 팀 전체에 최선인 행동이 나오게 할 수 있을까?

## 2. 이전 방법들

### Independent Q-Learning (IQL)

가장 단순한 방법은 에이전트마다 Q-Learning을 **따로** 돌리는 것입니다.

- Joint action을 전혀 고려하지 않음
- 각 에이전트 입장에서는 다른 에이전트도 같이 학습하며 바뀌기 때문에 환경이 계속 변하는 것처럼 보임 → **non-stationary**
- 2인 Pong 같은 단순한 환경에서는 잘되기도 하지만, 에이전트 수가 늘수록 학습이 불안정해짐

### Value Decomposition Network (VDN)

VDN은 팀 가치를 개별 가치의 **단순 합**으로 분해합니다.

$$
Q_{tot}(\boldsymbol{\tau}, \mathbf{u}) = \sum_{a=1}^{n} Q_a(\tau^a, u^a)
$$

($$\boldsymbol{\tau}$$: joint action-observation history, $$\mathbf{u}$$: joint action)

합이므로 각자 자기 $$Q_a$$를 최대화하면 $$Q_{tot}$$도 최대가 됩니다. 덕분에 중앙 학습이 가능해졌지만 한계가 있습니다.

1. **표현력 부족**: 팀 가치를 단순 합으로만 표현할 수 있어서, 에이전트 간 복잡한 상호작용을 담지 못함
2. **전역 상태 미사용**: 학습 때 볼 수 있는 전체 상태 $$s$$를 활용하지 않음

## 3. QMIX의 핵심: Monotonicity

QMIX는 "단순 합"이라는 조건을 더 넓은 조건으로 바꿉니다. 필요한 건 다음 성질(IGM, Individual-Global-Max)입니다.

$$
\arg\max_{\mathbf{u}} Q_{tot}(\boldsymbol{\tau}, \mathbf{u}) =
\begin{pmatrix}
\arg\max_{u^1} Q_1(\tau^1, u^1) \\
\vdots \\
\arg\max_{u^n} Q_n(\tau^n, u^n)
\end{pmatrix}
$$

즉, **각자가 자기 이익을 최대화하는 것만으로 팀 전체의 최적 행동이 나와야** 합니다. 이걸 보장하는 충분조건으로 QMIX는 **단조성(monotonicity)**을 강제합니다.

$$
\frac{\partial Q_{tot}}{\partial Q_a} \ge 0, \quad \forall a
$$

어떤 에이전트의 $$Q_a$$가 오르면 $$Q_{tot}$$는 절대 내려가지 않는다는 뜻입니다. 단순 합은 이 조건을 만족하는 특수한 경우일 뿐이고, QMIX는 이 조건만 지키면 **비선형 혼합도 허용**합니다.

이렇게 하면 두 가지를 얻습니다.

- 학습 중 $$\max_{\mathbf{u}} Q_{tot}$$를 각자의 argmax로 쉽게 계산할 수 있어 **off-policy 학습이 tractable**해짐
- 중앙 정책과 분산 정책이 **일관성**을 가짐

## 4. 네트워크 구조

QMIX는 세 부분으로 구성됩니다.

### (1) Agent Network

각 에이전트는 DRQN(MLP + GRU + MLP)으로 자기 관측 $$o_t^a$$와 이전 행동 $$u_{t-1}^a$$를 받아 $$Q_a(\tau^a, \cdot)$$를 출력합니다. 부분 관측이라 과거 이력을 기억하기 위해 GRU를 씁니다. 실행할 때는 이 네트워크만 있으면 됩니다.

### (2) Mixing Network

각 에이전트의 $$Q_1, \dots, Q_n$$을 입력받아 $$Q_{tot}$$를 출력하는 작은 feed-forward 네트워크입니다. 단조성을 지키기 위해 **가중치를 모두 0 이상**으로 제한합니다. (ELU 같은 단조 증가 활성 함수와 음이 아닌 가중치의 조합은 단조 함수입니다.)

### (3) Hypernetworks

Mixing network의 가중치와 bias는 직접 학습하지 않고, **전역 상태 $$s$$를 입력받는 hypernetwork가 생성**합니다.

- 가중치를 만드는 hypernetwork 출력에는 **절댓값**을 씌워 non-negative를 보장
- bias는 부호 제한이 없음 (단조성에 영향을 주지 않기 때문)
- 마지막 bias는 2층 네트워크(ReLU 포함)로 생성

왜 상태를 mixing network의 입력으로 그냥 넣지 않을까요? 상태를 직접 입력하면 그 경로의 가중치도 non-negative로 묶여서 **상태가 $$Q_{tot}$$에 영향을 주는 방식이 단조적으로 제한**됩니다. Hypernetwork로 가중치를 만들면 상태는 **임의의 비선형 방식으로** $$Q_{tot}$$에 영향을 줄 수 있습니다.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class QMixer(nn.Module):
    def __init__(self, n_agents, state_dim, embed_dim=32):
        super().__init__()
        self.n_agents, self.embed_dim = n_agents, embed_dim
        # hypernetworks: 상태 s → mixing network의 가중치/bias
        self.hyper_w1 = nn.Linear(state_dim, n_agents * embed_dim)
        self.hyper_b1 = nn.Linear(state_dim, embed_dim)
        self.hyper_w2 = nn.Linear(state_dim, embed_dim)
        self.hyper_b2 = nn.Sequential(
            nn.Linear(state_dim, embed_dim), nn.ReLU(), nn.Linear(embed_dim, 1)
        )

    def forward(self, agent_qs, state):
        # agent_qs: (B, n_agents), state: (B, state_dim)
        B = agent_qs.size(0)
        w1 = torch.abs(self.hyper_w1(state)).view(B, self.n_agents, self.embed_dim)  # ≥ 0
        b1 = self.hyper_b1(state).view(B, 1, self.embed_dim)
        hidden = F.elu(torch.bmm(agent_qs.unsqueeze(1), w1) + b1)                   # (B, 1, E)

        w2 = torch.abs(self.hyper_w2(state)).view(B, self.embed_dim, 1)             # ≥ 0
        b2 = self.hyper_b2(state).view(B, 1, 1)
        q_tot = torch.bmm(hidden, w2) + b2
        return q_tot.view(B)

# 단조성 확인: Q_tot를 각 Q_a로 미분한 값이 모두 0 이상인가?
torch.manual_seed(0)
mixer = QMixer(n_agents=3, state_dim=10)
agent_qs = torch.randn(4, 3, requires_grad=True)     # 배치 4, 에이전트 3
state = torch.randn(4, 10)
mixer(agent_qs, state).sum().backward()
print(agent_qs.grad)                  # 모든 원소가 양수
print((agent_qs.grad >= 0).all())     # tensor(True)
```

가중치는 무작위로 초기화했지만 $$\partial Q_{tot} / \partial Q_a$$가 모두 양수로 나옵니다. 단조성이 학습 결과가 아니라 **네트워크 구조(절댓값 + 단조 증가 활성 함수)로 보장**된다는 뜻입니다.

## 5. 학습

DQN과 같은 방식으로 replay buffer에 transition $$\langle s, \mathbf{u}, r, s' \rangle$$을 저장하고, 대상이 **$$Q_{tot}$$**라는 점만 다릅니다.

$$
\mathcal{L}(\theta) = \sum_{i=1}^{b}\left[\left(y_i^{tot} - Q_{tot}(\boldsymbol{\tau}, \mathbf{u}, s;\theta)\right)^2\right]
$$

$$
y^{tot} = r + \gamma \max_{\mathbf{u}'} Q_{tot}(\boldsymbol{\tau}', \mathbf{u}', s';\theta^-)
$$

$$\theta^-$$는 target network 파라미터입니다. 여기서 $$\max_{\mathbf{u}'}$$는 원래 joint action 전체를 탐색해야 하지만(에이전트 수에 대해 지수적), **단조성 덕분에 각 에이전트의 argmax만 구하면** 됩니다. 이것이 QMIX가 실용적인 이유입니다.

전체 loss는 팀 보상 하나로 end-to-end 학습되며, agent network와 mixing network가 함께 업데이트됩니다.

## 6. 실험

### Two-Step Game: 표현력 비교

두 에이전트가 첫 step의 선택에 따라 서로 다른 보상 행렬의 게임(State 2A, 2B)으로 넘어가는 간단한 게임입니다. 2B에서는 협력해서 특정 조합을 골라야 높은 보상(8)을 얻습니다.

- **VDN**: 단순 합으로는 2B의 보상 구조를 표현하지 못해 오차가 크고, 최적이 아닌 전략에 머묾
- **QMIX**: 비선형 혼합으로 보상 구조를 거의 정확히 표현하고 최적 전략을 학습

### StarCraft II 마이크로 컨트롤

| 맵 | 구성 |
|---|---|
| 3m / 5m / 8m | 마린 3·5·8기 |
| 2s3z | 스토커 2 + 질럿 3 |
| 3s5z | 스토커 3 + 질럿 5 |
| 1c3s5z | 거신 1 + 스토커 3 + 질럿 5 |

- 행동: `move[방향]`, `attack[적 ID]`, `stop`, `no-op`
- 자동 공격 같은 게임 내장 매크로는 끄고 강화학습 능력만 평가
- 팀 보상: 입힌 피해량 + 적 처치 시 10점 + 전멸 시 200점, 최댓값 20으로 정규화

**결과**

- **IQL**: 다른 에이전트의 학습으로 환경이 계속 변해 학습이 매우 불안정
- **VDN**: IQL보다 좋고, 5m·8m처럼 **집중 사격(focus fire)**이 핵심인 맵에서 강함. 하지만 정교한 컨트롤이 필요한 3m에서는 약함
- **QMIX**: 모든 맵에서 가장 좋은 성능. 특히 **역할이 다른 유닛이 섞인** 3s5z, 1c3s5z처럼 에이전트가 많고 이질적인 맵에서 격차가 큼

### Ablation

| 변형 | 내용 | 결과 |
|---|---|---|
| QMIX-NS | Hypernetwork 없이 mixing 가중치를 상태와 무관하게 학습 | VDN과 비슷하거나 약간 나음 |
| QMIX-Lin | Mixing network의 hidden layer 제거 (선형 혼합) | QMIX보다 낮음 |
| VDN-S | VDN에 상태 의존 항 $$V(s)$$를 추가 | 일부 맵(3m)에서 QMIX 이상 |

결론적으로 **비선형 혼합**과 **hypernetwork를 통한 전역 상태 활용**이 **둘 다** 있어야 성능이 나옵니다. 상태 정보 없이 비선형 혼합만 하는 것은 항상 도움이 되지는 않습니다.

## 7. 정리

| | IQL | VDN | QMIX |
|---|---|---|---|
| 팀 가치 | 없음 | $$\sum_a Q_a$$ | 단조 비선형 혼합 |
| 전역 상태 활용 | ✕ | ✕ | ○ (hypernetwork) |
| 분산 실행 일관성 | ✕ | ○ | ○ |
| 표현력 | 낮음 | 제한적 | 더 넓음 |

QMIX의 한계도 분명합니다. 단조성은 IGM의 **충분조건일 뿐 필요조건은 아니라서**, 한 에이전트의 선택에 따라 다른 에이전트의 최적 행동이 뒤바뀌는(non-monotonic) 문제는 표현하지 못합니다.

후속 연구에서 자주 쓰는 예시가 다음 보상 행렬입니다(에이전트 1이 행, 에이전트 2가 열을 고름).

| | A | B | C |
|---|---|---|---|
| **A** | **8** | -12 | -12 |
| **B** | -12 | 0 | 0 |
| **C** | -12 | 0 | 0 |

최적은 둘 다 A를 골라 8을 받는 것이지만, 한쪽만 A를 고르면 -12라는 큰 벌을 받습니다. 에이전트 1 입장에서 "A가 좋다"는 평가가 **상대가 무엇을 고르느냐에 따라 뒤집히므로**, $$Q_{tot}$$를 개별 Q의 단조 함수로 쓰면 이 구조를 정확히 표현할 수 없고 QMIX는 (B, B) 같은 안전한 차선책에 머물기 쉽습니다. 이 한계를 다룬 연구로 QTRAN(Son et al., 2019), Weighted QMIX(Rashid et al., 2020), QPLEX(Wang et al., 2021) 등이 있습니다.
