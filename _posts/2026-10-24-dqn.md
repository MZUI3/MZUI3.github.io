> 2013년 이전 강화학습의 성공은 대부분 손으로 만든 특징 위의 선형 가치 함수였고, TD-Gammon의 신경망 성공은 주사위의 확률성 덕분인 특수 사례로 여겨졌습니다. 비선형 함수 근사와 Q-러닝, 오프폴리시 학습을 섞으면 발산한다는 결과(Tsitsiklis & Van Roy, Baird)가 있어 연구는 수렴이 보장되는 선형 근사에 머물렀습니다. **Playing Atari with Deep Reinforcement Learning**(Mnih, Kavukcuoglu, Silver, Graves, Antonoglou, Wierstra, Riedmiller, DeepMind, 2013)은 이 통념을 깹니다. 원시 픽셀을 받는 CNN을 Q-러닝으로 학습해, 구조와 하이퍼파라미터를 바꾸지 않고 7개 Atari 2600 게임에서 6개는 기존 방법을, 3개(Breakout, Enduro, Pong)는 인간 전문가를 넘었습니다. 핵심 장치는 **경험 재생**(experience replay)입니다.

## 1. 심층 학습 관점에서 본 RL의 난점

세 가지입니다. (1) 지도 학습에는 대량의 라벨이 있지만 RL의 보상은 **희소하고 잡음 많고 지연**되며, 행동과 보상 사이가 수천 스텝일 수 있습니다. (2) 심층 학습은 표본의 **독립성**을 가정하지만 RL은 강하게 상관된 상태 열을 만납니다. (3) RL에서는 정책이 바뀌면 **데이터 분포도 바뀌어** 고정 분포를 가정하는 방법에 문제가 됩니다.

## 2. 배경: Q-러닝과 Q-네트워크

최적 행동 가치 $$Q^*(s, a) = \max_\pi \mathbb{E}[R_t \mid s_t = s, a_t = a, \pi]$$는 벨만 방정식 $$Q^*(s,a) = \mathbb{E}_{s'}[r + \gamma \max_{a'} Q^*(s', a') \mid s, a]$$를 만족하고, 이를 반복 갱신으로 쓰는 가치 반복은 수렴하지만 열마다 따로 추정해 일반화가 없습니다. 가중치 $$\theta$$의 신경망 Q-네트워크는 반복 $$i$$마다 손실

$$
L_i(\theta_i) = \mathbb{E}_{s,a \sim \rho}\big[(y_i - Q(s,a;\theta_i))^2\big], \qquad y_i = \mathbb{E}_{s'}\big[r + \gamma \max_{a'} Q(s', a'; \theta_{i-1})\big]
$$

를 최소화합니다. 목표 $$y_i$$가 네트워크 가중치에 의존한다는 점이 지도 학습과 다르며, 이전 반복의 $$\theta_{i-1}$$을 고정합니다. 기댓값을 단일 표본으로 바꾸고 매 스텝 갱신하면 익숙한 Q-러닝이 됩니다. 모델 프리이고, $$\epsilon$$-탐욕 행동 분포를 따르면서 탐욕 정책을 배우는 **오프폴리시**입니다.

## 3. 방법: 심층 Q-러닝

### 경험 재생

매 스텝의 경험 $$e_t = (s_t, a_t, r_t, s_{t+1})$$을 재생 메모리 $$\mathcal{D}$$(최근 100만 프레임)에 저장하고, 갱신 때 $$\mathcal{D}$$에서 **무작위 미니배치**(32개)를 뽑아 Q-러닝 갱신을 합니다. 그 뒤 $$\epsilon$$-탐욕으로 행동을 고릅니다. TD-Gammon 같은 온라인 방식에 비해 세 가지 이점이 있습니다.

1. **데이터 효율.** 각 경험이 여러 번의 가중치 갱신에 쓰입니다.
2. **상관 제거.** 연속 표본은 강하게 상관되어 비효율적이고, 무작위 추출이 상관을 깨어 갱신의 분산을 줄입니다.
3. **피드백 루프 차단.** 온폴리시 학습에서는 현재 파라미터가 다음 학습 표본을 정합니다. 최대화 행동이 왼쪽이면 표본이 왼쪽에 쏠리고, 오른쪽으로 바뀌면 분포도 바뀌어 원치 않는 피드백 루프로 나쁜 국소 최솟값에 갇히거나 발산할 수 있습니다. 재생은 행동 분포를 과거 여러 상태에 걸쳐 평균해 진동과 발산을 막습니다.

재생으로 학습하면 표본을 만든 파라미터와 현재 파라미터가 다르므로 **오프폴리시**여야 하고, 이것이 Q-러닝을 택한 이유입니다. 메모리는 중요한 전이를 구분하지 않고 최근 것으로 덮어쓰며 균일하게 뽑는다는 한계가 있고, 우선순위 스위핑 같은 정교한 방식을 향후 과제로 남깁니다.

### 전처리와 구조

210×160 RGB 프레임을 회색조 110×84로 줄이고 플레이 영역 84×84를 잘라 **최근 4프레임을 쌓아** 입력으로 씁니다(함수 $$\phi$$). 구조는 8×8 stride 4 필터 16개 + ReLU, 4×4 stride 2 필터 32개 + ReLU, 256유닛 FC + ReLU, 그리고 **행동마다 하나의 출력**을 내는 선형층입니다. 상태와 행동을 함께 입력하는 기존 방식은 행동마다 순전파가 필요하지만, 이 구조는 **한 번의 순전파로 모든 행동의 Q**를 얻습니다. 행동 수는 게임마다 4~18개입니다.

### 학습 세부

보상의 스케일이 게임마다 크게 달라 양의 보상은 1, 음은 −1로 **클리핑**해 같은 학습률을 쓸 수 있게 합니다(크기 차이를 구분 못 하는 대가). RMSProp, 미니배치 32, $$\epsilon$$은 첫 100만 프레임 동안 1에서 0.1로 선형 감소 후 고정, 총 1,000만 프레임. 프레임 스킵 $$k = 4$$(Space Invaders만 레이저가 보이도록 3)로 에이전트는 4프레임마다 행동하고 그 사이 반복합니다.

## 4. 코드로 보기: 경험 재생과 표본 상관

12칸 복도(5번 칸에 함정, 11번 칸에 보상)에서 작은 Q-네트워크를 (a) 온라인 Q-러닝, (b) 최근 전이만 담은 작은 버퍼, (c) 균일 경험 재생으로 5개 시드씩 학습하고, 연속 학습 표본의 상태 상관을 잽니다.

```python
import torch, torch.nn as nn, torch.nn.functional as F, numpy as np, random
torch.set_num_threads(1)
# a tiny deterministic corridor MDP: 12 cells, start at 0, reward +1 at cell 11, -1 at the trap in cell 5 (jump over it)
N = 12
def step(s, a):                      # actions: 0 = left, 1 = right, 2 = jump right by 2
    s2 = max(0, min(N - 1, s + [-1, 1, 2][a]))
    r = 1.0 if s2 == N - 1 else (-1.0 if s2 == 5 else -0.01)
    return s2, r, s2 in (5, N - 1)
def onehot(s): v = torch.zeros(N); v[s] = 1; return v
def run(mode, seed, episodes=150):
    torch.manual_seed(seed); random.seed(seed); np.random.seed(seed)
    q = nn.Sequential(nn.Linear(N, 64), nn.ReLU(), nn.Linear(64, 3)); opt = torch.optim.Adam(q.parameters(), 3e-3)
    buf = []; gamma = 0.95; returns = []
    for ep in range(episodes):
        s, done, G, t = 0, False, 0.0, 0; eps = max(0.05, 1 - ep / 80)
        while not done and t < 40:
            a = random.randrange(3) if random.random() < eps else int(q(onehot(s)).argmax())
            s2, r, done = step(s, a); G += r; t += 1
            buf.append((s, a, r, s2, done)); buf = buf[-5000:]
            if mode == "online": batch = buf[-1:]                                   # the classic online update: this transition only
            elif mode == "recent": batch = buf[-32:]                                # the last 32 (correlated) transitions
            else: batch = random.sample(buf, min(32, len(buf)))                      # experience replay
            S = torch.stack([onehot(b[0]) for b in batch]); A = torch.tensor([b[1] for b in batch]); R = torch.tensor([b[2] for b in batch])
            S2 = torch.stack([onehot(b[3]) for b in batch]); D = torch.tensor([float(b[4]) for b in batch])
            with torch.no_grad(): y = R + gamma * (1 - D) * q(S2).max(1).values
            loss = F.mse_loss(q(S).gather(1, A[:, None]).squeeze(1), y); opt.zero_grad(); loss.backward(); opt.step()
            s = s2
        returns.append(G)
    s, done, G, t = 0, False, 0.0, 0                     # greedy evaluation
    while not done and t < 40:
        s, r, done = step(s, int(q(onehot(s)).argmax())); G += r; t += 1
    return np.mean(returns[-30:]), G
print("deep Q-learning on a 12-cell corridor with a trap (5 seeds): mean return of the last 30 episodes and the greedy return")
for mode in ("online", "recent", "replay"):
    res = [run(mode, s) for s in range(5)]
    print(f"  {mode:<7}: train return {np.mean([r[0] for r in res]):6.2f}, greedy return {np.mean([r[1] for r in res]):6.2f}, solved seeds {sum(r[1] > 0.5 for r in res)}/5")
seq = [s % N for s in range(2000)]                        # a trajectory that walks through neighbouring states
rng = np.random.default_rng(0); sh = rng.permutation(seq)
print(f"\nstate correlation between consecutive training samples: on-policy stream {np.corrcoef(seq[:-1], seq[1:])[0,1]:.2f}, uniform replay {np.corrcoef(sh[:-1], sh[1:])[0,1]:.2f}")
```

```text
deep Q-learning on a 12-cell corridor with a trap (5 seeds): mean return of the last 30 episodes and the greedy return
  online : train return   0.90, greedy return   0.95, solved seeds 5/5
  recent : train return   0.75, greedy return   0.68, solved seeds 4/5
  replay : train return   0.70, greedy return   0.41, solved seeds 3/5

state correlation between consecutive training samples: on-policy stream 0.54, uniform replay -0.01
```

- 연속 표본의 상태 상관은 온폴리시 스트림에서 0.54, 균일 재생에서 −0.01입니다. 재생이 상관을 깬다는 두 번째 이점은 그대로 확인됩니다.
- 그러나 이 toy에서는 **재생이 성능을 높이지 않습니다.** 온라인 학습이 5/5 시드를 풀고 탐욕 수익 0.95인데, 재생은 3/5, 0.41입니다. 결정적이고 상태가 12개뿐인 문제는 상관된 표본으로도 쉽게 배우고, 오히려 초기의 무작위 전이가 버퍼에 오래 남아 학습을 늦춥니다. 경험 재생의 이점은 상관과 비정상성이 실제로 학습을 망치는 **고차원·긴 지평선** 환경에서 나타나는 것이고, 논문의 주장이 이 toy로 반증되는 것은 아닙니다. 재현되지 않은 결과로 그대로 보고합니다.

## 5. 실험

**학습 안정성.** 에피소드 평균 보상은 정책의 작은 변화가 방문 상태 분포를 크게 바꾸어 매우 잡음이 많습니다. 대신 학습 전 무작위 정책으로 모은 고정 상태 집합에 대한 **최대 예측 Q의 평균**을 추적하면 훨씬 매끄럽게 증가하고, 모든 실험에서 발산이 없었습니다. 수렴 보장은 없지만 큰 네트워크를 RL 신호와 SGD로 안정적으로 학습할 수 있다는 증거입니다. Seaquest의 가치 함수 시각화는 적이 나타나면 예측 가치가 뛰고, 어뢰가 명중 직전에 정점을 찍고, 적이 사라지면 원래로 돌아오는 합리적 변화를 보여 줍니다.

**주요 평가(ε=0.05 고정 스텝 평균 점수).**

| | B. Rider | Breakout | Enduro | Pong | Q*bert | Seaquest | S. Invaders |
|---|---|---|---|---|---|---|---|
| Random | 354 | 1.2 | 0 | −20.4 | 157 | 110 | 179 |
| Sarsa | 996 | 5.2 | 129 | −19 | 614 | 665 | 271 |
| Contingency | 1743 | 6 | 159 | −17 | 960 | 723 | 268 |
| **DQN** | **4092** | **168** | **470** | **20** | **1952** | **1705** | **581** |
| Human | 7456 | 31 | 368 | −3 | 18900 | 28010 | 3690 |

Sarsa와 Contingency는 배경 제거와 128색을 별도 채널로 쓰는 상당한 사전 지식을 넣었는데도 DQN이 7개 모두에서 큰 차이로 앞섭니다. 진화 탐색 HNeat는 결정적 상태 열의 취약점을 이용하므로 최고 단일 에피소드만 보고하는데, DQN은 Space Invaders를 제외한 모든 게임에서 평균 점수로도 HNeat 최고치를 넘습니다. Breakout, Enduro, Pong에서 인간을 넘고 Beam Rider는 근접하지만, 긴 시간 스케일의 전략이 필요한 Q*bert, Seaquest, Space Invaders는 인간에 한참 못 미칩니다.

## 6. 해석

**1. 심층 RL의 시작점입니다.** "비선형 근사 + Q-러닝 + 오프폴리시는 발산한다"는 통념을 공학적 장치로 우회했고, 2015년 Nature 버전은 **목표 네트워크**(target network)를 더해 49개 게임으로 확장합니다. 이후 [Double DQN]({% post_url 2026-08-04-double-dqn %})이 과대추정을, 우선순위 재생이 균일 추출의 한계를, 듀얼링이 구조를, 그리고 [Rainbow]({% post_url 2026-10-23-rainbow %})가 이 모두를 합칩니다. 논문이 향후 과제로 적은 "우선순위 스위핑 같은 정교한 추출"이 우선순위 재생이라는 다음 논문이 된 셈입니다.

**2. 경험 재생의 세 번째 이점이 가장 깊습니다.** 데이터 효율과 상관 제거는 직관적이지만, "현재 파라미터가 다음 데이터를 정한다"는 피드백 루프의 지적은 온폴리시 심층 RL의 본질적 불안정성을 짚습니다. 위 toy가 보여 주듯 작은 문제에서는 이 루프가 해롭지 않지만, 고차원에서는 치명적입니다. 반대로 재생을 쓰려면 오프폴리시여야 한다는 제약이 이후 PPO류 온폴리시 방법과의 분기점이 됩니다.

**3. 평가 방법론이 분야의 관행이 됐습니다.** 게임마다 구조·하이퍼파라미터를 바꾸지 않는 원칙, 인간 점수 대비 보고, ε=0.05 평가, 그리고 보상 대신 평균 Q를 학습 지표로 쓰는 관찰은 이후 Atari 벤치마크의 표준이 됩니다. 보상 클리핑은 편리하지만 크기 정보를 버리는 대가가 있고, 이후 Pop-Art와 값 변환으로 보완됩니다.

**4. 한계는 긴 지평선입니다.** 인간에 크게 못 미친 세 게임은 모두 장기 전략이 필요합니다. 4프레임 스택은 짧은 기억이고, 탐험은 ε-탐욕뿐입니다. 이 간극은 [계층적 DQN]({% post_url 2026-10-08-h-dqn %}), 내재적 동기, 그리고 [EfficientZero]({% post_url 2026-08-21-efficientzero %}) 같은 모델 기반 방법이 다룹니다.

**5. 평가를 읽을 때 주의할 점.** 7개 게임만 다룬 워크숍 논문이고, 인간 점수는 약 2시간 플레이 후 중앙값이라 Bellemare 등의 수치보다 훨씬 높습니다. 수렴 보장은 없고 "발산을 경험하지 않았다"는 관찰입니다. 목표 네트워크가 없어 Nature 버전보다 불안정하며, 시드 수나 분산은 보고되지 않았습니다. 위 toy의 결과는 재생의 이점이 환경에 따라 다르다는 점을 보여 줄 뿐, 논문의 설정과는 규모가 다릅니다.
