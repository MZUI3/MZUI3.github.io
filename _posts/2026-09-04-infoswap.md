> 교체 결과의 신원은 소스와 같고 목표와는 **달라야** 합니다. 그런데 목표의 포즈·표정·조명(지각 정보)을 가져올 때 목표의 신원이 섞여 들어오면 "둘을 섞은 제3의 인물"이 됩니다. [FaceShifter]({% post_url 2026-08-18-faceshifter %})·[SimSwap]({% post_url 2026-08-31-simswap %})을 포함한 기존 방법은 여러 손실 항으로 이를 **암묵적으로** 억제했을 뿐 분리에 대한 명시적 감독이 없었습니다. **InfoSwap**(Gao, Huang, Fu, Li, He, CASIA, CVPR 2021)은 분리를 **정보 병목(IB)** 문제로 정식화합니다. 사전학습 인식기의 중간 특징에서 신원을 예측하는 데 필요한 최소 충분 통계만 남기고 나머지를 비트 단위로 압축하면, 압축된 부분이 곧 신원 무관 지각 정보라는 것입니다. 여기에 "소스에는 가깝고 목표와는 적당히 멀어야 한다"는 **신원 대조 손실**을 더해, 판별적 신원이라는 새 지표에서 큰 차이로 앞섭니다.

## 1. 판별적 신원의 정의

소스-목표 신원 코사인 유사도의 평균 $$\mu_{s,t}$$와 표준편차 $$\sigma_{s,t}$$, $$\delta_{s,t} = \arccos \sigma_{s,t}$$에 대해, 생성 신원이 $$z^s_{id} \pm k\delta_{s,t}$$의 좁은 각 안에 있으면 목표와의 유사도는 $$\mu_{s,t} \pm 3\sigma_{s,t}$$ 안에 머뭅니다. 가짜-소스 유사도와 가짜-목표 유사도의 구간 추정이 **겹치지 않으면** 판별적입니다. 겹친다는 것은 일부 가짜가 소스와 목표의 각 이등분선 위에, 즉 둘에 똑같이 닮게 놓였다는 뜻입니다.

## 2. IIB: 정보 신원 병목

고정 인식기 $$f$$의 512차원 임베딩 $$z_{id} = f(X)$$와 앞 $$m = 10$$개 층의 내부 특징 $$R = \{R_1, \dots, R_m\}$$을 씁니다. IB의 목적 $$\min I(X;R) - \beta I(R;Y)$$를 교체에 맞게 $$\mathcal{L}_{IB} = \mathcal{L}_{info} + \beta \mathcal{L}_{task}$$로 둡니다.

**압축.** 병목 $$IB_i$$가 모든 내부 특징에서 $$R_i$$와 같은 크기의 **정보 제어기** $$\lambda_i \in [0,1]$$을 예측하고, $$R_i$$와 같은 평균·분산의 가우시안 잡음 $$\epsilon_i$$를 섞습니다.

$$
Z_i = \lambda_i R_i + (1 - \lambda_i)\epsilon_i, \qquad
I(Z_i; R_i) = -\log(1-\lambda_i)^2 + \tfrac12\Big[(1-\lambda_i)^2 + \big(\lambda_i \tfrac{R_i - \mu_{R_i}}{\sigma_{R_i}}\big)^2 - 1\Big]
$$

$$\lambda_i = 0$$이면 $$Z_i = \epsilon_i$$로 0비트, 1이면 전부 보존입니다. $$\lambda$$는 주의 맵이 아니라 **상호 정보로 잰 각 영역의 기여(비트)**라고 저자들은 강조합니다. $$\mathcal{L}_{info} = \frac1m\sum_i I(Z_i; R_i)$$.

**과제 손실.** $$\mathcal{L}_{recog} = 1 - \cos(\tilde z_{id}, z_{id})$$는 병목을 하나씩 끼운 네트워크들의 압축 임베딩 평균 $$\tilde z_{id}$$가 원래 신원을 유지하도록 하고, **ICL** $$\mathcal{L}_{icl} = \mathcal{L}_{pos} + \mathcal{L}_{neg}$$는 픽셀 공간의 결과 $$Y_{s,t}$$에 대해

$$
\mathcal{L}_{pos} = -\cos\langle \tilde z_{id}(Y_{s,t}), \tilde z_{id}(X_s)\rangle, \qquad
\mathcal{L}_{neg} = \big[\cos\langle \tilde z_{id}(Y_{s,t}), \tilde z_{id}(X_t)\rangle - \cos\langle \tilde z_{id}(X_s), \tilde z_{id}(X_t)\rangle\big]^2
$$

입니다. 목표와의 거리를 0으로 밀지 않고 **소스-목표 각도 마진**을 기준으로 삼는 점이 보통의 대조 손실과 다릅니다.

## 3. AII: 적응적 정보 통합

목표의 지각 특징은 제어기를 **반대로** 써서 $$f^t_i = \lambda^t_i \epsilon^s_i + (1 - \lambda^t_i) R^t_i$$로 만듭니다(신원에 무관한 영역만 남김, 잡음 통계는 소스 쪽). U-Net 디코더 $$dec$$로 $$f^t_i$$와 $$\lambda^t_i$$의 공간 크기를 키워 512·1024 해상도를 지원하고, AdaIN처럼 소스 신원 $$\tilde z^s_{id}$$와 지각 특징 $$\tilde f^t_i$$에서 아핀 파라미터를 만든 신원 활성 $$I^s_i$$와 지각 활성 $$P^t_i$$를 **통합기** $$\Lambda^t_i = T_{\theta_i}(\tilde\lambda^t_i, h^{i+1}) \in [0,1]$$로 섞습니다: $$h^i = \Lambda^t_i I^s_i + (1 - \Lambda^t_i) P^t_i$$. FaceShifter의 AAD 마스크가 이전 활성에서만 나오는 것과 달리, 이미 상호 정보로 배운 $$\tilde\lambda$$를 입력으로 쓰므로 더 근거 있는 통합이라는 것이고 ablation으로 확인합니다. 추가 손실은 상대적 적대 손실, 다중 수준 지각 손실(결과의 지각 특징 대 목표의), 순환 일관성(결과의 신원 + 소스의 지각 특징으로 소스 복원)입니다. 학습에는 FFHQ와 CelebA-HQ를 512×512로 정렬·크롭한 9.6만 장을 씁니다.

## 4. 코드로 보기: 병목이 신원 차원만 고른다

12차원 내부 특징 중 앞 4차원만 신원 임베딩에 쓰이는 고정 "인식기"에서, 2절의 상호 정보 식(논문 식 (6))과 코사인 인식 손실로 $$\lambda$$를 최적화해 어느 차원이 몇 비트를 유지하는지 보고($$\beta$$ 두 값), 세 가지 혼합 비율의 가짜 신원에 대해 ICL의 두 항을 계산합니다.

```python
import torch, torch.nn.functional as F
torch.manual_seed(0); torch.set_num_threads(1)
# a frozen 'face recogniser': 12-dim internal feature R; the identity z_id = W R uses only the first 4 dims, the other 8 carry pose/lighting
D = 12; W = torch.zeros(4, D); W[:, :4] = torch.eye(4)
def batch(n): id_part = torch.randn(n, 4); other = torch.randn(n, 8) * 1.5; return torch.cat([id_part, other], 1)
R = batch(4096); mu, sig = R.mean(0), R.std(0); z_id = R @ W.T
# information bottleneck: Z = lam * R + (1 - lam) * eps,  eps ~ N(mu, sig^2);  minimise I(Z;R) + beta * recognition loss
lam_logit = torch.zeros(D, requires_grad=True); opt = torch.optim.Adam([lam_logit], 0.05)
def mutual_info(lam, R):     # eq. (6): KL[p(Z|R) || p(Z)] for the Gaussian noise injection, in nats, averaged over the batch
    rn = (R - mu) / sig
    return (-torch.log((1 - lam) ** 2 + 1e-8) + 0.5 * ((1 - lam) ** 2 + (lam * rn) ** 2 - 1)).mean(0)
for beta in (1.0, 10.0):
    lam_logit.data.zero_()
    for s in range(1500):
        lam = torch.sigmoid(lam_logit); eps = mu + sig * torch.randn_like(R); Z = lam * R + (1 - lam) * eps
        recog = 1 - F.cosine_similarity(Z @ W.T, z_id, dim=1).mean()
        loss = mutual_info(lam, R).mean() + beta * recog; opt.zero_grad(); loss.backward(); opt.step()
    lam = torch.sigmoid(lam_logit).detach(); mi = mutual_info(lam, R) / torch.log(torch.tensor(2.0))
    print(f"beta = {beta:>4}: lambda on identity dims {lam[:4].numpy().round(2)}, on identity-irrelevant dims {lam[4:].numpy().round(2)}")
    print(f"            information kept per dim (bits): identity {mi[:4].numpy().round(2)}, irrelevant {mi[4:].numpy().round(2)}; recognition loss {recog.item():.4f}")
print("-> the bottleneck keeps only the dims that predict identity; the discarded dims (lambda -> 0, 0 bits) are the 'perceptual' information handed to the target branch")
# identity contrastive loss: the swapped identity should sit near the source but at the source-target distance from the target
zs, zt = F.normalize(torch.randn(3, 64), dim=1), F.normalize(torch.randn(3, 64), dim=1)
for mix in (0.5, 0.8, 1.0):
    zy = F.normalize(mix * zs + (1 - mix) * zt, dim=1)
    pos = -F.cosine_similarity(zy, zs, dim=1).mean(); neg = ((F.cosine_similarity(zy, zt, dim=1) - F.cosine_similarity(zs, zt, dim=1)) ** 2).mean()
    print(f"swapped identity = {mix:.1f} source + {1-mix:.1f} target: L_pos {pos:.3f}, L_neg {neg:.3f}  (ICL = L_pos + L_neg)")
```

```text
            information kept per dim (bits): identity [1.73 1.77 1.84 1.8 ], irrelevant [0. 0. 0. 0. 0. 0. 0. 0.]; recognition loss 0.3098

```

- 신원 무관 8차원의 $$\lambda$$는 두 $$\beta$$ 모두에서 정확히 0(0비트)이 되고, 신원 4차원은 $$\beta = 1$$에서 0.52(1.8비트), $$\beta = 10$$에서 0.82(4.8비트)를 유지합니다. 압축 항과 과제 항의 트레이드오프 파라미터 $$\beta$$가 "신원 정보를 얼마나 선명하게 남길지"를 정하고, 버려진 차원이 곧 지각 정보라는 분리가 별도의 분리 레이블 없이 IB 목적만으로 나옵니다. IB 원리가 곧 "분리에 대한 명시적 감독"이 된다는 것이 논문의 주장입니다.
- 가짜 신원이 소스와 목표의 50:50 혼합이면 $$\mathcal{L}_{neg} = 0.51$$로 크고, 80:20이면 0.06, 순수 소스면 0입니다. $$\mathcal{L}_{pos}$$만으로는 80:20도 −0.97로 거의 만족이지만 $$\mathcal{L}_{neg}$$가 "목표에서 소스-목표 거리만큼 떨어져라"를 추가로 요구합니다. 판별적 신원의 정의가 손실로 바뀐 것입니다.

## 5. 실험

**정량(FF++, FaceShifter 프로토콜).**

| 방법 | ID 검색 ↑ | 포즈 ↓ | 표정 ↓ |
|---|---|---|---|
| FSGAN | 60.41 | 0.626 | 0.028 |
| DeepFakes | 81.96 | 1.092 | 0.114 |
| FaceSwap | 54.19 | 0.488 | 0.029 |
| DiscoFaceGAN | 93.12 | 1.197 | 0.159 |
| FaceShifter | 97.38 | 0.511 | 0.032 |
| InfoSwap | **99.67** | **0.443** | 0.030 |

신원·포즈 모두 최고이고 표정은 FSGAN·FaceSwap에 근접합니다(표정은 다른 추정기를 써서 FaceShifter 논문의 수치와 스케일이 다릅니다).

**판별적 신원.** 가짜-소스와 가짜-목표 유사도의 통계로 겹침을 재면 InfoSwap이 가장 작습니다. 얼굴 형태가 소스에 가깝다는 정성 관찰(Figure 1)이 이에 대응합니다. **IB 분석**에서 $$\lambda$$를 시각화하면 눈·코·입 주변이 1에 가깝고 배경·머리는 0에 가깝습니다. **Ablation**은 ICL, 통합기에 $$\tilde\lambda$$를 쓰는 것, 순환 손실이 각각 신원 판별성에 기여함을 보입니다. 1024×1024 결과도 제시됩니다.

## 6. 해석

**1. 분리를 "손실 조합"에서 "정보 이론"으로 옮겼습니다.** 신원 벡터를 그냥 쓰는 FaceShifter·SimSwap과 달리, 인식기의 **중간 특징** 안에서 신원에 기여하는 부분과 아닌 부분을 상호 정보로 가르고, 후자를 목표 속성 표현으로 **재활용**합니다. 인코더를 새로 학습하지 않고 고정 인식기 하나로 두 표현을 얻는 것이 효율적이고, [RAFSwap]({% post_url 2026-10-06-rafswap %})이 지적한 "인식 벡터는 분리가 덜 되어 있다"는 문제를 정면으로 다룬 셈입니다.

**2. ICL은 "신원 손실 = 소스 코사인"의 관행을 바꿨습니다.** 결과가 목표를 닮는 것을 명시적으로 벌하되, 거리를 0이 아니라 소스-목표 거리로 정한 설계는 과도한 신원 강조(표정 붕괴)도 피합니다. [Smooth-Swap]({% post_url 2026-10-07-smooth-swap %})의 상대 거리 지표(-R)와 같은 발상이 손실로 들어온 것입니다.

**3. 판별적 신원이라는 지표가 새로 제안됐습니다.** ID 검색은 "소스 영상 중 하나에 가장 가까우면" 성공이라 관대하지만, 유사도 분포의 겹침은 "목표와도 닮은 중간 얼굴"을 잡아냅니다. 이후 [E4S]({% post_url 2026-10-09-e4s %})가 "in-between effect"라고 부른 문제를 먼저 수치화한 것입니다.

**4. 한계는 복잡성과 인식기 의존입니다.** 병목 10개, 통합기 10개, 다단계 미세조정이 필요해 [StyleSwap]({% post_url 2026-10-08-styleswap %})은 "세심한 손실 설계와 여러 데이터셋의 다단계 미세조정에 의존"한다고 평합니다. 또 지각 정보의 정의가 "인식기가 신원 예측에 안 쓰는 것"이라, 인식기가 조명·포즈 일부를 신원에 쓰면 그만큼 속성이 샙니다.

**5. 평가를 읽을 때 주의할 점.** 표정 수치는 추정기가 달라 FaceShifter 논문의 표와 직접 비교할 수 없고, 포즈도 마찬가지로 재계산된 것입니다. 판별적 신원 지표는 저자들이 정의한 것입니다. 위 toy는 신원 차원이 처음부터 분리된 선형 설정이라 병목의 "발견"이 쉬웠고, 실제 특징에서는 신원과 지각이 같은 뉴런에 섞여 있어 $$\lambda$$가 0/1로 깨끗하게 갈리지 않습니다.

## 7. 정리

| 항목 | 내용 |
|---|---|
| 문제 | 목표 지각 정보에 섞인 목표 신원이 결과를 "중간 인물"로 만듦, 분리의 명시적 감독 부재 |
| IIB | 고정 인식기 중간 특징 $$R_i$$에 $$\lambda_i$$로 잡음 혼합, $$I(Z_i;R_i)$$(비트) 최소화 + 인식 유지 + ICL |
| ICL | $$-\cos(\text{결과}, \text{소스}) + [\cos(\text{결과}, \text{목표}) - \cos(\text{소스}, \text{목표})]^2$$ |
| AII | 제어기를 반대로 써 지각 특징 추출, U-Net 확대, 통합기 $$\Lambda = T(\tilde\lambda, h)$$로 AdaIN 활성 혼합, 순환 손실 |
| 결과 | FF++ ID 99.67, 포즈 0.443(최고), 판별적 신원 겹침 최소, 1024² 가능 |
| 한계 | 복잡한 구조·학습, 인식기가 정의하는 "지각 정보"에 의존 |
