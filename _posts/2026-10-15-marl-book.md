> 이 블로그의 [QMIX]({% post_url 2026-07-10-qmix %}), [COMA]({% post_url 2026-09-09-coma %}), [MAPPO]({% post_url 2026-07-14-mappo %}), [PRIMAL]({% post_url 2026-10-06-primal %}), [Neural MMO]({% post_url 2026-09-10-neural-mmo %})는 모두 다중 에이전트 강화학습(MARL)의 한 조각입니다. 그 조각들을 하나의 체계로 묶은 것이 **Multi-Agent Reinforcement Learning: Foundations and Modern Approaches**(Albrecht, Christianos, Schäfer, 에든버러대, MIT Press 2024, CC-BY-NC-ND 공개)입니다. 2017년 IJCAI 튜토리얼에서 출발한 이 책은 "모든 MARL 연구자가 알아야 할 것"을 1부 **기초**(게임 이론 모델, 해 개념, 고전 알고리즘)와 2부 **심층 MARL**(알고리즘과 실무)로 나누고, 읽기 쉬운 파이썬 코드베이스를 함께 제공합니다. 이 글은 각 장이 답하는 질문을 축으로 책의 뼈대를 정리합니다.

## 1. 모델: 게임

단일 에이전트 RL의 MDP를 다중 에이전트로 확장하는 계층입니다. **정규형 게임**(상태 없는 1회 상호작용, 보상 행렬), **반복 정규형 게임**, **확률 게임**(상태와 전이가 있는 마르코프 게임), **부분 관측 확률 게임**(POSG, 각 에이전트가 자기 관측만 봄, 신념 상태와 필터링)으로 일반화됩니다. 보상 구조로는 영합(zero-sum), 공동 보상(common-reward), 일반합(general-sum)이 있고, 통신은 행동의 일부로 모델링합니다. 3.7절의 "RL ↔ 게임 이론 사전"(에이전트=플레이어, 정책=전략, 보상=효용)이 두 분야를 잇습니다.

## 2. 해 개념: 무엇이 "풀었다"인가

단일 에이전트의 최적 정책은 다중 에이전트에서는 정의되지 않습니다. 내 최적이 상대의 정책에 달려 있기 때문입니다. 책은 해 개념을 포함 관계로 쌓습니다.

- **최선 응답**: 다른 에이전트의 정책이 고정됐을 때의 최적.
- **미니맥스**(영합 2인): 상대가 최악으로 행동한다고 가정한 최적, **선형 계획법**으로 계산 가능.
- **내시 균형**: 모든 에이전트가 서로에 대해 최선 응답, 아무도 혼자 바꿀 이유가 없음. $$\epsilon$$-내시는 근사판.
- **(거친) 상관 균형**: 공유 신호에 조건부로 행동하는 더 넓은 집합, LP로 계산 가능.
- **파레토 최적, 사회 복지와 공정성**: 균형이 여럿일 때 고르는 기준.
- **무후회**: 사후적으로 다른 고정 행동이 더 낫지 않았음.

균형 해의 개념적 한계(비유일성, 하위 최적성, 계산 복잡도)도 다룹니다. $$\epsilon$$-내시 균형 계산은 **PPAD-완전**이라 일반적으로 어렵습니다.

## 3. MARL의 난점과 첫 접근

**중앙 학습**(모두를 하나의 에이전트로)과 **독립 학습**(각자가 다른 에이전트를 환경의 일부로 봄)이라는 두 단일 에이전트 환원이 출발점이고, Level-Based Foraging 예제로 둘의 한계를 봅니다. 핵심 난점은 넷입니다.

1. **비정상성.** 다른 에이전트가 학습하면 내 환경이 바뀝니다. 가위바위보에서 WoLF-PHC로 학습하는 두 에이전트의 정책이 순환하며 균형에 수렴하는 궤적이 그 그림입니다. 단일 에이전트 RL도 정책이 바뀌므로 비정상이지만, 다중 에이전트에서는 **내가 통제하지 않는** 비정상성이 더해집니다.
2. **균형 선택.** 균형이 여럿이면 어느 것으로 조율할지.
3. **다중 에이전트 신용 할당.** 공동 보상을 누가 만들었는지.
4. **다수 에이전트로의 확장.** 공동 행동 공간이 지수적으로 커짐.

## 4. 기초 알고리즘

게임의 가치 반복, **공동 행동 학습**(Minimax-Q, Nash-Q, Correlated-Q: 공동 행동의 Q를 배우고 각 단계의 게임을 해 개념으로 풂), **에이전트 모델링**(가상 플레이: 상대의 경험적 행동 빈도에 최선 응답; 베이즈 학습과 정보의 가치), **정책 기반 학습**(기대 보상의 기울기 상승, 무한소 기울기 상승의 동역학, WoLF, GIGA), **무후회 학습**(후회 매칭과 그 수렴)을 다룹니다. 공동 행동 학습의 한계(균형 계산 비용, 균형 선택)가 이후 심층 방법이 다른 길을 택한 이유입니다.

## 5. 코드로 보기: 미니맥스 LP, 가상 플레이, 가치 분해의 실패

판돈이 다른 가위바위보 행렬에서 LP로 미니맥스 전략과 게임 가치를 구하고 최선 응답으로 검증하며, 가상 플레이 2만 라운드의 경험적 빈도가 그 균형으로 가는지 보고, 공동 보상 행렬 게임에서 가산적 가치 분해(VDN)가 최적 공동 행동을 놓치는 사례를 만듭니다.

```python
import numpy as np
from scipy.optimize import linprog
# (1) minimax via linear programming for a zero-sum normal-form game (rock-paper-scissors with uneven stakes)
R = np.array([[0, -1, 2], [1, 0, -1], [-2, 1, 0]], float)          # row player's reward
def minimax(R):
    m, n = R.shape                                                  # maximise v s.t. sum_i x_i R[i,j] >= v for all j
    c = np.zeros(m + 1); c[-1] = -1
    A = np.hstack([-R.T, np.ones((n, 1))]); b = np.zeros(n)
    res = linprog(c, A_ub=A, b_ub=b, A_eq=[[*np.ones(m), 0]], b_eq=[1], bounds=[(0, 1)] * m + [(None, None)])
    return res.x[:m], res.x[-1]
x, v = minimax(R); y, _ = minimax(-R.T)
print("zero-sum game: minimax strategies via LP")
print(f"  row player {np.round(x, 3)}, column player {np.round(y, 3)}, game value {v:.3f}")
print(f"  best-response check: max_j (x^T R)_j = {max(x @ R):.3f}, min_i (R y)_i = {min(R @ y):.3f}")
# (2) fictitious play: empirical frequencies converge to the equilibrium (slowly)
cnt_r = np.ones(3); cnt_c = np.ones(3)
for t in range(20000):
    i = int(np.argmax(R @ (cnt_c / cnt_c.sum()))); j = int(np.argmin((cnt_r / cnt_r.sum()) @ R))
    cnt_r[i] += 1; cnt_c[j] += 1
print(f"  fictitious play after 20k rounds: row frequencies {np.round(cnt_r/cnt_r.sum(), 3)}")
# (3) value decomposition and the IGM property: an additive (VDN-style) fit on a payoff that breaks monotonic mixing
Q_joint = np.array([[8, -12, -12], [-12, 0, 0], [-12, 0, 0]], float)
best = np.unravel_index(Q_joint.argmax(), Q_joint.shape)
A = np.zeros((9, 6)); b = Q_joint.flatten()
for k, (i, j) in enumerate([(i, j) for i in range(3) for j in range(3)]): A[k, i] = 1; A[k, 3 + j] = 1
q = np.linalg.lstsq(A, b, rcond=None)[0]; q1, q2 = q[:3], q[3:]
print(f"\nmatrix game joint optimum: actions {tuple(int(b) for b in best)}, value {Q_joint[best]:.0f}")
print(f"additive decomposition (VDN) greedy actions: ({q1.argmax()}, {q2.argmax()}) -> value {Q_joint[q1.argmax(), q2.argmax()]:.0f}  (IGM fails: the -12 penalties pull the optimum away)")
print("monotonic mixing (QMIX) cannot represent this payoff either; QTRAN/QPLEX relax monotonicity for such games")
```

```text
zero-sum game: minimax strategies via LP
  row player [0.25 0.5  0.25], column player [0.25 0.5  0.25], game value -0.000
  best-response check: max_j (x^T R)_j = 0.000, min_i (R y)_i = 0.000
  fictitious play after 20k rounds: row frequencies [0.251 0.503 0.246]

matrix game joint optimum: actions (0, 0), value 8
additive decomposition (VDN) greedy actions: (1, 1) -> value 0  (IGM fails: the -12 penalties pull the optimum away)
monotonic mixing (QMIX) cannot represent this payoff either; QTRAN/QPLEX relax monotonicity for such games
```

- 미니맥스 전략은 [0.25, 0.5, 0.25]이고 게임 가치는 0입니다. 어느 열에 대해서도 행 플레이어의 기대 보상이 가치 이상이고 어느 행에 대해서도 열 플레이어가 가치 이하로 막는다는 최선 응답 검증이 통과하므로 내시 균형입니다. 4.3.1절의 LP가 그대로입니다.
- 가상 플레이의 경험적 빈도는 2만 라운드 뒤 [0.251, 0.503, 0.246]으로 균형에 접근합니다. 영합 게임에서 가상 플레이의 **경험적 빈도**가 수렴한다는 6.3.1절의 결과이고, 실제 행동은 매 라운드 결정적이라 정책 자체는 수렴하지 않는다는 점이 함정입니다.
- 공동 보상 행렬에서 최적 공동 행동은 (0, 0)에 가치 8인데, 가산 분해의 탐욕 행동은 (1, 1)에 가치 0입니다. −12의 벌점이 각 에이전트의 개별 Q를 끌어내려 **IGM**(개별 탐욕 = 공동 탐욕)이 깨지는 9.5.1절의 예입니다. QMIX의 단조 혼합도 이 보상(비단조)을 표현하지 못하고, QTRAN·QPLEX가 단조성을 완화하는 이유입니다.

## 6. 심층 MARL

**학습·실행 모드.** 중앙 학습·중앙 실행, 분산 학습·분산 실행, 그리고 가장 널리 쓰이는 **중앙 학습·분산 실행**(CTDE: 학습 때는 전역 정보를 쓰고 실행 때는 각자 관측만 씀).

**독립 학습.** 각 에이전트가 DQN·A2C·PPO를 따로 돌립니다(IDQN, IA2C, IPPO). 단순하고 의외로 강하지만 비정상성에 노출됩니다.

**다중 에이전트 정책 기울기.** 다중 에이전트 정책 기울기 정리, **중앙 비평가**(상태·공동 행동을 보는 비평가로 분산을 줄임, MADDPG), 반사실적 베이스라인으로 신용을 할당하는 [COMA]({% post_url 2026-09-09-coma %}), 중앙 비평가를 통한 균형 선택. [MAPPO]({% post_url 2026-07-14-mappo %})는 IPPO에 중앙 비평가를 더한 형태로 읽힙니다.

**가치 분해(공동 보상).** 공동 Q를 개별 Q들로 분해해 각자 탐욕 선택이 공동 최적이 되게 하는 **IGM** 성질을 목표로 합니다. 가산 분해 VDN, 단조 혼합 [QMIX]({% post_url 2026-07-10-qmix %}), 그리고 단조성을 넘는 QTRAN·QPLEX. 실무 절은 SMAC 등에서의 결과와 함정을 다룹니다.

**에이전트 모델링.** 심층 모델로 상대 정책을 예측하거나 표현을 학습해 조건부로 행동합니다.

**동질 에이전트.** **파라미터 공유**(모든 에이전트가 한 네트워크, 에이전트 ID를 입력에)와 경험 공유로 학습 효율을 높입니다. PRIMAL과 Neural MMO가 이 방식입니다.

**영합 게임의 자기 대결.** MCTS, 자기 대결 MCTS, **AlphaZero**. 그리고 **집단 기반 학습**: 정책 공간 응답 오라클(PSRO, 메타 게임의 균형에 대한 최선 응답을 반복 추가)과 그 수렴, 그리고 AlphaStar의 리그 학습.

## 7. 실무와 환경

10장은 에이전트-환경 인터페이스, PyTorch에서의 파라미터 공유 구현, 중앙 가치 함수와 가치 분해 코드, 실용 팁(시간 스텝 쌓기 대 순환망, 보상 표준화, 중앙 최적화), 학습 곡선과 하이퍼파라미터 탐색의 보고 방법을 다룹니다. 11장은 환경 선택 기준과 구조적으로 다른 2×2 행렬 게임(무갈등·갈등), 복합 환경(Level-Based Foraging, MPE, **SMAC**, Multi-Robot Warehouse, Google Research Football, Hanabi, Overcooked), 컬렉션(Melting Pot, OpenSpiel, PettingZoo)을 정리합니다.

## 8. 해석

**1. 게임 이론을 건너뛰지 않는 것이 이 책의 선택입니다.** 심층 MARL 논문만 읽으면 "비정상성 때문에 CTDE를 쓴다" 정도로 끝나지만, 1부를 거치면 **무엇에 수렴해야 하는지**(어떤 해 개념), **왜 어려운지**(PPAD, 균형 선택), **고전 알고리즘이 어디서 막혔는지**(공동 행동 학습의 비용)가 보입니다. 위 toy의 LP와 가상 플레이가 그 최소 단위입니다.

**2. IGM이 가치 분해 전체를 꿰는 열쇠입니다.** VDN·QMIX·QTRAN·QPLEX의 차이는 "IGM을 만족하는 함수족을 얼마나 넓게 잡는가"로 정리되고, 위 toy의 비단조 행렬이 보여 주듯 표현력의 한계는 알고리즘이 아니라 **함수족**의 한계입니다. [QMIX]({% post_url 2026-07-10-qmix %}) 글의 단조성 제약이 왜 필요하고 왜 부족한지가 이 틀에서 분명해집니다.

**3. 독립 학습의 재평가가 실무적 교훈입니다.** 이론적으로는 비정상성 때문에 보장이 없지만, IPPO·MAPPO가 SMAC에서 강하다는 결과는 "단순한 것부터 시도하라"는 메시지이고, 책이 10장에서 보고 방법(여러 시드, 학습 곡선)을 강조하는 이유도 MARL 결과의 분산이 크기 때문입니다.

**4. 한계는 저자들도 명시합니다.** 통신 학습, 모델 기반 MARL, 다중 에이전트 모방·역강화학습, 인간-에이전트 협력, LLM 기반 에이전트는 다루지 않습니다. 2024년 출간이라 LLM 다중 에이전트 시스템의 폭발 직전까지입니다.

**5. 평가를 읽을 때 주의할 점.** 교과서라 특정 알고리즘의 우열을 정량 비교하지 않고, 각 알고리즘의 결과는 원 논문의 조건에 묶여 있습니다. 위 toy의 가상 플레이는 영합 게임이라 수렴하지만 일반합 게임에서는 순환할 수 있고, 가치 분해 예는 상태 없는 행렬 게임이라 실제 SMAC의 어려움(부분 관측, 긴 지평선)은 담지 않습니다.
