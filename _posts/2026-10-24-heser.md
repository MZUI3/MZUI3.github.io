> 사람이 신원을 인식할 때 얼굴 구조만큼 **머리 형태와 머리 모양**도 봅니다. 그런데 얼굴 교체는 머리카락과 머리 윤곽을 목표의 것으로 고정하므로 전체 인상의 유사도에 한계가 있습니다. **헤드 스와핑**은 소스의 머리 전체를 목표의 몸에 올리는 과제이고, [DeepFaceLab]({% post_url 2026-10-24-deepfacelab %})이 수작업과 대량 데이터로 시도했을 뿐 few-shot으로, 실제 장면에서 한 연구는 없었습니다. **HeSer**(Shu, Wu, Zhou, Liu, Hong, Ding 등, Baidu·화남이공대, CVPR 2022)가 꼽는 세 난점은 (1) 신원뿐 아니라 머리 구조와 비강체인 머리카락을 모델링해야 하고, (2) 머리 형태·머리 모양이 바뀌면 머리 가장자리와 배경 사이에 **큰 빈틈**이 생기며(얼굴 교체에는 없는 문제), (3) 피부색 차이를 처리해야 한다는 것입니다. 두 모듈이 각각 (1)과 (2)+(3)을 맡습니다.

## 1. Head2Head Aligner

소스 $$K$$장($$K$$-shot)과 목표 한 장에서, 목표의 포즈·표정에 정렬된 소스의 **애니메이션 초상** $$I_A$$를 먼저 만듭니다. 네 인코더를 씁니다. 소스에서 **초상 인코더** $$E_{por}$$가 머리·머리카락의 전역 구조를, 사전학습 인식 모델인 **신원 인코더** $$E_{id}$$가 중앙 크롭의 신원을 뽑아 각각 $$K$$장 평균을 냅니다. 목표에서는 증강 $$A$$를 거친 뒤 **포즈 인코더** $$E_{pose}$$가 신원 무관 포즈를, 중앙 크롭에서 **표정 인코더** $$E_{exp}$$가 세부 표정을 뽑습니다. 네 벡터를 이어 [AdaIN]({% post_url 2026-10-24-adain %})으로 스타일 기반 생성기에 주입합니다.

$$
I_A = G(\bar f_{por}, \bar f_{id}, f_{pose}, f_{exp})
$$

학습은 같은 영상에서 $$K+1$$프레임을 뽑아 $$K$$장을 소스, 1장을 목표로 쓰는 자기 재구성이고(LPD와 같은 재구성·지각·적대·신원 손실), 테스트에서는 다른 사람의 영상입니다. 소스·목표가 같은 사람이므로 분리는 인코더 설계(증강, 중앙 크롭)에 의존합니다. 주체별 미세조정으로 신원·포즈 일관성을 더 올릴 수 있습니다.

## 2. Head2Scene Blender

$$I_A$$의 머리를 목표의 몸·배경에 이어 붙입니다. 두 문제를 하나의 서브모듈로 풉니다. 머리 형태가 다르므로 원래 머리 영역 중 새 머리가 덮지 않는 **빈틈을 채워야** 하고, 머리 피부색이 목표의 목·몸 피부와 **일치**해야 합니다.

**전처리.** 파싱으로 $$I_A$$와 $$I_T$$의 머리 마스크 $$M^H_A, M^H_T$$를 얻고, 애니메이션 머리를 **회색조** $$I^{GH}_A$$로 바꿉니다(색을 옮기는 대신 회색 머리를 다시 칠하는 문제로 바꾸는 것이 쉽습니다). 목표 머리 마스크를 팽창한 것과의 차이가 목표 인페인팅 마스크, 두 머리 마스크의 합집합을 팽창한 것에서 $$M^H_A$$를 뺀 것이 애니메이션 인페인팅 마스크 $$M^I_A$$, 그 밖이 배경 $$I^{BG}_T$$입니다.

**의미 유도 색 참조 생성(RC).** 참조는 목표 영역과 공간적으로 맞고 픽셀별 색 안내를 줘야 하므로, FPN 특징의 상관으로 목표 색을 **질의**해 만듭니다. 이전 방법들은 모든 위치 쌍의 상관을 계산해 $$O(wh \cdot wh)$$의 메모리를 썼지만, 라벨이 다른 픽셀은 거의 기여하지 않으므로 **같은 의미 영역 안에서만** 계산합니다. 영역 $$r \in \{\text{face, hair, eye, nose, lip, tooth, inpainting}\}$$마다 채널 중심화 특징의 코사인 상관 $$\Gamma^r \in \mathbb{R}^{N^r_A \times N^r_T}$$를 구하고 softmax(온도 $$\tau$$)로 목표 픽셀 색을 가중합합니다. 머리 색 참조 $$I^{HR}_{T \to A}$$는 얼굴·머리카락·눈·코·입·치아 영역에서, 인페인팅 참조 $$I^{IR}_{T \to A}$$는 목표 인페인팅 마스크에서 만듭니다. 쌍 데이터가 없으므로 학습은 같은 이미지에 색 증강 $$C'$$와 좌우 반전 $$F$$를 가해 "같은 위치 복사"를 막습니다.

**블렌딩 U-Net.** 두 참조, 머리 마스크, 배경, 인페인팅 마스크, 회색 머리를 채널로 이어 넣어 최종 $$I_B$$를 냅니다. 재구성·지각·적대 손실에, 참조가 의미 있는 대응을 배우도록 **순환 손실**(목표 → 애니메이션 → 목표로 되돌린 색 참조가 목표와 같아야 함)과 다른 이미지 $$I'_T$$를 쓴 변형을 더합니다.

## 3. 코드로 보기: 영역별 대응의 비용과 정확도

64×64 합성 파싱 맵(피부·머리카락·눈·입술·인페인팅 영역)에서 전체 상관 행렬과 영역별 상관 행렬의 원소 수를 세고, 영역 고유 서명 + 잡음의 특징에서 전역 최근접 매칭이 다른 의미 영역으로 새는 비율을 재며, 회색 머리를 참조 톤으로 다시 칠했을 때 평균과 질감 표준편차를 봅니다.

```python
import numpy as np
rng = np.random.default_rng(0)
# semantic-guided colour reference: correlate features only within the same semantic region, not across the whole image
H = W = 64; regions = {"skin": 0, "hair": 1, "eyes": 2, "lips": 3, "inpaint": 4}
yy, xx = np.mgrid[0:H, 0:W]
seg = np.zeros((H, W), int); seg[(xx - 32) ** 2 / 300 + (yy - 36) ** 2 / 500 < 1] = 0; seg[yy < 14] = 1
seg[((xx - 22) ** 2 + (yy - 30) ** 2 < 9) | ((xx - 42) ** 2 + (yy - 30) ** 2 < 9)] = 2; seg[(xx - 32) ** 2 / 40 + (yy - 48) ** 2 / 6 < 1] = 3
seg[((xx - 32) ** 2 / 400 + (yy - 36) ** 2 / 650 < 1) & ~((xx - 32) ** 2 / 300 + (yy - 36) ** 2 / 500 < 1) & (yy >= 14)] = 4
counts = {k: int((seg == v).sum()) for k, v in regions.items()}
print("pixels per semantic region:", counts)
full = (H * W) ** 2; per_region = sum(c * c for c in counts.values())
print(f"correlation matrix entries: whole image {full:,}  vs  per-region {per_region:,}  ({full / per_region:.1f}x fewer)")
# features: a region-specific signature + noise; a pixel's best match is the most similar pixel in the OTHER image
C = 16; proto = rng.standard_normal((5, C))
def feats(seg): return proto[seg] + 0.8 * rng.standard_normal((H, W, C))
fA, fT = feats(seg), feats(np.roll(seg, 3, 1))                                            # the target is slightly shifted
segT = np.roll(seg, 3, 1)
A, T = fA.reshape(-1, C), fT.reshape(-1, C); A = A - A.mean(1, keepdims=True); T = T - T.mean(1, keepdims=True)
A /= np.linalg.norm(A, axis=1, keepdims=True); T /= np.linalg.norm(T, axis=1, keepdims=True)
sample = rng.choice(H * W, 600, replace=False)
corr = A[sample] @ T.T
best_global = corr.argmax(1); wrong_global = np.mean(segT.reshape(-1)[best_global] != seg.reshape(-1)[sample])
wrong_region = 0.0
for k, v in regions.items():
    idx = np.where(segT.reshape(-1) == v)[0]; mine = sample[seg.reshape(-1)[sample] == v]
    if len(idx) and len(mine): wrong_region += 0.0                                        # by construction every match stays in its region
print(f"\nbest-match pixel lands in a different semantic region: global correlation {wrong_global * 100:.1f}%  vs  semantic-guided {wrong_region * 100:.1f}%")
print("-> restricting the correspondence to the same label (skin->skin, hair->hair) is both cheaper and avoids colouring skin from hair pixels")
# re-colouring a grey head: the reference gives per-pixel colour, the head keeps its own luminance pattern
grey = 0.5 + 0.2 * np.sin(xx / 3.0) * (seg == 0); ref_tone = np.where(seg == 0, 0.35, 0.0)           # darker target skin
recol = np.where(seg == 0, grey - grey[seg == 0].mean() + ref_tone, grey)
print(f"skin mean after re-colouring {recol[seg == 0].mean():.2f} (target {0.35}), skin texture std kept {recol[seg == 0].std():.3f} (source {grey[seg == 0].std():.3f})")
```

```text
pixels per semantic region: {'skin': 2768, 'hair': 896, 'eyes': 50, 'lips': 49, 'inpaint': 333}
correlation matrix entries: whole image 16,777,216  vs  per-region 8,580,430  (2.0x fewer)

best-match pixel lands in a different semantic region: global correlation 0.8%  vs  semantic-guided 0.0%
-> restricting the correspondence to the same label (skin->skin, hair->hair) is both cheaper and avoids colouring skin from hair pixels
skin mean after re-colouring 0.35 (target 0.35), skin texture std kept 0.140 (source 0.140)
```

- 이 toy에서 영역별 상관은 전체의 2배만 절약합니다. 피부 영역이 전체의 68%를 차지해 $$N^2$$의 대부분을 혼자 내기 때문입니다. 논문의 $$O(wh \cdot wh) \to O(N^r_A \cdot N^r_T)$$ 절감은 영역이 고르게 나뉠수록 크고, 실제 얼굴 파싱(19클래스)에서는 더 큽니다.
- 정확도 쪽이 더 중요합니다. 전역 매칭은 0.8%의 픽셀을 다른 의미 영역에서 가져오고(잡음이 큰 눈·입술 같은 작은 영역이 피부로 새는 식), 영역별 매칭은 정의상 0%입니다. 피부를 머리카락 색으로 칠하는 오류가 구조적으로 불가능해집니다.
- 회색 머리의 평균을 참조 톤 0.35로 옮기면 질감 표준편차 0.140이 그대로 유지됩니다. 색은 목표에서, 음영 구조는 소스에서 온다는 분해입니다.

## 4. 실험

VoxCeleb2 테스트셋에서 소스 25그룹 × 목표 10장 = 250개 결과를 방법마다 만들고, 20명(일반 15, 전문가 5)이 신원 보존, 표정·포즈 일치, 피부색 일관성, 인페인팅 매끄러움, 전체 품질을 순위 매겨 0~5점으로 환산합니다. 비교 대상은 얼굴 교체(FaceShifter 계열, 32-shot 중 한 장이 소스)와 DeepFaceLab(같은 32프레임)입니다.

**결과.** HeSer가 신원, 인페인팅, 전체 품질에서 큰 차이로 1위입니다. 표정 일치와 피부색은 얼굴 교체가 앞서는데, 신원을 목표 이미지에 직접 주입하는 방식이라 얼굴 구조와 피부색을 자연스럽게 유지하기 때문입니다. 얼굴 교체는 수염이 조금 옮겨지지만 머리 형태·머리 모양이 그대로라 인상의 유사도가 낮고, DeepFaceLab은 비슷한 포즈의 소스가 없으면 애니메이션이 나쁘며 빈 픽셀을 채우지 못하고 색 정렬도 열세입니다(Figure 7). Head2Head Aligner 단독으로는 재연기 방법들과 비교해 평가합니다(보충).

## 5. 해석

**1. 과제 정의가 기여입니다.** "머리 형태와 머리카락도 신원"이라는 전제에서 얼굴 교체와 헤드 스와핑의 차이를 세 난점으로 명확히 했고, 특히 **배경 빈틈**은 얼굴 형태를 소스에 맞추려는 [HifiFace]({% post_url 2026-10-24-hififace %})·[FaceInpainter]({% post_url 2026-10-24-faceinpainter %})가 작은 규모로 마주친 문제의 극단입니다. 인페인팅을 피할 수 없다는 점에서 교체는 결국 장면 합성 문제가 됩니다.

**2. "의미끼리만 대응"은 재사용 가능한 설계입니다.** 전역 상관 대신 라벨별 상관은 비용과 오류를 함께 줄이며, [AOT]({% post_url 2026-10-24-aot %})가 위치·법선을 수송 벡터에 붙인 것, [RAFSwap]({% post_url 2026-10-24-rafswap %})의 영역 토큰, [E4S]({% post_url 2026-10-24-e4s %})의 영역별 스타일 코드와 같은 방향입니다. 위 toy의 0.8% → 0%가 그 효과의 작은 예입니다.

**3. 회색조로 바꾼 뒤 다시 칠하는 분해가 영리합니다.** 색 전이를 "소스 색을 목표 색으로 매핑"이 아니라 "소스의 음영에 목표의 색을 입히기"로 바꾸면 메이크업 전이의 기법을 빌릴 수 있고, 배경 색이 바뀌는 PSGAN류의 문제를 피합니다.

**4. 한계는 few-shot 정렬기의 분리와 평가입니다.** 같은 영상의 프레임으로만 학습하므로 소스·목표가 다른 사람일 때 신원·포즈 분리는 증강에 기댑니다. 평가는 사용자 연구 하나이고 정량 지표가 없으며, 비교 대상 둘 중 하나(얼굴 교체)는 과제가 다릅니다.

**5. 평가를 읽을 때 주의할 점.** 사용자 20명, 각 25개 결과의 순위 기반 점수라 통계적 힘이 약하고, 표정·피부색에서 얼굴 교체에 진다는 점은 저자들도 인정합니다. 데이터 수집·학습 세부는 보충 자료에 있습니다. 위 toy는 특징이 영역 서명 + 잡음인 합성이라 실제 FPN 특징의 의미 혼동 정도를 보여 주지 않습니다.

## 6. 정리

| 항목 | 내용 |
|---|---|
| 과제 | few-shot 헤드 스와핑: 머리 형태·머리카락 포함 머리 전체를 목표 몸에, 실제 장면 |
| 난점 | 머리 구조·비강체 머리카락 모델링, 머리 가장자리-배경 빈틈, 피부색 차이 |
| Head2Head Aligner | 초상·신원(소스 K장 평균) + 포즈·표정(목표) → AdaIN 스타일 생성기, 자기 재구성 학습 |
| Head2Scene Blender | 회색 머리 + 의미 영역별 상관으로 만든 머리 색·인페인팅 참조 + 블렌딩 U-Net, 순환 손실 |
| 결과 | 사용자 연구에서 신원·인페인팅·전체 품질 1위(얼굴 교체·DFL 대비), 표정·피부색은 얼굴 교체 우세 |
| 한계 | 같은 영상 기반 학습의 분리, 정량 지표 없음 |
