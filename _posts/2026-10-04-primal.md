> 물류 창고의 로봇 수백 대가 서로 부딪히지 않고 각자 목적지로 가야 하는 문제를 **MAPF(Multi-Agent Path Finding)**라고 합니다. **PRIMAL**(*Pathfinding via Reinforcement and Imitation Multi-Agent Learning*, Sartoretti et al., RA-L 2019)은 이를 중앙에서 계획하지 않고, **각 로봇이 자기 주변만 보고 스스로 판단**하는 분산 정책으로 풉니다.

## 1. 배경: 중앙집중식 계획의 한계

기존 MAPF는 대부분 **centralised planning**에 의존했습니다. 모든 로봇의 위치를 한곳에서 보고 전체 경로를 계산합니다(예: [CBS]({% post_url 2026-10-14-cbs-task-assignment %}), M*).

- 로봇 수에 비해 **처리할 수 있는 규모가 작음**. 수백~수천 대면 계산이 폭발
- 노이즈와 불확실성이 많은 **실제 배포 환경**에 적용하기 어려움
- 계획에 몇 분씩 걸리는 실제 환경에서는 변화가 생겼을 때 **다시 계획하기 어려움**

그래서 PRIMAL은 강화학습과 모방학습을 결합한 **분산 정책**을 제안합니다.

- 기존 계획기의 **시연(demo)**을 기준으로 학습하고
- 학습한 **하나의 정책을 모든 로봇에 복사**해서 사용

## 2. MAPF 환경 설계

구성 요소는 네 가지입니다. 관측, 행동 공간, 보상 구조, 정책.

### 관측 (Observation)

**부분 관측 이산 격자 세계**에서, 각 로봇은 자기 중심 **10×10 시야(FOV)**만 봅니다. FOV를 넓히면 전체 관측으로 바꿀 수도 있습니다. 학습을 쉽게 하려고 정보를 **채널별로 분리**합니다.

- 장애물
- 다른 로봇의 위치
- 자기 목표 위치 (FOV 안에 있을 때)
- 시야 안의 다른 로봇들의 목표 위치

목표가 **FOV 밖**에 있을 수 있으므로, 목표 방향의 **단위 벡터와 거리**를 추가로 줍니다.

### 행동 (Action)

**상·하·좌·우 이동 또는 정지**, 5가지입니다. 벽으로 이동하거나 다른 로봇과 충돌하는 **유효하지 않은 행동**은 별도의 loss로 판별하고, **샘플링에서 제외**합니다. 실험적으로 음의 보상을 주는 것보다 이렇게 제외하는 편이 더 좋았습니다.

또 같은 칸을 왔다 갔다 하는 **진동(oscillating) 정책**을 막기 위해, 바로 직전 위치로 되돌아가는 행동을 막습니다.

### 보상 (Reward)

- 매 이동마다 작은 **음의 보상** (빨리 가도록)
- 목표가 아닌 곳에서 멈추면 더 큰 음의 보상
- **충돌**하면 큰 음의 보상
- 모든 로봇이 목표에 도착하면 **큰 양의 보상**

논문 Table I의 값은 다음과 같습니다.

| 상황 | 보상 |
|---|---|
| 이동 (상·하·좌·우) | −0.3 |
| 목표 위에서 정지 | 0.0 |
| 목표가 아닌 곳에서 정지 | −0.5 |
| 충돌 | −2.0 |
| 에피소드 완료 | +20.0 |

이동 벌점(−0.3)보다 멈춤 벌점(−0.5)을 크게 둔 것이 포인트입니다. 반대라면 로봇이 "움직이면 손해"라고 배워 제자리에 서 있는 정책으로 빠지기 쉽습니다.

## 3. Actor-Critic 네트워크

**A3C** 알고리즘을 기반으로, 관측에서 다음 행동을 결정하는 정책을 신경망으로 근사합니다(CNN + LSTM). 출력은 세 가지입니다.

- **Policy**: 다음 행동의 확률
- **Value**: 상태 가치 추정
- **Blocking**: 지금 내가 다른 로봇을 막고 있는지 예측

정책, 가치, blocking 예측은 **256 step마다 또는 에피소드가 끝날 때** 업데이트합니다.

### Loss

**Value loss**: 예측 가치와 실제 return의 차이를 누적

$$
\mathcal{L}_V = \sum_t\big(V(o_t) - R_t\big)^2
$$

**Policy loss**: advantage $$A(o_t, a_t)$$로 행동을 평가하고, **엔트로피** 항을 더해 탐험을 장려

$$
\mathcal{L}_\pi = -\sum_t\Big[\log P(a_t \mid \pi, o_t)\,A(o_t, a_t) + \sigma_H\,H\big(\pi(o_t)\big)\Big],\qquad \sigma_H = 0.01
$$

여기에 유효하지 않은 행동을 피하도록 하는 loss와 blocking 예측 loss가 더해집니다.

## 4. 협력 학습 (Coordination Learning)

### 문제: 이기적인 로봇

각 로봇이 **자기 보상만 최대화**하면, 먼저 목표에 도착한 로봇이 **목표 칸에 가만히 서서** 다른 로봇의 길을 막는 이기적인 정책이 자주 생깁니다. 자기 보상은 최대지만 팀 전체로는 손해입니다. 그래서 **이타적인 행동**을 유도해야 합니다.

### Blocking Penalty

- 목표에 머물면서 **다른 로봇의 접근을 막으면 -2**의 벌점
- 다른 로봇이 **10 step 이상 지연**되는 경우도 막은 것으로 처리
- 막고 있는지는 **A\***로 판단: 내가 없을 때와 있을 때 다른 로봇의 최단 경로 길이를 비교

```python
def blocking_penalty(me, others, grid, astar, delay_threshold=10):
    """me가 목표 칸에 서 있어서 다른 로봇의 최단 경로가 크게 늘어나면 벌점"""
    penalty = 0.0
    for other in others:
        with_me = astar(grid, other.pos, other.goal, blocked={me.pos})
        without_me = astar(grid, other.pos, other.goal, blocked=set())
        if without_me is None:                     # 원래부터 갈 수 없으면 내 책임이 아님
            continue
        if with_me is None or len(with_me) - len(without_me) > delay_threshold:
            penalty -= 2.0
    return penalty
```

> 이 판정은 다른 로봇마다 A\*를 두 번씩 돌리므로 비쌉니다. 그래서 학습 중에만 쓰고, 실제 실행(추론) 때는 정책 신경망만 사용합니다. Blocking 여부를 별도 출력으로 **예측하게 학습**하는 것(위 네트워크의 blocking head)도, 이 정보를 정책이 스스로 알게 하려는 장치입니다.

### Expert Demonstration

강화학습만으로는 협력 행동을 배우기 어렵습니다. 그래서 일부 에피소드에서는 **중앙집중식 MAPF 계획기(ODrM\*)**의 해답을 시연으로 써서 **모방학습(behavior cloning)**을 하고, 나머지 에피소드에서는 **강화학습**을 합니다. 시연은 "어떻게 협력하는지"를, 강화학습은 "시연에 없는 상황에서 어떻게 할지"를 가르칩니다.

### Environment Sampling

에피소드를 시작할 때마다 **격자 크기와 장애물 밀도를 무작위로** 정합니다. 밀도를 균일하게 뽑으면 로봇끼리 마주칠 일이 드물어 협력이 필요한 상황에 충분히 노출되지 않으므로, 다양한 밀도를 섞어 학습합니다.

## 5. 실험

다양한 격자 크기와 장애물 밀도, 로봇 수에서 중앙집중식 계획기(ODrM\*, CBS 등)와 비교했습니다.

- **소규모**에서는 최적 계획기가 더 짧은 경로를 찾지만, 로봇 수가 늘수록 계획기는 **시간 안에 해를 찾지 못하는** 경우가 많아졌습니다.
- **PRIMAL**은 로봇이 매우 많은 환경(수백~1,000대 이상)에서도 동작했고, 특히 **장애물이 적고 넓은** 환경에서 성공률이 높았습니다.
- 반면 장애물이 촘촘한 좁은 환경에서는 중앙 계획기보다 성공률이 낮았습니다. 좁은 통로에서 여러 로봇이 양보해야 하는 상황은 부분 관측만으로 풀기 어렵기 때문입니다.
- ODrM\*의 **inflation factor**(충돌 회피 계수)를 키우면 빨라지지만 경로가 길어지는데, PRIMAL은 이런 근사 계획기와 비교해서도 큰 규모에서 경쟁력 있었습니다.
- 실제 로봇과 드론 실험으로 실제 환경 적용 가능성도 보였습니다.

## 6. 정리

| 요소 | PRIMAL의 설계 |
|---|---|
| 관측 | 10×10 FOV를 채널별로 분리 + 목표 방향 벡터·거리 |
| 행동 | 5가지, 유효하지 않은 행동은 샘플링에서 제외 |
| 학습 | A3C (RL) + 중앙 계획기 시연 (IL) |
| 협력 | **Blocking penalty** (A\*로 판정) |
| 일반화 | 격자 크기와 장애물 밀도를 무작위로 |
| 장점 | 분산 실행, 로봇 수에 확장 가능 |
