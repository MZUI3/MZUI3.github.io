> [Nirkin 등의 2018 방법]({% post_url 2026-08-14-face-segmentation-swapping %})은 3D 프록시와 분할로 임의 쌍을 바꿨지만 종단간 학습이 아니었고, DeepFakes·[CageNet]({% post_url 2026-08-13-fast-face-swap %}) 같은 학습 방법은 **인물마다 수천 장으로 다시 학습**해야 했습니다. RSGAN·FSNet은 잠재 벡터로 신원을 분리해 주체 비의존을 달성했지만 압축 때문에 품질이 낮았습니다. **FSGAN**(Nirkin, Keller, Hassner, Bar-Ilan·Open University, ICCV 2019)은 특정 인물 학습 없이 **교체와 재연기를 동시에** 하는 첫 방법입니다. 큰 포즈 변화를 작은 단계로 나눠 반복 재연기하고, 소스 영상의 뷰들을 포즈 공간에서 삼각분할해 보간하며, 가림은 인페인팅으로, 피부톤·조명 차이는 포아송 블렌딩 손실로 풉니다. 세 개의 pix2pixHD형 생성기가 각각 한 가지 일을 맡는 모듈식 설계입니다.

## 1. 구조

소스 $$I_s$$, 목표 $$I_t$$에 대해 목표의 얼굴을 소스로 바꾸되 포즈·표정은 유지합니다.

1. **재연기 $$G_r$$ + 분할 $$G_s$$**: $$G_r$$은 소스 이미지와 목표 랜드마크의 70채널 히트맵을 받아 재연기된 얼굴 $$I_r$$과 그 분할 $$S_r$$을 냅니다. $$G_s$$는 목표의 얼굴·머리카락·배경 3클래스 분할 $$S_t$$를 냅니다(U-Net).
2. **인페인팅 $$G_c$$**: 소스에서 가려져 재연기 결과에 빠진 부분을 목표 분할 $$S_t$$ 전체를 덮도록 채웁니다.
3. **블렌딩 $$G_b$$**: 완성된 얼굴 $$F_c$$를 목표 $$I_t$$에 $$S_t$$ 마스크로 섞습니다.

생성기는 pix2pixHD의 거칠게-세밀하게 구조에 다중 스케일 판별기를 쓰되, 전역 생성기를 병목 블록 U-Net(연결 대신 합)으로 바꾸고 bilinear 업샘플을 씁니다. 손실은 공통으로 **도메인 특화 지각 손실**(ImageNet VGG 대신 VGGFace2 얼굴 인식과 CelebA 속성 분류로 학습한 VGG-19의 특징 L1), 픽셀 L1, 다중 스케일 적대 손실입니다.

## 2. 재연기: 작은 단계와 뷰 보간

주체 비의존 재연기는 포즈 차이가 크면 실패합니다. 그래서 소스와 목표의 오일러 각과 3D 랜드마크 중심을 보간해 중간 랜드마크 $$p_j$$를 만들고, $$I_{r_j} = G_r(I_{r_{j-1}}; H(p_j))$$로 **재귀적으로** 조금씩 돌립니다. 학습은 같은 영상의 두 프레임 쌍으로, $$n$$단계 후 결과가 목표와 같아야 한다는 **단계별 일관성 손실**과 한 번에 간 결과의 손실, 적대 손실, 분할 손실을 합칩니다. $$G_s$$와 $$G_r$$을 번갈아 학습하며 $$G_r$$의 분할 헤드로 $$G_s$$를 보조하면 거친 라벨의 잡음이 걸러집니다.

영상 소스가 있으면 **외형 맵**을 만듭니다. 각 소스 프레임의 (yaw, pitch)를 평면에 찍고(roll은 버림), k-d 트리로 너무 가까운 점과 모션 블러 프레임을 걸러낸 뒤, [−75, 75]² 경계점 4개와 함께 **들로네 삼각분할**합니다. 목표 포즈가 떨어지는 삼각형의 세 꼭짓점 프레임을 각각 재연기해 **무게중심 좌표**로 가중 평균합니다. 경계점은 제외하고 정규화하며, 한쪽만 있으면 좌우 반전으로 채웁니다. 소스 영상 전체를 학습 없이 쓰는 것이 주체 비의존성의 핵심입니다.

## 3. 인페인팅과 포아송 블렌딩 손실

2018 방법은 소스와 목표 분할의 교집합만 옮겨 큰 가림에서 아티팩트가 났습니다. $$G_c$$는 재연기 결과의 분할에서 타원형 조각을 무작위로 떼어 머리카락 가림을 흉내 낸 입력으로 학습해, 목표 마스크 전체를 덮는 얼굴을 만듭니다.

블렌딩은 포아송 최적화 $$P(I_t; I_r^t; S_t) = \arg\min_f \lVert \nabla f - \nabla I_r^t \rVert^2$$ s.t. $$f = I_t$$ (마스크 밖)를 **학습 목표**로 씁니다. $$G_b$$의 출력이 포아송 해와 가깝도록 지각·픽셀 손실을 걸고 적대 손실을 더한 것이 **포아송 블렌딩 손실**입니다. 추론 때 최적화를 풀지 않고 네트워크 한 번으로 피부톤과 조명을 맞춥니다.

## 4. 코드로 보기: 뷰 보간, 포아송 블렌딩, 단계 분할

소스 뷰 8개의 (yaw, pitch)를 경계점과 함께 들로네 삼각분할해 질의 포즈마다 어느 뷰가 어떤 무게로 쓰이는지 보고, 1차원 단면에서 하드 붙여넣기와 포아송 블렌딩의 경계 점프·질감 보존을 비교하며, 단계 크기에 초선형으로 커지는 오차 모델에서 60° 회전을 $$n$$단계로 나눌 때의 누적 오차를 봅니다.

```python
import numpy as np
from scipy.spatial import Delaunay
rng = np.random.default_rng(0)
# (1) face view interpolation: source views embedded by (yaw, pitch), Delaunay triangulation, barycentric weights for a query pose
views = np.array([[-40, 0], [-20, 10], [0, 0], [20, -5], [40, 5], [0, 20], [-10, -15], [25, 15]], float)
corners = np.array([[-75, -75], [-75, 75], [75, -75], [75, 75]], float)
pts = np.vstack([views, corners]); tri = Delaunay(pts)
def interp(query):
    t = tri.find_simplex(query); v = tri.simplices[t]
    T = tri.transform[t]; b = T[:2] @ (query - T[2]); lam = np.append(b, 1 - b.sum())
    keep = v < len(views); lam = np.where(keep, lam, 0); lam = lam / lam.sum()        # drop boundary vertices, renormalise
    return v, lam
for q in ([5.0, 3.0], [-30.0, 4.0], [60.0, 0.0]):
    v, lam = interp(np.array(q)); sel = [(int(i), round(float(l), 2)) for i, l in zip(v, lam) if l > 0]
    print(f"query pose {q}: views {sel}  (index -> weight)")
print(f"triangles {len(tri.simplices)}, every query uses at most 3 source views -> the whole source video is usable without training on it")
# (2) Poisson blending in 1-D: keep the target outside the mask, match the SOURCE GRADIENTS inside
x = np.linspace(0, 1, 200); target = 0.45 + 0.08 * np.sin(5 * x); source = 0.70 + 0.08 * np.sin(5 * x + 1.0) + 0.03 * np.sin(40 * x)
mask = (x > 0.35) & (x < 0.65); idx = np.where(mask)[0]
paste = np.where(mask, source, target)
# solve f'' = source'' inside, f = target on the boundary (tridiagonal system)
m = len(idx); A = np.zeros((m, m)); b = np.zeros(m); g = np.gradient(np.gradient(source))
for k in range(m):
    A[k, k] = -2; b[k] = g[idx[k]]
    if k > 0: A[k, k-1] = 1
    else: b[k] -= target[idx[0] - 1]
    if k < m - 1: A[k, k+1] = 1
    else: b[k] -= target[idx[-1] + 1]
f = target.copy(); f[idx] = np.linalg.solve(A, b)
print("\nPoisson blending (1-D): seam jump and preserved source detail")
print(f"  hard paste : jump at the mask border {abs(paste[idx[0]] - paste[idx[0]-1]):.3f}, source detail kept {np.corrcoef(paste[idx], source[idx])[0,1]:.3f}")
print(f"  Poisson    : jump at the mask border {abs(f[idx[0]] - f[idx[0]-1]):.3f}, source detail kept {np.corrcoef(f[idx], source[idx])[0,1]:.3f}")
print("-> the blended face takes the target's low-frequency colour/lighting at the border while keeping the source's texture gradients")
# (3) stepwise reenactment: one big landmark jump vs n small steps with a reenactment map that degrades with the step size
def reenact_error(step): return 0.02 * step ** 2                       # error grows super-linearly with the angular step
for n in (1, 2, 4, 8):
    print(f"60-degree pose change in {n} step(s): accumulated error {sum(reenact_error(60 / n) for _ in range(n)):.1f}")
```

```text
query pose [5.0, 3.0]: views [(3, 0.0), (7, 0.2), (2, 0.8)]  (index -> weight)
query pose [-30.0, 4.0]: views [(1, 0.45), (0, 0.52), (6, 0.03)]  (index -> weight)
query pose [60.0, 0.0]: views [(4, 1.0)]  (index -> weight)
triangles 18, every query uses at most 3 source views -> the whole source video is usable without training on it

Poisson blending (1-D): seam jump and preserved source detail
  hard paste : jump at the mask border 0.231, source detail kept 1.000
  Poisson    : jump at the mask border 0.001, source detail kept 0.997
-> the blended face takes the target's low-frequency colour/lighting at the border while keeping the source's texture gradients
60-degree pose change in 1 step(s): accumulated error 72.0
60-degree pose change in 2 step(s): accumulated error 36.0
60-degree pose change in 4 step(s): accumulated error 18.0
60-degree pose change in 8 step(s): accumulated error 9.0
```

- 질의 포즈 (5, 3)은 정면 뷰 0.8, 다른 뷰 0.2로, (−30, 4)는 두 측면 뷰가 반씩 섞이고, 소스 뷰들이 덮는 범위(볼록 껍질) 밖인 (60, 0)은 경계점이 제외되어 가장 가까운 뷰 하나(1.0)만 씁니다. 삼각형마다 최대 3개 뷰만 쓰므로 소스 영상이 길어도 비용이 일정합니다.
- 포아송 블렌딩은 경계 점프를 0.231에서 0.001로 없애면서 소스의 질감 기울기(상관 0.997)를 유지합니다. 경계의 색·조명은 목표에서, 내부 세부는 소스에서 오는 것이고, $$G_b$$는 이 해를 흉내 내도록 학습됩니다.
- 오차가 단계 크기의 제곱이면 60°를 8단계로 나눌 때 누적 오차가 1/8입니다. 실제 생성기의 오차 곡선은 다르지만, 반복 재연기가 유리한 조건은 "오차가 단계에 초선형"이라는 것뿐입니다.

## 5. 실험

IJB-C의 고화질 영상 5,500개(인물당 최대 100프레임, 랜드마크 분산 최대 기준)로 $$G_r$$을, 2018 데이터 1만 장 + LFW Parts + Figaro 머리카락으로 $$G_s$$를 학습합니다. 128→256 점진 학습, V100 8장으로 $$G_s$$ 6시간, 나머지 2일. 추론은 재연기 30 FPS, 교체 10 FPS입니다.

FaceForensics++의 쌍에서 **같은 영상에 학습하지 않고** 비교합니다. 정량 평가는 교체 결과를 포즈가 가장 가까운 소스 프레임과 dlib 검증 거리·SSIM으로, 포즈는 목표와의 오일러 각 거리, 표정은 2D 랜드마크 거리로 잽니다(첫 500영상 × 100프레임).

| 방법 | 검증 거리 ↓ | SSIM ↑ | 오일러 각 ↓ | 랜드마크 ↓ |
|---|---|---|---|---|
| Nirkin 2018 | 0.39 | 0.49 | 3.15 | 26.5 |
| DeepFakes | 0.38 | 0.50 | 4.05 | 34.1 |
| FSGAN | 0.38 | 0.51 | 2.49 | 22.2 |

신원·품질은 비슷하고 **포즈·표정 보존이 뚜렷이 좋습니다.** 사람 눈에 민감한 아티팩트는 SSIM에 잘 안 잡힌다고 저자들도 적습니다. Face2Face와는 입 랜드마크만 바꿔 넣는 방식으로 표정 전용 재연기를 정성 비교합니다. Ablation은 $$G_r$$만, $$+G_c$$, $$+G_b$$, 전체 순으로 가림과 피부톤이 개선됨을 보입니다. 큰 각도 차이에서 반복 횟수를 3으로 늘리면 신원·질감이 더 보존됩니다(Figure 5).

## 6. 해석

**1. "재연기 후 블렌딩"(소스 지향) 계열의 완성형입니다.** [SimSwap]({% post_url 2026-08-31-simswap %})의 분류로 보면 FSGAN은 소스 얼굴을 목표 포즈로 바꾼 뒤 붙이는 **소스 지향** 방법이고, 같은 해 [FaceShifter]({% post_url 2026-08-18-faceshifter %})는 목표 특징에 신원을 주입하는 **목표 지향** 방법입니다. 이후 논문들은 FSGAN을 "얼굴 형태가 목표에 고정되고 조명·해상도를 존중하지 못하는" 대표로 인용하지만, 가림과 블렌딩을 명시적으로 다루는 장점은 [FSGANv2]({% post_url 2026-09-11-fsganv2 %})와 [E4S]({% post_url 2026-10-09-e4s %})의 소스 지향 설계로 이어집니다.

**2. 모듈 분해가 디버깅 가능성을 줍니다.** 재연기·인페인팅·블렌딩이 분리되어 어느 단계가 실패했는지 보이고, 각 단계에 맞는 손실(단계별 일관성, 타원 가림 증강, 포아송)을 설계할 수 있습니다. 반대로 단계가 쌓여 오차가 누적되고, 226M 파라미터·2440 GFLOPs로 무겁다는 점을 [MobileFaceSwap]({% post_url 2026-10-05-mobilefaceswap %})이 지적합니다.

**3. 고전 그래픽스를 학습 목표로 바꾸는 기법.** 포아송 최적화를 후처리가 아니라 네트워크가 흉내 낼 **정답**으로 쓰는 발상은, [Disney의 다중 밴드 블렌딩]({% post_url 2026-08-30-hires-face-swapping %})이나 [AOT]({% post_url 2026-08-20-aot %})의 최적 수송처럼 "알고 있는 좋은 해를 빠른 네트워크로 상각"하는 흐름의 한 예입니다.

**4. 도메인 특화 지각 손실.** ImageNet VGG 대신 얼굴 인식·속성 분류로 학습한 VGG가 얼굴 세부를 더 잘 잡는다는 관찰은 이후 거의 모든 얼굴 생성 논문이 ArcFace류 신원 손실을 쓰는 것과 같은 방향입니다.

**5. 평가를 읽을 때 주의할 점.** 정량 지표의 신원 거리는 dlib 검증이라 거칠고, 세 방법의 신원·SSIM이 사실상 같습니다. 포즈·표정 우위는 소스 지향 설계(목표 랜드마크로 직접 조건화)의 당연한 결과이기도 합니다. 뷰 보간은 결과를 약간 흐리게 만들어 고해상도에 부적합하다고 Naruniec 등이 지적합니다. 위 toy의 삼각분할과 포아송은 알고리즘의 산술일 뿐 학습된 생성기의 품질은 보여 주지 않습니다.

## 7. 정리

| 항목 | 내용 |
|---|---|
| 목표 | 특정 인물 학습 없는(주체 비의존) 얼굴 교체 + 재연기, 영상에서 시간 일관성 |
| 재연기 | 랜드마크 히트맵 조건 순환 생성기, 큰 포즈를 작은 단계로, 단계별 일관성 손실 |
| 뷰 보간 | (yaw, pitch) 들로네 삼각분할 + 무게중심 가중 평균, 소스 영상 전체 활용 |
