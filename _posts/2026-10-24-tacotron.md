> 2017년까지의 음성 합성(TTS)은 텍스트 분석 프론트엔드, 지속시간 모델, 음향 모델, 보코더가 각각 전문 지식으로 설계되고 따로 학습되는 복잡한 파이프라인이었습니다. **Tacotron**(Wang, Skerry-Ryan, Stanton, Wu, Weiss, Jaitly, Yang, Xiao, Chen, Bengio, Le, Agiomyrgiannakis, Clark, Saurous, Google, Interspeech 2017)은 **문자 열을 입력받아 스펙트로그램을 직접 출력하는 하나의 seq2seq 모델**을 무작위 초기화에서 학습해 미국 영어 MOS 3.82를 얻었고, 당시 운영 중이던 파라메트릭 시스템(3.69)을 넘었습니다. 프레임 단위로 생성하므로 샘플 단위 자기회귀인 WaveNet보다 훨씬 빠릅니다.

## 1. 문제: TTS는 고도로 압축된 입력을 푸는 역문제

텍스트는 음성보다 훨씬 압축된 표현이고, 같은 텍스트가 여러 발음과 억양으로 실현될 수 있습니다. 출력은 연속값이고 입력보다 훨씬 길어서 예측 오차가 빠르게 누적됩니다. 기계 번역용 seq2seq를 그대로 쓰면 attention이 한 문자에 오래 머물러 정렬이 망가집니다. 기존 신경망 접근도 한계가 있었습니다. WaveNet은 언어학 특징을 입력으로 받아 보코더와 음향 모델만 대체했고, DeepVoice는 각 구성 요소를 신경망으로 바꿨지만 따로 학습했으며, Char2Wav는 보코더 파라미터를 예측하고 사전학습이 필요했습니다.

## 2. 방법

### CBHG 모듈

인코더와 후처리 네트워크의 핵심 블록입니다. 폭 $$1 \ldots K$$의 1-D 합성곱 뱅크($$K = 16$$, 각 128채널)로 유니그램부터 $$K$$-그램까지의 지역 문맥을 뽑고, stride 1의 max pooling으로 지역 불변성을 더한 뒤, 고정 폭 1-D 합성곱 투영과 잔차 연결, 4층 highway network, 양방향 GRU(128)를 통과시킵니다. 모든 합성곱에 배치 정규화를 씁니다. 기계 번역의 문자 단위 인코더(Lee et al.)에서 가져오되 비인과 합성곱, BN, 잔차, stride 1 풀링을 더해 일반화가 좋아졌습니다.

### 인코더

문자를 256차원으로 임베딩하고 **프리넷**(FC-256-ReLU → Dropout 0.5 → FC-128-ReLU → Dropout 0.5)을 거쳐 CBHG로 보냅니다. 프리넷의 병목과 드롭아웃이 수렴과 일반화를 돕고, CBHG 인코더는 다층 RNN 인코더보다 과적합이 적고 발음 오류가 적습니다.

### 디코더

내용 기반 tanh attention을 쓰는 디코더입니다. attention RNN(GRU 256)이 매 스텝 쿼리를 만들고, 문맥 벡터와 attention RNN 출력을 이어 2층 잔차 GRU(256)에 넣습니다. 디코더 목표는 **80밴드 멜 스펙트로그램**입니다. 선형 스펙트로그램은 정렬을 배우기에 중복이 많아서, 명료도와 운율 정보만 담은 압축 표현을 쓰고 파형 복원은 후처리에 맡깁니다.

가장 중요한 트릭은 **한 스텝에 겹치지 않는 $$r$$개 프레임을 한꺼번에 예측**하는 것입니다. 디코더 스텝 수가 $$1/r$$로 줄어 모델 크기, 학습·추론 시간이 줄고, 무엇보다 attention이 초기에 앞으로 움직이기 쉬워져 **정렬이 훨씬 빨리 안정적으로 학습**됩니다. 한 문자는 보통 여러 프레임에 대응하므로 한 프레임씩 내면 같은 문자에 여러 스텝 머물러야 하기 때문입니다. 논문은 $$r = 2$$로 MOS를 측정했고 $$r = 5$$도 잘 동작합니다. 추론 때는 $$r$$개 예측 중 마지막 프레임을 다음 입력으로 넣고, 학습 때는 $$r$$번째마다의 정답 프레임을 넣습니다. scheduled sampling은 음질을 해쳐 쓰지 않았고, 대신 디코더 프리넷의 드롭아웃이 출력 분포의 다봉성을 푸는 잡음원 역할을 합니다.

### 후처리 네트워크와 파형 합성

후처리 네트워크(CBHG)는 멜 스펙트로그램을 Griffin-Lim으로 복원 가능한 **선형 스케일 스펙트로그램**으로 바꿉니다. 왼쪽에서 오른쪽으로만 가는 seq2seq와 달리 전체 시퀀스를 양방향으로 보므로 프레임별 오차를 교정할 수 있고, 하모닉과 고주파 포먼트 구조가 더 또렷해집니다. 파형은 Griffin-Lim(1984)으로 만듭니다. 예측한 크기를 1.2제곱하면 아티팩트가 줄고, 50회(사실상 30회) 반복이면 수렴합니다. 학습 가중치가 없어 TensorFlow 그래프 안에 넣었지만 손실은 걸지 않았습니다. 저자들도 Griffin-Lim은 단순함을 위한 선택이고 학습 가능한 인버터가 다음 과제라고 적었습니다.

### 학습 세부

50ms 프레임, 12.5ms 시프트, 2048점 FFT, 24kHz, pre-emphasis 0.97. 디코더(멜)와 후처리(선형) 모두 $$\ell_1$$ 손실을 같은 가중치로 더합니다. Adam, 학습률 0.001에서 0.0005/0.0003/0.0001로 감쇠, 배치 32. 패딩 프레임에 손실 마스크를 쓰면 모델이 **언제 멈출지 몰라 끝에서 소리를 반복**하므로, 0으로 채운 패딩 프레임도 재구성하게 둡니다. 데이터는 전문 여성 화자의 북미 영어 24.6시간입니다.

## 3. 코드로 보기: Griffin-Lim 수렴과 $$r$$의 효과

합성 유성음 신호의 STFT 크기만 주고 Griffin-Lim으로 위상을 복원하며 스펙트럼 수렴 오차를 반복 횟수별로 기록합니다. 그리고 3초 발화에서 $$r$$에 따라 디코더 스텝 수와 문자당 스텝 수가 어떻게 변하는지 셉니다.

```python
import numpy as np
rng = np.random.default_rng(0)
# a synthetic "voiced" signal: harmonics with vibrato, 24 kHz, 0.6 s
sr, n = 24000, 14400
t = np.arange(n) / sr
f0 = 180 * (1 + 0.02 * np.sin(2 * np.pi * 5 * t))
phase = 2 * np.pi * np.cumsum(f0) / sr
x = sum(np.sin(k * phase) / k for k in range(1, 8)) * np.hanning(n)

win, hop = 1200, 300                    # 50 ms frame, 12.5 ms shift, as in the paper
w = np.hanning(win)
def stft(x):
    frames = np.stack([x[i:i + win] * w for i in range(0, len(x) - win + 1, hop)])
    return np.fft.rfft(frames, n=2048, axis=1)
def istft(S):
    frames = np.fft.irfft(S, n=2048, axis=1)[:, :win] * w
    out = np.zeros(hop * (len(frames) - 1) + win); norm = np.zeros_like(out)
    for i, f in enumerate(frames):
        out[i * hop:i * hop + win] += f; norm[i * hop:i * hop + win] += w ** 2
    return out / np.maximum(norm, 1e-8)

mag = np.abs(stft(x))                   # what the model predicts: magnitude only
def griffin_lim(mag, iters):
    S = mag * np.exp(2j * np.pi * rng.random(mag.shape))   # random initial phase
    errs = []
    for _ in range(iters):
        y = istft(S); S2 = stft(y)
        errs.append(np.linalg.norm(np.abs(S2) - mag) / np.linalg.norm(mag))   # spectral convergence
        S = mag * np.exp(1j * np.angle(S2))
    return istft(S), errs
y, errs = griffin_lim(mag, 60)
print("Griffin-Lim: relative magnitude error after k iterations (paper: about 30-50 iterations are enough)")
for k in (1, 5, 10, 20, 30, 50, 60): print(f"  iter {k:>2}: {errs[k-1]:.4f}")
L = min(len(x), len(y))

# reduction factor r: decoder steps and frames per character for a 60-character sentence of 3.0 s
frames = int(3.0 / 0.0125)
print(f"\n3.0 s utterance = {frames} frames (12.5 ms hop), 60 characters")
for r in (1, 2, 3, 5): print(f"  r={r}: {frames // r:>3} decoder steps, {frames / r / 60:.1f} steps per character")
```


- 무작위 위상에서 시작한 Griffin-Lim은 1회에 68%였던 크기 오차를 30회에 16%, 50회에 9%까지 줄입니다. 논문이 "50회면 수렴, 사실 30회면 충분"이라고 한 범위입니다. 복원되는 것은 크기이지 원래 위상이 아니므로, 파형 자체는 원본과 다르지만 사람이 듣기에 비슷한 소리가 됩니다.
- $$r = 1$$이면 한 문자가 평균 4개 디코더 스텝에 대응해 attention이 같은 자리에 머물러야 하지만, $$r = 2$$면 2스텝, $$r = 5$$면 1스텝 미만입니다. 스텝마다 attention이 전진할 수 있으므로 정렬 학습이 쉬워지는 이유가 숫자로 보입니다.

## 4. 실험

**Ablation(정렬 시각화).** 인코더·디코더 모두 2층 잔차 GRU인 바닐라 seq2seq는 scheduled sampling 없이는 정렬을 못 배우고, 배워도 attention이 여러 프레임에 걸쳐 **한 자리에 갇혀** 명료도와 전체 길이가 무너집니다. 인코더만 GRU로 바꾼 모델은 Tacotron보다 정렬이 노이즈가 많고, 긴 문장에서 발음 오류가 늘어납니다. 후처리 네트워크를 빼고 디코더가 선형 스펙트로그램을 직접 내게 하면 100~400번 빈 사이의 고차 하모닉과 고주파 포먼트가 흐려집니다.

**MOS.** 100개의 미공개 문장, 문장당 8명 평가, 헤드폰 사용 평가만 집계.

| 시스템 | MOS |
|---|---|
| Tacotron | 3.82 ± 0.085 |
| 파라메트릭(LSTM 기반, 운영 중) | 3.69 ± 0.109 |
| 연결 합성(운영 중) | 4.09 ± 0.119 |

Griffin-Lim 아티팩트를 안고도 파라메트릭 시스템을 넘었고, 단위 선택 기반 연결 합성에는 못 미칩니다.

## 5. 해석

**1. 중간 표현을 두 단계로 나눈 것이 설계의 핵심입니다.** "정렬을 배우기 좋은 압축된 표현(멜)"과 "파형으로 되돌리기 좋은 표현(선형)"을 분리하고 후처리 네트워크로 잇습니다. 이 분리는 Tacotron 2에서 후처리 네트워크를 WaveNet 보코더로 바꾸는 길을 열었고, 멜 스펙트로그램을 음성 모델의 공용 인터페이스로 만들었습니다. [음성 분류 기초]({% post_url 2026-06-22-audio-classification %})에서 다룬 멜 스케일이 생성에서도 중심이 되는 지점입니다.

**2. $$r$$ 프레임 동시 예측은 작은 트릭이 큰 차이를 만드는 예입니다.** 속도 향상은 부수 효과이고, 본질은 attention에게 "앞으로 가라"는 귀납 편향을 주는 것입니다. 이후 단조 attention, 지속시간 예측(FastSpeech)처럼 정렬을 명시적으로 다루는 연구들이 같은 문제를 다른 방식으로 풉니다.

**3. 드롭아웃이 잡음원이라는 관찰이 흥미롭습니다.** 디코더 프리넷의 드롭아웃을 추론에도 켜 두는 관행(Tacotron 2에서도 유지)이 여기서 시작됩니다. 다봉 분포를 $$\ell_1$$ 회귀로 학습할 때 생기는 "평균으로 뭉개짐"을 확률적 입력으로 피하는 것으로, [디퓨전 기반 음성 모델]({% post_url 2026-07-03-latent-diffusion-models %})이 등장하기 전의 실용적 해법이었습니다.

**4. [RNN·LSTM·GRU]({% post_url 2026-06-08-rnn-lstm-gru %}) 시대의 seq2seq 설계가 응축되어 있습니다.** 잔차 GRU, 양방향 GRU, highway network, 내용 기반 attention이 모두 등장합니다. 2년 뒤 Transformer TTS, FastSpeech가 attention 정렬 문제를 비자기회귀로 우회하지만, 멜 스펙트로그램 출력과 프리넷·포스트넷 구조는 그대로 남습니다.

**5. 평가를 읽을 때 주의할 점.** 단일 화자 24.6시간의 사내 데이터라 공개 데이터셋 재현과는 조건이 다릅니다. MOS는 자연성만 측정하고 발음 정확도(WER)는 보고하지 않았습니다. ablation은 정렬 그림과 청취에 의존하며 수치 비교가 없습니다. 위 toy의 합성 신호는 실제 음성보다 단순해 Griffin-Lim 수렴이 빠를 수 있습니다.

## 6. 정리

| 항목 | 내용 |
|---|---|
| 문제 | 다단계 TTS 파이프라인의 설계 비용과 오차 누적, 바닐라 seq2seq의 정렬 실패 |
| 구조 | 문자 임베딩 → 프리넷 → CBHG 인코더 → attention 디코더(멜 80밴드, $$r$$프레임) → CBHG 후처리(선형) → Griffin-Lim |
| 핵심 트릭 | $$r$$개 프레임 동시 예측(정렬 안정·속도), 프리넷 드롭아웃(잡음원), 패딩 프레임도 재구성 |
| 손실 | 멜·선형 스펙트로그램 $$\ell_1$$, 동일 가중치 |
| 결과 | MOS 3.82(파라메트릭 3.69, 연결 합성 4.09), 프레임 단위 생성으로 WaveNet보다 빠름 |
| 남은 과제 | Griffin-Lim 아티팩트 → 학습 가능한 보코더(Tacotron 2) |
