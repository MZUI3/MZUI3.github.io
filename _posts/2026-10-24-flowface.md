> [HifiFace]({% post_url 2026-10-24-hififace %})는 3D 형상 정보를 **잠재 특징에 주입**해 얼굴 형태를 옮겼지만, FlowFace의 저자들은 그렇게 넣은 형상을 디코더가 정확히 복원하기 어렵다고 봅니다. 그리고 거의 모든 방법이 신원을 **인식 임베딩**으로 뽑는데, 판별 과제로 학습된 임베딩은 클래스 내 변화를 무시해 개인적 외형을 잃는다는 [Smooth-Swap]({% post_url 2026-10-24-smooth-swap %})의 지적이 있습니다. 추론 때 인식 모델이 필요하다는 배포상의 불편도 있습니다. **FlowFace**(Zeng, Zhang, Fan, Lv, Wang, Zhang, Ma, Li, Ding, Yu, NetEase Fuxi·UTS, AAAI 2023)는 두 가지를 바꿉니다. 얼굴 **윤곽**은 1단계에서 **의미 플로**로 목표 얼굴을 픽셀 단위로 **명시적으로 워핑**해 옮기고, 안쪽은 2단계에서 인식기 대신 얼굴로 사전학습한 **MAE 인코더**의 패치 임베딩 공간에서 **교차 attention**으로 옮깁니다. MAE 잠재 공간에서 교체를 한 첫 방법입니다.

## 1. 1단계: 얼굴 재형성 네트워크

**형상 표현.** 픽셀 단위 워핑이므로 명시적 랜드마크가 필요합니다. 3D 복원 모델 $$E_{3D}$$로 FLAME 계수(형상 $$\beta$$, 포즈 $$\theta$$, 표정 $$\psi$$, 카메라 $$c$$)를 뽑고, 목표 메시 $$M_t$$와 **소스 형상 + 목표 포즈·표정**의 메시 $$M_{s2t}$$를 만들어 목표 카메라로 투영한 2D 랜드마크 $$P_t$$, $$P_{s2t}$$를 얻습니다. **윤곽 랜드마크만** 씁니다. 안쪽 랜드마크는 신원 정보를 담아 재형성을 방해하기 때문입니다.

**의미 플로 추정.** 두 랜드마크 집합의 변위는 희소하므로, 의미 유도 생성기 $$G_{res}$$가 $$(P_{s2t}, P_t, S_t)$$에서 조밀한 **의미 플로** $$V_t$$를 만듭니다. 목표 분할 맵 $$S_t$$는 랜드마크가 잃은 의미 정보를 보충합니다. 워핑 모듈이 $$V_t$$로 이미지와 분할 맵을 함께 워핑하고($$I^{res}_t, S^{res}_t$$), 둘을 이어 받는 **의미 유도 판별기** $$D_{res}$$가 이미지 수준과 의미 수준에서 진위를 가려 플로가 부정확할 때의 부자연스러움을 막습니다(학습에만 사용). 손실은 힌지 적대, 소스=목표일 때의 재구성(확률적으로 같게 둠), 그리고 워핑 결과에서 검출한 랜드마크 $$P^{res}_t$$와 $$P_{s2t}$$의 **랜드마크 손실**($$\lambda_{ldmk} = 800$$, $$\lambda_{rec} = 10$$).

## 2. 2단계: 얼굴 교체 네트워크

**공유 얼굴 인코더.** 소스와 목표(재형성된 $$I^{res}_t$$)를 **같은** 인코더 $$E_f$$로 패치 임베딩 $$e_s, e_t \in \mathbb{R}^{N \times L}$$에 매핑합니다. MAE 방식으로 대규모 얼굴 데이터에서 마스크 복원으로 사전학습하면, 가려진 패치를 이웃에서 복원해야 하므로 각 패치 임베딩에 풍부한 위상·의미 정보가 담깁니다. StyleGAN2의 압축 코드나 신원 임베딩보다 외형과 신원을 더 잘 담는다는 주장이고, 인코더 두 개가 필요 없어 배포가 단순합니다.

**교차 attention 융합 모듈(CAFM).** 신원은 관련 패치끼리(코→코) 옮겨져야 하므로, 목표 패치를 쿼리, 소스 패치를 키·값으로 $$CA = \text{softmax}(Q_t K_s^\top / \sqrt{d_k})$$를 계산하고 $$V_{fu} = CA \cdot V_s + V_t$$로 소스 신원을 모아 목표 값에 **더합니다**. LN·MLP·스킵을 거쳐 표준 Transformer 블록 2개로 $$e_o$$를 만들고, MAE의 ViT 디코더 대신 **합성곱 디코더**로 이미지를 냅니다(더 사실적). 손실은 적대, $$I^{res}_t$$와의 재구성 10, ArcFace 신원 5(학습에만), 랜드마크 포즈 5000, VGG 마지막 두 층 지각 2, 세밀 표정 임베딩 10.

## 3. 코드로 보기: 플로 워핑과 의미 매칭

좁은 목표 윤곽과 넓은 소스 형상의 24개 윤곽 랜드마크 변위를 thin-plate-spline형 RBF로 보간해 조밀 플로를 만들고, 목표 얼굴 마스크를 워핑해 소스 형상과의 IoU를 재며, 섞인 순서의 소스 패치에 대해 교차 attention이 의미가 맞는 패치를 찾는 비율을 봅니다.

```python
import numpy as np
rng = np.random.default_rng(0)
# face contour as 2-D landmarks from a toy 3DMM: shape coefficient 'wide' and 'long'; the target wears the source's shape, its own pose
ang = np.linspace(0, 2 * np.pi, 24, endpoint=False)
def contour(wide, long, cx=32, cy=32): return np.stack([cx + (12 + 4 * wide) * np.cos(ang), cy + (15 + 4 * long) * np.sin(ang)], 1)
P_t = contour(-0.8, 0.3)                                   # target: narrow face
P_s2t = contour(0.9, -0.4)                                 # source shape rendered at the target's pose/expression -> the reshaping goal
# dense semantic flow from sparse landmark displacements: thin-plate-spline-like RBF interpolation (the paper learns it with a generator)
H = W = 64; yy, xx = np.mgrid[0:H, 0:W]; pts = np.stack([xx.ravel(), yy.ravel()], 1).astype(float)
def rbf(d2): return d2 * np.log(d2 + 1e-9)
K = rbf(((P_t[:, None] - P_t[None]) ** 2).sum(-1)); disp = P_s2t - P_t
coef = np.linalg.solve(K + 1e-3 * np.eye(len(P_t)), disp)
flow = (rbf(((pts[:, None] - P_t[None]) ** 2).sum(-1)) @ coef).reshape(H, W, 2)
print(f"semantic flow: max displacement {np.abs(flow).max():.1f} px, mean inside the face {np.linalg.norm(flow, axis=-1)[((xx-32)**2/144 + (yy-32)**2/225) < 1].mean():.1f} px")
# warp the target face mask with the flow (backward warping of the shape) and compare its outline with the source shape
face_t = ((xx - 32) ** 2 / (12 + 4 * -0.8) ** 2 + (yy - 32) ** 2 / (15 + 4 * 0.3) ** 2) < 1
face_goal = ((xx - 32) ** 2 / (12 + 4 * 0.9) ** 2 + (yy - 32) ** 2 / (15 + 4 * -0.4) ** 2) < 1
# forward splat: every target pixel moves by its flow
dst = np.zeros_like(face_t); sx = np.clip(np.round(xx + flow[..., 0]).astype(int), 0, W - 1); sy = np.clip(np.round(yy + flow[..., 1]).astype(int), 0, H - 1)
dst[sy[face_t], sx[face_t]] = True
from scipy.ndimage import binary_closing; dst = binary_closing(dst, iterations=2)
iou = lambda a, b: (a & b).sum() / (a | b).sum()
print(f"face-shape IoU with the source shape: target as is {iou(face_t, face_goal):.2f} -> after warping with the semantic flow {iou(dst, face_goal):.2f}")
# why contour landmarks only: inner landmarks (eyes, mouth) carry identity and would distort the inner face if used for the flow
print("the flow is estimated from CONTOUR landmarks only; the inner face is left to the second-stage swapping network")
# second stage: cross-attention fusion in a shared MAE latent space; identity flows between semantically matching patches
N, D = 16, 8; es = rng.standard_normal((N, D)); et = es + 0.5 * rng.standard_normal((N, D))      # target patches resemble the source's at the same semantic position
perm = rng.permutation(N); es_shuf = es[perm]                                                       # patches of the source in a different order (misalignment)
att = np.exp(et @ es_shuf.T / np.sqrt(D)); att /= att.sum(1, keepdims=True)
print(f"cross-attention: fraction of target patches whose top-attended source patch is the semantically matching one despite the shuffle: {np.mean(att.argmax(1) == np.argsort(perm)) * 100:.0f}%")
```

```text
semantic flow: max displacement 33.7 px, mean inside the face 4.2 px
face-shape IoU with the source shape: target as is 0.57 -> after warping with the semantic flow 0.94
the flow is estimated from CONTOUR landmarks only; the inner face is left to the second-stage swapping network
cross-attention: fraction of target patches whose top-attended source patch is the semantically matching one despite the shuffle: 81%
```

- 윤곽 변위만으로 보간한 플로는 얼굴 안쪽 평균 4.2픽셀, 최대 34픽셀이고, 워핑 후 목표 얼굴 마스크와 소스 형상의 IoU가 0.57에서 0.94로 오릅니다. 논문의 생성기는 이 보간을 학습하고 분할 맵으로 보강하지만, "윤곽의 희소 변위 → 조밀 플로 → 워핑"이라는 뼈대는 이 toy와 같습니다. 픽셀 공간에서 형태를 바꾸므로 디코더가 형상을 "복원"할 필요가 없습니다.
- 소스 패치의 순서를 섞어도 교차 attention은 81%의 목표 패치를 의미가 맞는 소스 패치에 연결합니다. 패치 임베딩이 내용으로 맺어지므로 소스·목표의 정렬이 필요 없다는 CAFM의 전제입니다. [RAFSwap]({% post_url 2026-10-24-rafswap %})의 부위 토큰 attention이 네 부위였다면 여기서는 모든 패치입니다.

## 4. 실험

CelebA-HQ + FFHQ + VGGFace2에서 저품질을 제외한 35만 장, 256². $$F_{res}$$ 3.2만 스텝, MAE 인코더 사전학습 후 고정, $$F_{swa}$$ 64만 스텝.

**FF++(1만 장).** ID 검색은 CosFace·SphereFace 두 인식기의 평균, 표정은 다른 표정 임베딩 모델의 거리입니다.

| 방법 | ID 평균 ↑ | 형상 ↓ | 표정 ↓ | 포즈 ↓ |
|---|---|---|---|---|
| FaceShifter | 89.01 | 1.68 | 0.33 | 2.28 |
| SimSwap | 94.43 | 1.74 | 0.26 | 1.40 |
| HifiFace | 94.62 | 1.62 | 0.30 | 2.29 |
| $$F_{res}$$ + SimSwap | 95.56 | 1.67 | 0.27 | 2.27 |
| $$F_{swa}$$만 | 98.70 | 1.43 | 0.21 | 1.99 |
| FlowFace | **98.83** | **1.17** | 0.22 | 2.66 |

신원·형상·표정에서 최고이고 포즈만 조금 나쁜데, 얼굴 형태를 바꾸면 포즈 추정기가 영향을 받기 때문이라고 설명합니다. 재형성 네트워크를 SimSwap 앞에 붙이기만 해도 신원·형상이 좋아집니다. 정성적으로 HifiFace보다 형태가 소스에 가깝고(잠재 주입보다 명시 플로가 정확) 세밀한 표정을 더 지키며(Figure 2), MegaFS·[FaceInpainter]({% post_url 2026-10-24-faceinpainter %})·HighRes([FSLSD]({% post_url 2026-10-24-fslsd %}))·Smooth-Swap보다 형태와 수염 같은 안쪽 특징을 잘 옮기면서 Smooth-Swap과 달리 머리 모양·색은 유지합니다(Figure 3). **사용자 연구**(SimSwap, HifiFace 대비)에서 형태 44.2%, 신원 37.6%, 표정 35.1%, 사실성 43.6%로 선택됩니다. Ablation은 $$F_{res}$$만으로는 안쪽이 그대로, $$F_{swa}$$만으로는 윤곽이 목표임을 보입니다.

## 5. 해석

**1. 형태를 픽셀 공간에서 명시적으로 바꾼다는 선택.** HifiFace의 잠재 주입과 [E4S]({% post_url 2026-10-24-e4s %})의 마스크 재구성 사이에서, 플로 워핑은 가장 직접적입니다. 형상 오차 1.17 대 1.62가 그 효과이고, 2단계 설계라 재형성 네트워크를 **다른 교체기 앞에도** 붙일 수 있습니다($$F_{res}$$ + SimSwap). 윤곽 랜드마크만 쓰는 선택은 FLAME 신원 기저와 표정의 분리를 믿는 것입니다.

**2. 신원 표현을 인식기에서 자기지도 인코더로 옮겼습니다.** Smooth-Swap의 진단(판별 임베딩은 개인적 변화를 지움)에 대한 다른 답이고, [Splice]({% post_url 2026-10-24-splice-vit %})가 DINO 특징을 외형 전이에 쓴 것처럼 **자기지도 ViT 특징이 생성의 표현**이 되는 흐름입니다. 소스·목표에 같은 인코더를 쓰므로 신원·속성이 같은 공간에 있고, 교차 attention이 그 안에서 "무엇을 가져올지"를 패치 단위로 정합니다. 다만 신원 손실에는 여전히 ArcFace가 학습 때 쓰입니다.

**3. 교차 attention 융합은 AdaIN 주입의 대안입니다.** 전역 벡터를 모든 위치에 넣는 대신 패치 대응으로 넣으므로 RAFSwap과 같은 장점(정렬 불변, 배경 보존)을 가지며, 두 Transformer 블록으로 끝나는 가벼운 구조입니다. 위 toy의 81%가 그 대응의 성격입니다.

**4. 한계는 분할·3D 의존과 포즈 오차입니다.** 1단계는 3D 복원과 분할 맵에 기대고, 플로가 틀리면 워핑 아티팩트가 생깁니다(판별기가 억제). 포즈 오차 증가를 "형태 변화 때문"으로 설명하지만 검증은 없습니다. 256²에 머무르며 영상은 다루지 않습니다.

**5. 평가를 읽을 때 주의할 점.** FaceShifter·HifiFace의 ID 수치 일부는 원 논문 인용이고 나머지는 재계산이라 표 안에서도 조건이 섞여 있습니다. 표정 지표는 새 임베딩 모델이라 다른 논문과 비교할 수 없습니다. 사용자 연구의 선택률은 세 방법 중 상대 비율입니다. 위 toy의 플로는 RBF 보간이지 학습된 생성기가 아니고, 패치 매칭 toy는 목표 패치가 소스 패치의 잡음 버전이라는 유리한 설정입니다.

## 6. 정리

| 항목 | 내용 |
|---|---|
| 전제 | 얼굴 윤곽도 신원; 잠재 주입 형상은 복원이 어렵고, 인식 임베딩은 개인적 외형을 잃음 |
| 1단계 $$F_{res}$$ | FLAME 계수 → 소스 형상 + 목표 포즈·표정의 윤곽 랜드마크 → $$(P_{s2t}, P_t, S_t)$$에서 의미 플로 → 목표 워핑, 의미 유도 판별기, 랜드마크 손실 800 |
| 2단계 $$F_{swa}$$ | 얼굴 MAE 공유 인코더 → 교차 attention 융합(Q 목표, K·V 소스, 더하기) → Transformer 2블록 → 합성곱 디코더 |
| 결과 | FF++ ID 98.83, 형상 1.17(HifiFace 1.62), 표정 0.22, 사용자 연구 1위; $$F_{res}$$는 SimSwap에도 적용 |
| 한계 | 3D·분할 의존, 포즈 오차 증가, 256², 학습 시 ArcFace 필요 |
